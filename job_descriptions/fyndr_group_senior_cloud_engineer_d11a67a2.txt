Senior Cloud Engineer




AWS | Kubernetes / EKS | Terraform | SaaS Platform

Take a live AWS platform from manual releases towards continuous delivery.
Work with the Cloud Infrastructure Manager to standardise how each customer's environment is built and updated.
Stay hands-on with Kubernetes and help run the platform you design.




The Opportunity

We're partnering with an Australian software company that runs a separate AWS environment for each enterprise customer. Those environments have been customised over time, and engineers still roll out releases by hand.




The Cloud Infrastructure Manager has started building reusable infrastructure templates. You'll work alongside him to decide what can be standardised, what needs to stay specific to each customer and how to introduce changes safely while customers use the platform every day.




What You Will Be Doing

Build reusable infrastructure as code to provision, update and scale customer environments on AWS.
Develop CI/CD pipelines with software engineers so tested changes can move reliably into production.
Secure container builds and releases, from checking image sources and scanning for vulnerabilities to controlling which image reaches each environment.
Run production Kubernetes workloads, manage upgrades and troubleshoot issues while keeping services available.
Improve monitoring and recovery so the team can spot a failed release, stop the rollout and restore service.
Strengthen AWS networking, access controls and secrets management across customer environments.




What We Are Looking For

Hands-on experience designing and running AWS infrastructure in production. A SaaS or product engineering background is particularly relevant.
Experience improving how a live service is released, ideally moving manual deployments towards repeatable, automated delivery.
Production Kubernetes experience, preferably on Amazon EKS, including upgrades, scaling or troubleshooting.
Practical infrastructure-as-code experience with Terraform, CloudFormation or similar tooling.
Strong Linux and scripting skills, with the judgement to diagnose production issues and make changes safely.




Why Consider This Role?

Influence the platform design while the modernisation is still at an early stage.
See your work through from design and implementation to the releases customers rely on.
Help grow the in-house cloud team's expertise and mentor engineers who will use what you build.
