Key Responsibilities

Test Planning & Execution: Design detailed, comprehensive, and well-structured test plans and test cases based on software requirements.

Automation Development: Build and maintain automated test scripts for UI, API, and integration testing using modern automation frameworks.

Bug Tracking & Reporting: Identify, record, document thoroughly, and track software bugs; verify fixes once resolved by the development team.

Regression Testing: Perform thorough regression testing when bugs are resolved or new code releases occur.

Agile Collaboration: Partner closely with software developers, product managers, and UX designers to clarify requirements and establish acceptance criteria.

Qualifications & Requirements

Experience: 2–5 years of proven work experience in software quality assurance or software development.

Technical Skills: Hands-on experience with automated testing tools (e.g., Selenium, Playwright, Cypress, Appium) and API testing (e.g., Postman, REST Assured).

Programming: Proficiency in at least one object-oriented programming scripting language (Python, Java, JavaScript, or TypeScript).

Core Competencies: Strong understanding of Software Development Life Cycle (SDLC), Software Testing Life Cycle (STLC), and Agile/Scrum processes.

Tools: Experience with bug tracking tools (Jira, GitHub Issues) and CI/CD tools (Jenkins, GitHub Actions, GitLab CI).
