Job Description:

About Broadcom

VMware by Broadcom is a leader in datacenter infrastructure, networking, security, and virtualization software. We have an exciting opportunity for a Senior Engineer to join the Application Networking and Security (ANS) division.

About The ANS Team

ANS is a fast-paced, tight-knit team providing advanced security solutions such as Distributed Firewall and Rule Recommendation, Network Traffic Anomalies Detection, Network Flows Visualization and Monitoring, Intrusion Detection and Prevention and Malware Prevention.

About The Role

We are looking for a skilled DevOps Engineer to streamline our software development lifecycle, automate infrastructure workflows, and enhance deployment reliability. You will bridge the gap between development and operations by managing version control, maintaining robust CI/CD pipelines, and leveraging modern scripting and AI-driven automation tools.

Key Responsibilities



CI/CD Pipeline Management: Design, build, and maintain automated Continuous Integration and Continuous Deployment (CI/CD) pipelines using Jenkins to ensure fast, reliable code delivery.
Version Control & Build Systems: Manage source code repositories, branching strategies, and merge workflows using Git, while optimizing build systems for speed and consistency.
System Administration: Configure, monitor, and troubleshoot Linux-based servers and environments to ensure high availability, performance, and security.
Automation & Scripting: Write clean, maintainable scripts in Python to automate repetitive operational tasks, system checks, and deployment workflows.
AI-Assisted Operations: Integrate modern AI tools (such as AI coding assistants, automated code-review bots, or AIOps monitoring tools) into daily workflows to accelerate troubleshooting, script generation, and anomaly detection.
Cross-Team Collaboration: Partner closely with software developers, QA engineers, and security teams to resolve build failures, manage releases, and enforce DevOps best practices.



Required Skills & Qualifications



Experience: 3-5 years of experience in software product.
Education: A Bachelor's or Master's degree in Computer Science.
Version Control: Strong hands-on experience with Git (GitHub, GitLab, or Bitbucket), including branching models, pull requests, and conflict resolution.
CI/CD & Build Tools: Proven experience setting up and administering Jenkins (declarative/scripted pipelines, plugins, webhooks) and familiarity with build tools (e.g., Maven, Gradle, npm, or Make).
Operating Systems: Solid command-line proficiency in Linux (Ubuntu, CentOS, RHEL), including process management, networking basics, permissions, and shell scripting.
Programming/Scripting: Practical experience writing automation scripts and utilities using Python.
AI Tooling: Familiarity with using AI tools (e.g., GitHub Copilot, ChatGPT/LLMs, or AI-powered log analysis/observability tools) to improve engineering productivity and operational efficiency.
Problem-Solving: Strong analytical skills with the ability to diagnose pipeline bottlenecks, build errors, and environment issues quickly.



Nice-to-Have Qualifications



Experience with containerization and orchestration tools (Docker, Kubernetes).
Familiarity with cloud platforms (AWS, Azure, or Google Cloud Platform).
