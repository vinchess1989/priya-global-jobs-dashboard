Senior Software Test Automation Engineer – Enterprise Web & Systems Integration

Permanent ¦ Hybrid ¦ Limerick

€60,000 - €75,000 DOE + Excellent Benefits




TechHeads Recruitment is partnering with a leading global healthcare technology organisation to recruit an experienced Senior Software Test Automation Engineer for its engineering team in Limerick.

This is an exciting opportunity to work on an enterprise web/software and system-integration platform with connected hardware, contributing to the development and delivery of high-quality, reliable software solutions.

We are seeking a technically strong, hands-on Test Automation Engineer with expertise in end-to-end system testing, web and API automation, SQL and complex software integrations.

The successful candidate will work closely with software developers, systems engineers and cross-functional teams to develop automated testing solutions, validate enterprise applications and troubleshoot system integration issues.




Key Responsibilities

Design, develop and maintain automated testing frameworks for enterprise web applications and APIs.
Perform end-to-end system testing across web applications, backend services and integrated software platforms.
Develop and maintain automated test scripts using C#, TypeScript and/or Python.
Implement web automation solutions using Playwright and/or Selenium.
Perform API testing, SQL database validation and system integration testing.
Validate software interactions with connected hardware, external applications and services.
Investigate complex software defects, troubleshoot integration issues and perform root cause analysis.
Support healthcare interoperability testing, including HL7 messaging and interfaces.
Integrate automated testing into CI/CD pipelines using Azure DevOps and Git.
Develop test plans, test cases, test reports and requirements traceability documentation.
Collaborate with development teams to improve automation coverage, software quality and release reliability.
Participate in Agile development activities and continuous improvement initiatives.




Essential Skills & Experience

5+ year’s professional experience in software testing, quality assurance or test automation.
Strong hands-on experience in end-to-end system testing of enterprise software applications.
Proven experience developing and maintaining web and API test automation frameworks.
Programming or scripting experience using C#, TypeScript and/or Python.
Practical experience with Playwright and/or Selenium.
Strong SQL skills for database testing, data validation and troubleshooting.
Experience testing complex software integrations involving multiple applications, APIs and external systems.
Familiarity with Azure DevOps, Git and CI/CD processes.
Strong analytical, debugging and technical troubleshooting skills.
Experience with test planning, defect management, requirements traceability and Agile methodologies.
Relevant degree in Computer Science, Software Engineering, Information Technology or a related technical discipline.




Highly Desirable

Experience with HL7 healthcare messaging and system integration.
Previous experience in regulated healthcare, MedTech or healthcare software environments.
Experience testing enterprise software platforms integrated with connected hardware.
Experience developing automation frameworks from scratch.
Knowledge of software verification and validation practices within regulated environments.




What's on Offer?

Competitive salary and excellent benefits package.
Permanent position with a leading global healthcare technology organisation.
Opportunity to work on innovative enterprise software and connected healthcare systems.
Collaborative engineering environment with opportunities for professional development and career progression.




€60,000 - €75,000 DOE + Excellent Benefits
