Job Summary~

We are looking for a skilled DevOps Engineer with strong expertise in Kubernetes, CI/CD pipelines, and Jenkins. The ideal candidate should have hands-on experience in GCP, along with working knowledge of service mesh technologies like Istio and modern observability tools such as Google Cloud Monitoring and New Relic.

About the team~

The DevOps team is responsible for building and operating the core infrastructure that powers JioStar’s digital platforms. The focus is on automation, scalability, and reliability to ensure seamless delivery and high system uptime.

The team manages cloud environments across AWS and GCP, containerized workloads on Kubernetes, and service communication using Istio. They enable robust CI/CD pipelines, efficient caching layers (e.g., Redis), and standardized environment provisioning.

Acting as the backbone of engineering operations, DevOps ensures secure deployments, proactive monitoring, performance optimization, and cost efficiency across systems.

The team’s mandate is to deliver a resilient, scalable, and high-performing platform that supports rapid development and consistent user experience.

Key responsibilities~


Design, implement, and manage CI/CD pipelines using Jenkins and other tools
Deploy, manage, and scale applications on Kubernetes (GKE preferred)
Build and maintain infrastructure on Google Cloud Platform (GCP)
Implement and manage service mesh (Istio) for microservices architecture
Set up and manage monitoring, alerting, and observability using Google Cloud Monitoring and New Relic
Create dashboards, alerts, and SLOs/SLIs for production systems
Automate infrastructure provisioning using tools like Terraform or similar
Monitor system performance and ensure high availability and reliability
Troubleshoot production issues and perform root cause analysis
Collaborate with development teams to improve deployment processes
Implement best practices for security, scalability, and cost optimization


Skills and attributes for success~


Strong experience with Kubernetes (cluster management, deployments, networking)
Expertise in CI/CD tools, especially Jenkins
Good hands-on experience with GCP (GKE, IAM, Cloud Monitoring, VPC, etc.)
Working knowledge of Istio / Service Mesh architecture
Experience with monitoring tools like Google Cloud Monitoring and New Relic
Experience with Docker and containerization
Familiarity with Infrastructure as Code (Terraform preferred)
Strong scripting skills (Bash / Python / Shell)
Understanding of Git-based workflows


Good to Have


Experience with multi-cloud environments (AWS/GCP)
Exposure to ArgoCD / GitOps workflows
Knowledge of Helm charts and Kubernetes packaging
Experience with centralized logging (ELK / Loki / GCP Logging)
Familiarity with security best practices (IAM, RBAC, secrets management, Vault)


Preferred education and experience~


Bachelor’s degree in Computer Science, IT, or related field
Relevant certifications (CKA/CKAD, GCP certifications) are a plus
