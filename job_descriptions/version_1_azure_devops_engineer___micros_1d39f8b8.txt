Job Description

Version 1 is seeking an experienced Azure DevOps Engineer with strong Microsoft Power Platform experience to join our team.

The successful candidate will take ownership of improving, standardising and automating the current Application Lifecycle Management (ALM) processes across the Power Platform delivery lifecycle.

This role requires strong hands-on experience with Azure DevOps (ADO) and its integration with Microsoft Power Platform, including Dataverse and Power Pages. The focus will be on improving source control, build and release automation, deployment consistency and governance across multiple Power Platform environments.

You will work closely with the existing Power Platform delivery team to implement robust DevOps practices that support reliable and repeatable deployments.

Key Responsibilities


Design, implement and improve Power Platform ALM processes using Azure DevOps.
Develop and maintain automated CI/CD pipelines for Power Platform deployments across multiple environments.
Manage Azure DevOps Repos and Git branching strategies for Power Platform development.
Implement source control processes for Dataverse solutions and Power Platform components.
Implement and maintain source control and deployment processes for Power Pages website code and configuration, including synchronisation between environments, local development and Azure DevOps repositories.
Automate the unpacking, versioning, validation, build and deployment of Power Platform solutions.
Use appropriate Power Platform CLI (PAC CLI) and Azure DevOps tooling to automate development and deployment activities.
Improve existing release processes to reduce manual deployment steps and provide greater consistency, traceability and repeatability.
Support environment-specific configuration, solution deployment and dependency management across the Power Platform environment estate.
Establish appropriate controls for pull requests, branching, approvals and releases.
Troubleshoot and resolve Power Platform build and deployment issues.
Produce clear technical documentation covering ALM processes, pipelines, branching and deployment procedures.
Work collaboratively with Power Platform developers, technical leads and other project stakeholders.


Qualifications

Strong hands-on experience with Azure DevOps, particularly:
Azure Repos
Git
Branching and pull request processes

Understanding of managed and unmanaged solutions and appropriate Power Platform solution strategies.
Experience handling environment-specific configuration such as environment variables and connection references.

Strong understanding of DevOps and ALM principles and the ability to apply them practically within a Power Platform programme.
Self-driven approach with the ability to take ownership of DevOps and ALM improvements.

Preferred Criteria
