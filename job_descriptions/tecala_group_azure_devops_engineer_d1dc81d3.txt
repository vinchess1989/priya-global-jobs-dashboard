ABOUT THE ROLE

We’re looking for an Azure DevOps Engineer to join our cloud team. You’ll design, build and support CI/CD pipelines and infrastructure-as-code across a range of client environments, helping customers modernise how they deliver and run their applications on Microsoft Azure. This is a hands-on technical role where you’ll work closely with architects, developers and client stakeholders.




WHAT WE'RE LOOKING FOR

What You’ll Be Doing

Designing, building and maintaining CI/CD pipelines in Azure DevOps (and GitHub Actions where required).
Developing and managing infrastructure as code using Terraform and/or Bicep/ARM templates.
Deploying and supporting Azure services including App Services, AKS, Functions, Azure SQL, networking and identity.
Automating build, release and operational tasks with PowerShell, Bash or Python.
Implementing monitoring, logging and alerting with Azure Monitor, Log Analytics and Application Insights.
Embedding security and governance best practice into pipelines and platforms (Key Vault, policy, RBAC, secrets management).
Troubleshooting deployment and platform issues and contributing to continuous improvement.
Producing clear technical documentation and supporting handover to operations teams.
Working directly with clients to understand requirements and recommend practical solutions.

What You’ll Bring

3+ years’ experience in a DevOps, cloud or platform engineering role.
Strong hands-on experience with Azure DevOps (Repos, Pipelines, Boards, Artifacts) and YAML pipelines.
Solid Microsoft Azure experience across computer, networking, storage and identity (Entra ID).
Infrastructure-as-code experience with Terraform and/or Bicep.
Scripting skills in PowerShell and/or Python/Bash.
Experience with containers (Docker, Kubernetes/AKS) highly regarded.
Understanding of Git branching strategies and release management.
Microsoft certifications such as AZ-400 or AZ-104 highly regarded.
MSP or consulting experience across multiple client environments is a plus.
Excellent communication skills and a client-focused, collaborative approach.
Full Australian working rights and ideally ability for DISP sponsorship.
