DevOps Lead

Location: Melbourne

Experience: 10-12 Years

About the Role

We are looking for an experienced DevOps Lead to drive the design, implementation, and optimization of cloud-native infrastructure, DevOps practices, and automation frameworks. The ideal candidate will have strong expertise in Azure cloud technologies, CI/CD pipelines, Infrastructure as Code (IaC), containerization, Kubernetes, and platform lifecycle management.

This role requires a hands-on technical leader who can mentor teams, collaborate with stakeholders, and enable scalable, secure, and reliable deployment strategies across enterprise environments.

Key Responsibilities

Lead and manage the end-to-end DevOps infrastructure and platform lifecycle.
Design and implement scalable DevOps architectures for Azure PaaS and AKS/Kubernetes environments.
Develop and maintain CI/CD pipelines using Azure DevOps, Jenkins, GitHub, and GitLab.
Build and manage Infrastructure as Code (IaC) solutions using Terraform, ARM Templates, and Ansible.
Automate deployment, monitoring, configuration management, and operational processes.
Define and implement deployment strategies to ensure seamless software releases across multiple environments.
Collaborate with development, infrastructure, and security teams to improve delivery efficiency and platform reliability.
Troubleshoot complex customer and production issues and provide timely resolutions.
Create operational documentation, runbooks, playbooks, and automation tools to improve customer experience and operational excellence.
Mentor and train junior engineers, fostering DevOps best practices and continuous improvement.
Drive platform modernization initiatives and cloud adoption strategies.

Required Skills & Experience

Technical Skills

Strong experience working in Agile and fast-paced DevOps environments.
Expertise in Azure Cloud Platform, including Azure PaaS services and Azure Kubernetes Service (AKS).
Hands-on experience with Azure DevOps, Azure Repos, Jenkins, Git, GitHub, and GitLab.
Experience migrating and managing source code repositories across platforms.
Strong knowledge of Infrastructure as Code (IaC) using Terraform, ARM Templates, and Ansible.
Experience with Docker containers and Kubernetes orchestration.
Strong scripting and automation skills using Bash, PowerShell, and Python.
Experience in platform lifecycle management, deployment automation, and release management.
Familiarity with source control systems, debugging tools, testing frameworks, and open-source DevOps ecosystems.
Understanding of application environments supporting Microsoft and Java technology stacks.

Leadership & Soft Skills

Proven experience leading DevOps teams and large-scale cloud transformation initiatives.
Excellent stakeholder management and communication skills.
Strong problem-solving and troubleshooting capabilities.
Ability to mentor team members and drive continuous learning.
Customer-focused mindset with experience supporting enterprise environments.

Preferred Qualifications

Azure DevOps Engineer Expert Certification or equivalent.
Microsoft Azure Certifications.
Kubernetes Certifications (CKA/CKAD) desirable.
Experience with cloud governance, security, and compliance frameworks.

Tools & Technologies

Cloud & Containers: Azure, Azure PaaS, AKS, Docker, Kubernetes

CI/CD & Source Control: Azure DevOps, Azure Repos, Jenkins, Git, GitHub, GitLab

Infrastructure as Code: Terraform, ARM Templates, Ansible

Scripting: Bash, PowerShell, Python

If you are passionate about cloud automation, DevOps transformation, and leading high-performing engineering teams, we'd love to hear from you.
