Job Requirements

Senior DevOps Engineer

Location: PCS CA, Toronto

Years of Experience: 5-7 Years

Job Summary: We are seeking a Senior DevOps Engineer to design, implement, and manage scalable CI/CD pipelines, cloud infrastructure, automation frameworks, and release processes. The ideal candidate will have strong experience in Azure cloud, Infrastructure as Code (IaC), containerization, monitoring, and DevSecOps practices. This role requires close collaboration with development, QA, infrastructure, and security teams to ensure reliable, secure, and efficient software delivery.

Responsibilities


Design, build, and maintain end-to-end CI/CD pipelines for application and data platform deployments.
Automate infrastructure provisioning using Infrastructure as Code (Terraform, ARM/Bicep, or similar).
Manage Azure cloud resources, networking, storage, compute, and security configurations.
Deploy and manage containerized applications using Docker and Kubernetes (AKS).
Implement release management strategies, deployment automation, and rollback mechanisms.
Configure monitoring, logging, alerting, and performance dashboards using Azure Monitor, Application Insights, Grafana, or Prometheus.
Implement DevSecOps practices, including vulnerability scanning, secrets management, and policy enforcement.


Mandatory Skills


Azure DevOps (Repos, Pipelines, Artifacts) - Expert
Git/GitHub - Expert
CI/CD Pipeline Design and Automation - Regular


Preferred Skills


Experience with Infrastructure as Code tools such as Terraform or ARM/Bicep.
Familiarity with container orchestration platforms like Kubernetes.
Knowledge of monitoring tools such as Grafana or Prometheus.


Qualifications


Bachelor's degree in Computer Science, Information Technology, or related field.
7+ years of experience in DevOps or related roles.
