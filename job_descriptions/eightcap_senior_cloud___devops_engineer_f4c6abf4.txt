Eightcap operates at the intersection of cutting-edge technology and global financial markets. Headquartered in Melbourne with a global footprint spanning the UK, Cyprus, and Bulgaria, we build the high-performance infrastructure that connects the world to CFD markets - reliably, securely and with precision.




We're after an engineer who treats infrastructure as software: versioned, reviewed, tested and released. Someone who is as comfortable reviewing a Terraform pull request as they are tracing a production latency spike, and who leaves every codebase, pipeline and security posture better than they found it. The Senior Cloud / DevOps Engineer will own the health, security and evolution of the AWS estate that our trading services, client-facing applications and internal systems run on.




To drive real impact in this role, you will:

Own the Cloud Platform: Design, build and operate our multi-account AWS environments, with Terraform as the backbone for every change, from modules to drift detection to plan-and-review.
Build the Paved Road: Own CI/CD in GitHub Actions and build boilerplates for .NET, Go and Python so teams can ship standardised, production-ready environments with minimal friction.
Engineer Security In: Apply least-privilege IAM, secrets management, network controls and CSPM tooling like Wiz, and embed scanning and policy-as-code directly into pipelines.
Automate Compliance: Build continuous evidence and controls against SOC 2, ISO 27001 and the AWS Well-Architected Framework, so audit readiness is always on, not a scramble.
Own Observability and Reliability: Run the CloudWatch stack, define SLOs, lead incident response and post-incident reviews, and keep runbooks sharp enough for another engineer to follow.
Lead Without the Title: Set platform standards, review infrastructure and pipeline changes from other engineers, mentor the team on cloud and security practice and help shape the roadmap.
Partner Across the Business: Work closely with Infrastructure and Security, Product Engineering squads and Trading Platform Operations to keep the estate secure, resilient and easy to build on.




What You'll Bring:

Significant hands-on experience designing, building and operating production AWS workloads, including multi-account setups, VPC networking, IAM, EC2, Lambda, Fargate, RDS and CloudWatch.
Expert-level Terraform, including authoring reusable modules, managing remote state and refactoring live infrastructure without downtime.
Strong GitHub Actions experience across application and infrastructure pipelines, with secure credential handling.
A genuine software engineering background in at least one general-purpose language (Python, Go, TypeScript or C#), with tests, code review and release discipline as habit.
Demonstrable cloud security engineering, including least-privilege IAM, RBAC, SSO, MFA, secrets management and remediation using CSPM tooling such as Wiz.
Experience automating compliance evidence against ISO 27001, SOC 2 and the AWS Well-Architected Framework.
A track record leading incidents and post-incident reviews under real change control.
Clear communication skills, including writing design docs and explaining trade-offs to technical and non-technical stakeholders.
Availability for an on-call rotation and occasional out-of-hours maintenance.
Bonus if you hold an AWS Professional or Security certification, have worked in a regulated financial services environment (ASIC, FCA or CySEC), have exposure to trading platforms, low-latency systems or market data, or have contributed to a pen test remediation or certification cycle.
