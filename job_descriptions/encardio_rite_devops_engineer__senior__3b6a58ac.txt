Qualifications


5–8 years of professional experience in DevOps, platform engineering, or infrastructure with a strong software development focus.
Strong Python programming skills — you write clean, tested, reviewable code, not just one-off scripts.
Hands-on Terraform experience: module authoring, monorepo patterns, remote state (S3), and code review discipline.
Helm chart authoring from scratch — templating, schema validation, values design, and release management.
Deep GitHub Actions experience: custom actions, reusable workflows, composite actions, and secrets management.
Production Kubernetes/EKS experience: deployments, RBAC, networking, debugging, and Helm-based release management.
Crossplane for Kubernetes-native cloud resource provisioning.
ArgoCD and Argo Workflows for GitOps delivery and pipeline orchestration.
Solid understanding of Docker and container image best practices.
