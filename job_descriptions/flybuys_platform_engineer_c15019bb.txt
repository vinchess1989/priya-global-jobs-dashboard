Your Role

The Cloud Platform Engineer builds, operates and continuously improves secure, reliable and cost-effective cloud platforms that enable Flybuys teams to deliver services safely and efficiently.

The role uses automation, infrastructure as code and reusable platform capabilities to improve developer experience, strengthen observability and resilience, reduce operational and security risk, and support reliable delivery across AWS environments.


Build and improve secure, scalable and reusable AWS platform capabilities using infrastructure as code and automated delivery practices.
Operate and enhance cloud infrastructure, container platforms, application hosting services and supporting tooling.
Improve reliability through observability, service-level objectives, resilience patterns, disaster recovery and effective incident response.
Identify and remediate cloud security risks, vulnerabilities and compliance gaps in partnership with security and application teams.
Optimise cloud costs and capacity through sound architecture, lifecycle management, tagging and usage insights.
Maintain secure CI/CD pipelines, runners and deployment workflows that support safe progression to production.
Create internal tools, standards and reusable patterns that improve developer experience and reduce manual effort.
Coach application teams in AWS operational excellence and support adoption of platform standards.
Use approved AI-assisted engineering tools responsibly to improve platform delivery and operations.
Participate in the on-call roster and contribute to incident reviews and lasting corrective actions.


Your Experience


Strong understanding of AWS cloud services and best practices across automation, operations, security, resilience and cost optimisation.
Knowledge of AWS services including CloudFront, EC2, S3, ECS, EKS, RDS, SNS, SQS, Lambda and Step Functions.
Strong understanding of infrastructure as code using AWS CloudFormation, with a focus on AWS CDK.
Understanding of container operations and security, CI/CD, Git-based workflows, and monitoring and observability practices using Datadog.
Able to design, build and support AWS infrastructure and platform services using AWS CDK and CloudFormation.
Proficient in at least one programming language such as TypeScript, Python, Go or Java.
Able to build and maintain GitLab CI pipelines, runners, cloud infrastructure pipelines, automation and release processes.
Skilled in troubleshooting production issues and using Datadog logs, metrics, traces, dashboards and monitors to improve visibility, performance and reliability.
Able to remediate security risks and communicate clearly across application, security and engineering teams.
A minimum of 5 years’ experience in cloud, platform, DevOps or a similar engineering role, including strong hands-on experience managing AWS production environments.
Experience building cloud infrastructure using AWS CDK and CloudFormation.
Practical experience with Docker, ECS or EKS and applying operational and security best practices.
Hands-on experience implementing and operating observability capabilities using Datadog or a comparable enterprise observability platform. Experience working in complex, cross-functional
Agile teams and building automation, internal tools, infrastructure pipelines and release processes.
A tertiary qualification in Information Technology, Computer Science or a related discipline, or equivalent relevant industry experience.
AWS certification such as AWS Certified Solutions Architect – Associate or AWS Certified DevOps Engineer – Professional is desirable.
