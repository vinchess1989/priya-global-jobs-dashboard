Core Responsibilities


CI/CD Pipeline Management: Build, maintain, and update continuous integration and continuous deployment pipelines (using tools like Jenkins, GitLab CI, or GitHub Actions) to automate code testing and deployment.
Infrastructure as Code (IaC): Provision, scale, and manage cloud or hybrid environments programmatically using tools like Terraform, Ansible, Chef, or Puppet.
Cloud & Server Administration: Manage virtual machines, cloud services (AWS, Azure, GCP), networking configurations (DNS, load balancers, firewalls), and user permissions.
Containerization & Orchestration: Package and scale applications using Docker and Kubernetes or OpenShift.
Monitoring & Observability: Track system health, application performance, and logs using tools like Prometheus, Grafana, ELK Stack, or Splunk to spot bottlenecks early.
Incident Response & Troubleshooting: Debug live production issues, handle quick rollbacks, and minimize downtime or service outages.
Security & Compliance (DevSecOps): Integrate automated vulnerability scans, security policies, and patch management into the pipeline.
Cross-Functional Collaboration: Work directly with developers, QA testers, and IT operations to align on release requirements and best practices.


Key Skills Needed


Scripting & Coding: Proficiency in Python, Bash, or PowerShell for writing automation scripts.
Operating Systems: Strong command of Linux/Unix system administration.
Cloud Platforms: Hands-on experience with AWS, Microsoft Azure, or Google Cloud Platform.


Soft Skills: Problem-solving under pressure, communication, and team alignment
