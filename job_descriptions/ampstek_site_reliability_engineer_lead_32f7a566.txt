Role: Site Reliability Engineering (SRE) Lead

Location: Perth

Contract: 12+ Months and Extendable




We are currently looking for candidates with expertise in the following areas:

Site Reliability Engineering (SRE)

Kubernetes

CI/CD

Monitoring & Observability

Application & Container Security




Project objective

• Be the Team Lead (15Yrs+) for Client Site Reliability Engineering (SRE) capability portfolio.

• Develop backlogs and roadmaps for improving the SRE capability for different application teams

• Work with different Application Development teams in supporting their needs across Kubernetes, CI/CD, Monitoring & Observability and Application & Container Security.

• Lead and coordinate incident response for any work requiring Kubernetes investigation.




In-scope/ Solution

• Coordinating work delivery. releases and run standup meetings.

• Continuous improvement & upgrades on Kubernetes Platform and its enabling applications for other Application Development teams.

• Setting up monitoring tooling and supporting Application Development teams in setting up their monitoring and observability needs.

• Enabling security best practices on Kubernetes, Containers, and other Applications, working with Cyber on Governance and Standards.




Job Description

Provide technical leadership, establish SRE/observability standards, mentor engineers and collaborate with application, cloud, architecture and security teams.

Lead production incident management, troubleshooting, RCA and problem management, driving improvements in availability, performance, resilience and MTTR.

Design, operate and optimize highly available, scalable and secure Azure Kubernetes Service (AKS) environments, including upgrades and troubleshooting.

Implement GitOps using Argo CD, Helm and Git, enabling automated, controlled deployments and configuration management.

Build and manage CI/CD pipelines using Azure DevOps/GitHub Actions, incorporating Infrastructure as Code with Terraform/Bicep and automation.

Establish end-to-end monitoring and observability using Prometheus, Grafana, Azure Monitor and OpenTelemetry, including dashboards & alerts.

Embed DevSecOps and SecOps practices, container security, secrets management, RBAC, security controls and automated security checks within CI/CD pipelines.
