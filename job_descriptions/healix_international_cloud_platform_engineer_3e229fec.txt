Job Description

Location: Healix Group, Ground Floor, Brookside Office Park, 11 Imam Haron Rd

Cloud Platform Engineer

Shape the future of cloud at Healix

We're looking for a Cloud Platform Engineer to help design, build and support secure, scalable cloud infrastructure across our Azure and AWS environments. This is an exciting opportunity to play a key role in Healix's cloud adoption and platform modernisation journey, delivering resilient, automated and compliant cloud services that support critical business operations.

What We're Looking For


Experience managing enterprise infrastructure and delivering cloud-first solutions
Strong knowledge of Azure and/or AWS, Infrastructure as Code and CI/CD pipelines
Hands-on experience with technologies such as Terraform, Docker, Kubernetes, PowerShell, Python, GitHub and Linux/Windows Server
Strong troubleshooting, operational support and problem-solving skills
Understanding of cloud security, disaster recovery and compliance requirements
Excellent communication skills with the ability to engage both technical and non-technical stakeholders


Desirable Qualifications


Degree in Computer Science or a related discipline
Azure and/or AWS certifications
Infrastructure as Code and/or containerisation certifications


Why Healix?

At Healix, Our Values Guide Everything We Do. We


Put People First by prioritising care and wellbeing
Think Independently through expertise, analysis and sound judgement
Earn Trust by acting with integrity, transparency and reliability


If you're passionate about cloud technologies, automation and building robust platforms that make a real impact, we'd love to hear from you.

About The Role

What you'll be doing


Building and managing cloud infrastructure across Azure and AWS
Developing and maintaining Infrastructure as Code (Terraform) and automated deployment pipelines
Designing resilient, highly available cloud architectures
Implementing CI/CD practices using GitHub and modern automation tools
Monitoring, troubleshooting and optimising cloud platforms for performance, security and cost efficiency
Supporting infrastructure projects including migrations, upgrades and new deployments
Working closely with development, security and wider IT teams to deliver cloud capabilities
Driving best practice in cloud engineering, automation, security and operational excellence


Required Criteria


Proven cloud infrastructure experience – hands‑on delivery and operation of scalable platforms in Azure and/or AWS
Infrastructure as Code & automation expertise – strong experience with Terraform, CI/CD pipelines, and repeatable environments
Operational engineering capability – confident troubleshooting across networking, identity, compute, storage, and platform services
Security‑first mindset – experience building and operating compliant, resilient, and well‑governed cloud infrastructure


Desired Criteria


Containerisation & platform tooling exposure – Docker, Kubernetes, and modern deployment tooling
Broad infrastructure background – experience modernising on‑prem environments to cloud‑native architectures
Cloud certifications – Azure and/or AWS administration, IaC or containerisation accreditation
