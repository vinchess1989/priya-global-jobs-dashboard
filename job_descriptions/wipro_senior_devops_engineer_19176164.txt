Dean Simon
Dean Simon

Wipro’s dynamic approach to people, process and technology has established us as an industry leader. We help enterprises accelerate transformation through modern cloud engineering, automation and secure DevOps solutions.




We are looking for an experienced Senior DevOps Engineer to design, build and maintain secure, scalable enterprise DevOps platforms on AWS. You will combine hands-on engineering with technical leadership across GitHub Enterprise, CI/CD, GitOps, Infrastructure as Code and cloud-native technologies.




Location: London or Norwich

Working Model: Hybrid




Key Responsibilities

Design, build and maintain large-scale GitHub Enterprise implementations.
Develop highly effective CI pipelines using GitHub Actions.
Implement GitOps continuous delivery using tools such as Flux CD or Argo CD.
Build and manage AWS infrastructure using Terraform and AWS CDK.
Engineer containerised solutions using Amazon ECS and EKS.
Build solutions using AWS Lambda, API Gateway, EventBridge, SNS and SQS.
Drive secure-by-design engineering, automated testing, monitoring and observability.
Optimise production environments for performance, resilience and cost.
Provide technical leadership and manage technical risks across engineering, security, operations and product teams.




What We’re Looking For

Strong hands-on DevOps engineering and technical leadership experience.
Extensive experience with GitHub Enterprise and GitHub Actions.
Strong knowledge of CI/CD and GitOps, including Flux CD and/or Argo CD.
Hands-on AWS cloud engineering expertise.
Strong experience with Terraform and AWS CDK.
Essential experience with Amazon ECS/EKS and containerisation.
Strong Bash, Python or similar scripting/programming skills.
Experience with AWS serverless and event-driven services.
Strong understanding of enterprise security, DevSecOps and vulnerability management.
Excellent technical communication, stakeholder engagement and team leadership skills.




Key Technologies

AWS | GitHub Enterprise | GitHub Actions | GitOps | Argo CD | Flux CD | Terraform | AWS CDK | ECS | EKS | Lambda | API Gateway | EventBridge | SNS | SQS | Python | Bash | DevSecOps | CI/CD




Inclusion
