Job Description

Performs quality assurance checks for applications developed in house, packaged, or third-party hosted, using a variety of manual and automated tools. Develops and implements quality assurance, problem reporting processes and systems. OML roles mapped to this profile are: Senior Quality Engineer, Technical Lead: Quality

Engineering, Technical Lead: Quality Engineering (Automation) and Technical Test Manager.

Key Responsibilities


Test Framework Architecture: Design, develop, and maintain scalable automated UI and API test suites using Playwright (TypeScript/JavaScript) for mission-critical insurance and financial workflows (e.g., quotes, policy underwriting, claims processing, payments, and customer onboarding).
Audit-Ready Test Management & Reporting: Manage test plans, test cases, test executions, and defect tracking in Jira Xray, ensuring strict bidirectional traceability between business or regulatory requirements and test evidence. Configure automated test results (JUnit/JSON reports) to sync back to Xray via REST API or CI/CD plugins.
CI/CD Integration & Release Gates: Embed automated test suites into CI/CD pipelines (e.g., GitHub Actions, GitLab CI, Jenkins) to serve as automated quality gates on pull requests, nightly regression runs, and pre-production releases.
Test Data Security & Masking: Implement secure test data management practices using synthetic or anonymized datasets, ensuring strict compliance with data privacy standards (e.g., POPIA, GDPR) and preventing sensitive customer PII from leaking into logs, traces, or test environments.
Cross-Functional Collaboration: Participate in sprint planning, backlog refinement, and architecture reviews to identify edge cases—such as premium calculation logic, multi-step approval workflows, and third-party payment or credit bureau integrations—early in the delivery lifecycle.
Failure Triage & Reliability: Investigate test failures, distinguish between genuine product defects, environment instability, and flaky tests, and maintain high suite reliability using Playwright’s trace viewer, video recordings, and network interception (page.route).


Required Qualifications


Experience: 3+ years of hands-on experience as a Test Automation Engineer or in software quality automation, ideally within financial services, insurance, fintech, or other regulated industries.
Playwright Mastery: Proven experience building and scaling test frameworks in Playwright using TypeScript or JavaScript, including Page Object Model (POM) design, custom fixtures, storageState authentication handling, parallel execution, and network mocking.
Xray & Jira Expertise: Practical experience managing auditable test lifecycles in Xray for Jira, including linking requirements/user stories to test executions, managing test sets/plans, and automating result imports.
API, Integration & Data Validation: Strong experience testing RESTful and/or GraphQL APIs (using Playwright’s APIRequestContext, Postman, or similar tools) alongside SQL/database validation to verify financial calculations, ledger entries, and policy state transitions.
Security & Compliance Awareness: Solid understanding of authentication and authorization flows (OAuth2, OIDC, MFA), session security, and handling sensitive financial or personal data safely within test automation pipelines.
CI/CD & Version Control: Strong command of Git workflows and configuring automated test runs in modern CI/CD environments.


Preferred Qualifications


Domain familiarity with life insurance, wealth management, claims lifecycles, or adviser/broker digital portals.
Experience testing integrations with legacy core banking or policy systems, payment gateways, or third-party verification services.
Experience with performance or load testing tools (e.g., k6, JMeter) for high-volume transaction periods.
Familiarity with Docker, containerized test execution, and cloud platforms (AWS, Azure, or GCP).
ISTQB Foundation Level or Agile Tester certification.
Expertise in programming languages like Java, JavaScript or Python.
Experience in creating test automation frameworks at both a frontend and backend layer.
Strong expertise in SQL and test data management
Mastery of performance testing tools like Apache JMeter or LoadRunner and analysing system performance
Proficiency in security testing tools like OWASP ZAP or Burp Suite.
Extensive experience in CI/CD pipelines using Jenkins, GitLab CI, ADO, or similar.
In-depth understanding of DevOps practices and tools, including containerisation and orchestration with tools like Docker and Kubernetes.
Experience in working with cloud technologies like AWS, Azure or Google Cloud.
