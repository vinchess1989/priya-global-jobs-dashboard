ABOUT THE POSITION

Build it. Automate it. Secure it. Scale it.


Are you passionate about cloud technology, automation and building platforms that just work? Do you enjoy solving complex technical challenges, improving performance and making sure applications are always ready for business?


We're looking for a talented Platform Engineer to take ownership of our cloud platforms and DevOps environment, helping development teams deliver applications faster, smarter and more reliably.


This is an opportunity to work across AWS and Microsoft Azure, build scalable cloud infrastructure, automate deployments and ensure that business-critical platforms remain secure, stable and high-performing.




RequirementsEssential Skills:


5 - 8 years’ experience in infrastructure, cloud, or platform engineering.

3+ years’ hands-on experience running production workloads on AWS and/or Azure.

3+ years’ experience building and operating CI/CD pipelines and Infrastructure as Code.

Proven experience designing and operating highly scalable, high-availability platforms that handle significant traffic peaks (for example e-commerce, high-volume transactional, or mobile platforms).

Experience managing cloud tenant configuration and security posture using Microsoft Secure Score, Microsoft Defender for Cloud, and AWS Security Hub or equivalent tools.

Experience designing and operating hybrid and multi-cloud network connectivity: site-to-site IPsec VPN, BGP routing, and cloud network architecture (VPC / VNet, transit, and peering).

Experience operating Linux workloads and Odoo or a similar ERP (advantageous).

3+ years’ hands-on PostgreSQL operations on Amazon RDS or a similar managed service: SQL-based performance diagnosis, log analysis, tuning, backups and upgrades (operational database administration, not data engineering).

3+ years’ hands-on experience with observability tooling in production: Amazon CloudWatch, Azure Monitor and Application Insights, and New Relic (or an equivalent such as Datadog or Dynatrace), including instrumentation, alerting, dashboards, and query languages (NRQL, CloudWatch Logs Insights, KQL).

Experience working with external development partners and managed service providers.

Experience participating in an on-call or standby rotation.

Qualifications:

National Senior Certificate (Grade 12).

Degree or Diploma in Information Technology, Computer Science, or a related field (preferred)

AWS Certified Cloud Practitioner
