The Release Manager oversees and executes release management activities to ensure successful, seamless code deployments across all lower and production environments. This is a hands-on role requiring a technical expert who will maintain robust CI/CD pipelines while actively collaborating with multiple teams to deliver artifacts on time. By enforcing established SDLC release processes, troubleshooting deployment failures, and managing clear client communications, you will ensure high-quality software delivery and operational stability.

Requirements

Key Responsibilities


Manage Deployments: Coordinate and execute end-to-end release management activities to ensure successful code deployment across lower and production environments
Pipeline Engineering: Maintain automated CI/CD pipelines to streamline deployment workflows, optimize delivery speed, and reduce manual errors
Process Enforcement: Enforce established SDLC release processes, governance models, and deployment protocols across all internal teams and client stakeholders
Cross-Team Liaison: Partner actively with multiple development, engineering, and product teams to track dependencies and ensure all release artifacts are delivered on time
Troubleshoot Failures: Diagnose and troubleshoot complex CI/CD pipeline and deployment failures rapidly, recommending and implementing permanent technical fixes
Client Communication: Serve as a primary point of contact for clients, providing clear, transparent updates regarding release schedules, risks, and deployment statuses. Required Qualifications
CI/CD Expertise: Proven, hands-on experience building, scaling, and maintaining continuous integration and continuous deployment pipelines using GitLab and GitHub
Data Stack Familiarity: Hands-on experience managing and executing code deployments specifically for Snowflake, Apache Airflow, and DBT
SDLC Knowledge: Deep understanding of the standard Software Development Life Cycle (SDLC) and release management methodologies
Communication Skills: Exceptional verbal and written communication skills, with a proven track record of successful client-facing communication and stakeholder management
Problem Solving: Strong technical troubleshooting skills with the ability to isolate infrastructure, pipeline, or code configuration failures under tight release deadlines. Preferred Qualifications
Experience working within cloud data warehouse environments or data engineering release tracks
Certification in GitLab, GitHub Actions, or relevant cloud/DevOps practices
Experience managing releases in multi-tenant or complex enterprise client ecosystems
