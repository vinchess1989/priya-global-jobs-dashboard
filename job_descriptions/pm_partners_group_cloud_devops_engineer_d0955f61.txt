PM-Partners group is a specialist Project Management Consultancy. We have a unique way of running projects and providing training and advice, so our clients get the best results with less cost and risk. Each year we deliver over $3B of projects, train over 10,000 people, and help some of Australia’s leading brands improve their PMOs.

The Opportunity

A leading Australian bank is seeking an experienced Cloud DevOps Engineer with strong Amazon Web Services (AWS) expertise to support the development, automation and optimisation of its cloud infrastructure and deployment processes.

Working closely with engineering, architecture and security teams, you will help build and maintain secure, scalable and reliable AWS environments, improve CI/CD pipelines and drive automation across cloud infrastructure and software delivery.

Key Responsibilities

Design, implement and maintain secure, scalable and resilient cloud infrastructure within AWS.
Develop, manage and optimise CI/CD pipelines to automate build, testing and deployment processes.
Implement Infrastructure as Code (IaC) using Terraform, AWS CloudFormation or similar tools.
Automate infrastructure provisioning, configuration management and operational processes.
Monitor cloud environments, troubleshoot issues and optimise performance, availability and costs.
Embed security, governance and compliance controls into cloud infrastructure and deployment workflows.
Collaborate with developers, architects and security teams to improve engineering practices and delivery outcomes.
Support containerisation and orchestration technologies, including Docker and Kubernetes, particularly Amazon EKS.
Drive continuous improvement across cloud operations, DevOps tooling and platform reliability.

Key Skills and Experience

Proven experience in a Cloud DevOps Engineer, AWS Engineer or Platform Engineering role.
Strong hands-on experience with AWS and its core cloud infrastructure services.
Experience with CI/CD pipelines, including AWS CodePipeline, CodeBuild, GitHub Actions, Jenkins or similar tools.
Strong Infrastructure as Code experience using Terraform, CloudFormation or similar technologies.
Scripting and automation skills using Python, Bash or similar languages.
Experience with Git-based version control and automated deployment practices.
Understanding of AWS networking, IAM, security, monitoring and cloud architecture.
Exposure to Docker, Kubernetes and Amazon Elastic Kubernetes Service (EKS).
Strong troubleshooting and problem-solving skills, with the ability to work across technical teams.

Desirable Experience

Experience working within banking, financial services or another regulated environment.
Knowledge of AWS security, governance and compliance requirements.
Exposure to monitoring and observability tools such as Amazon CloudWatch, Splunk, Datadog or Prometheus.
Experience supporting enterprise-scale AWS environments and production workloads.
AWS certifications such as Solutions Architect, SysOps Administrator or DevOps Engineer.
