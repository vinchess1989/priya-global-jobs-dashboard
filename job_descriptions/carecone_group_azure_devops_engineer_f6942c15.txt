Role- Azure DevOps Engineer
Type- Permanent
Location - Sydney
Key Responsibilities

Support application and infrastructure deployments across all environments.
Manage and troubleshoot CI/CD pipelines and release activities.
Perform environment validation, deployment verification, and production support.
Support integration connectivity, certificates, authentication, and infrastructure related issues.
Support SQL Server instance and database provisioning, commissioning, configuration, and decommissioning in collaboration with DBA and infrastructure teams.
Manage SQL Server logins, database users, roles, and permissions in accordance with least privilege principles and access approval processes.
Support database deployments, SQL Server Agent jobs, backup and restore activities, and database connectivity and performance troubleshooting.
Execute DR, rollback, and change management activities, including database recovery validation.
Maintain operational documentation, runbooks, and deployment procedures.
Collaborate with Agile teams to deliver project and release commitments.
Mandatory Skills

Strong troubleshooting and problem solving skills.
On premises infrastructure support experience: Windows Server, IIS, networking, and certificates.
PowerShell and Shell scripting.
Jenkins and Azure DevOps CI/CD pipelines.
Chef cookbook and deployment troubleshooting.
Working knowledge of Microsoft SQL Server administration and SQL Server Management Studio (SSMS), including:
Server and database provisioning, commissioning, and configuration.
Windows and SQL authentication, logins, users, roles, and permission management.
Backup and restore procedures, SQL Server Agent jobs, and operational health checks.
T SQL scripting and troubleshooting database connectivity, blocking, and failed jobs.
ServiceNow: Incident, Change, and Release Management.
Jira and Agile/Scrum delivery.
Bitbucket: branching, PRs, and repository management.
Good to Have

GitHub Actions workflow development and support.
IBM MQ, API integrations, and connectivity troubleshooting.
Monitoring tools such as AppDynamics, Splunk, Elastic, or Grafana.
SQL Server Always On availability groups, failover clustering, and DR testing.
Database deployment automation using Liquibase, Flyway, or equivalent tools.
SQL Server performance diagnostics, including execution plans, indexing, and query tuning.
Banking or financial services experience.
