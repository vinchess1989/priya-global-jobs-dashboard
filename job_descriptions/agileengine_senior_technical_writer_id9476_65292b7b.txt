We are looking for a Senior Technical Writer to design and automate AI-driven software documentation for end users, developers, and system integrators.

The mandatory requirements are 4+ years of technical writing experience, prompt engineering and AI tools, technical knowledge of APIs and systems, and proficiency with Git, YAML, or Markdown.

RECRUITMENT PROCESS


Application — Share a few details about your experience and background.
Coding Challenge — If applicable, complete it in the coding language you are most comfortable with.
Video Interview — Record a short video introduction in English.
Technical Interview or Hiring Manager Interview — Discuss your experience and fit for the role.
Offer — If it’s a match, you’ll receive an offer.


What You’ll Gain


Remote work — Work from where you feel most productive.
Local presence in India — Work in a structured and compliant environment aligned with Indian regulations.
Competitive compensation in INR — Receive compensation in INR, plus support for learning, education, and wellness.
Exciting projects — Work with modern technologies for global clients and fast-growing companies.


MUST HAVES


4+ years of technical writing experience, with demonstrated expertise in software documentation (SaaS, cloud platforms, or developer-focused content).
Deep familiarity with prompt engineering and ability to design effective prompts, configure AI tools, and iterate based on output quality to achieve consistent documentation.
Strong understanding of documentation architecture and information design. Ability to analyze different documentation types and design patterns that scale.
Technical comfort with APIs, event streaming, batch processing, system architecture, and data models. Ability to understand complex concepts and write documentation that captures them accurately.
Proficiency with Markdown, YAML, Git, and version-controlled workflows. Comfortable in code editors and command-line environments.
Strong written and verbal communication skills, with an ability to write clear, user-centered documentation and communicate technical concepts to diverse audiences.
Attention to detail and excellent organizational skills with the ability to manage multiple priorities and maintain consistency across documentation systems.
Problem-solving mindset with ability to think critically about processes and advocate for improvements to documentation systems and workflows.
Experience in fast-paced, cross-functional product environments with the ability to adapt to changing priorities.
Bachelor's degree in computer science, English, or a related field, or equivalent work experience.
Upper-intermediate English level.


NICE TO HAVES


Loyalty product, MarTech, or B2B SaaS experience preferred.
Redocly documentation framework for API references.


What You Will Do


Partner with product, engineering, and operations teams to understand documentation needs and user workflows, then design documentation architecture and automation patterns that serve multiple audiences – end users, developers, and system integrators.
Establish documentation standards and build governance and quality gates directly into the automation system to ensure generated documentation maintains consistency and user value.
Build and refine prompt templates, style guides, and content models that enable developers and writers to generate consistent, high-quality documentation at scale.
Write, edit, and review documentation to model excellence, validate automation output quality, and identify patterns that strengthen prompts and templates.
Measure documentation impact using analytics and user feedback to identify gaps and inform improvements to the automation system, content strategy, and documentation approach.
Document all systems, configurations, prompts, and decision logic thoroughly so the team can maintain, evolve, and improve the automation system independently.
