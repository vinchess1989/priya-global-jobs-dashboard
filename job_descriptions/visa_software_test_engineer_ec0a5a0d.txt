Job Description

Information security is an integral part of Visa’s corporate culture. It is essential to maintaining our position as an industry leader in electronic payments, and it is the responsibility of each employee to safeguard information, protect it from unauthorized access, and ensure regulatory compliance. Information security has a significant effect on privacy, consumer confidence, external reputation, and/or the bottom line, and it is a priority on everyone’s agenda.

The successful candidate will be part of Visa’s Business-to-Business Identity & Access Management team, which is part of the larger Cybersecurity organization. The B2B IAM team has a global focus and is responsive to an evolving threat landscape, regulatory compliance, IT security requirements, and technology architecture. The B2B IAM team is responsible for secure access to business portals and associated services.

The Software Test Engineer will support quality, security, release readiness, and platform stability for B2B IAM applications. This role requires test engineering experience, automation skills, full-stack application testing exposure, security patch validation support, release validation support, and production-like environment support experience.

Essential Functions


Support test planning, test design, execution, and automation for Java, .NET
Core, Python, and full-stack B2B IAM applications.
Develop and maintain automated tests and scripts using Selenium, Playwright, Postman/Newman, JMeter, Java, Python, or similar tools.
Perform functional, regression, integration, API, performance, smoke, sanity, and post-deployment validation testing.
Support full-stack application testing and troubleshooting across front-end, back-end, database, API, middleware, and infrastructure layers.
Support QA, staging, pre-production, and production-like environments by troubleshooting issues, validating configurations, and helping maintain stability.
Assist with security patching, vulnerability remediation, dependency upgrades, certificate renewals, middleware updates, and patch validation.
Assist with release management activities including release readiness, deployment validation, smoke testing, regression testing, release validation support, rollback support, and post-release validation.
Help improve platform stability through log analysis, defect investigation, root cause analysis, and collaboration with development, security, and operations teams.
Conduct API and performance testing using tools such as Postman, SoapUI, OpenAPI/Swagger, JMeter, LoadRunner, or similar tools.
Work with relational databases and directory services to validate data, write SQL queries, troubleshoot issues, and support IAM workflows.
Collaborate with developers, product owners, QA engineers, security engineers, operations personnel, and system engineers to support secure and stable delivery.
Ensure testing activities follow Visa Development Management Methodology, Visa Technical Security Requirements, SSDLC practices, and cybersecurity requirements.
Use CI/CD, source control, code quality, and DevOps tools such as Jenkins, GitHub, Bitbucket, Artifactory, SonarQube, Checkmarx, Docker, Kubernetes, or similar tools.
Contribute to test utilities, scripts, dashboards, and automation solutions using Java, Python, JavaScript, REST APIs, SQL, HTML5, CSS3, or similar technologies.
Support the use of generative AI, agentic tools, and AI-assisted automation to improve test generation, execution, failure analysis, release validation, and support workflows.
Participate in Agile/Scrum ceremonies and create and maintain test cases, test plans, automation scripts, execution reports, and technical documentation.


Visa requires at least 3 days in office, expectations of these days will be confirmed by your Hiring Manager.

Qualifications

Basic Qualifications:


Bachelor’s degree OR 3+ years of relevant work experience.


Preferred Qualifications


Bachelor's degree, OR 3+ years of relevant work experience
2 or more years of work experience.
Bachelor’s or master’s degree in Computer Science, Information Systems, Cybersecurity, Engineering, or a related technical field is preferred.
Experience in software quality engineering, test automation, application testing, release validation, or platform support.
Experience with Java, Python, JavaScript, SQL, shell scripting, or similar programming languages.
Experience testing Java, .NET Core, Python applications, RESTful services, microservices, and relational databases.
Experience with automation, API, and performance testing tools such as Selenium, Playwright, Postman/Newman, REST Assured, SoapUI, JMeter, LoadRunner, PyTest, JUnit, TestNG, or Cucumber.
Experience or familiarity with front-end technologies such as JavaScript, HTML5, CSS3, React, Angular, Node.js, Bootstrap, Webpack, or jQuery.
Familiarity with JBoss Web Server, Apache Tomcat, Red Hat Linux, MS SQL Server, LDAP, Active Directory, and Windows environments.
Experience or familiarity with security patching, vulnerability remediation, release validation, deployment support, platform stability, monitoring, log analysis, troubleshooting, and root cause analysis.
Basic understanding of SSDLC, cybersecurity controls, vulnerability management, application security testing, and tools such as SonarQube, Checkmarx, FindBugs, Black Duck, Veracode, or Fortify.
Familiarity with CI/CD, DevOps, source control, containerization, and Agile tools such as Jenkins, GitHub, Bitbucket, Artifactory, Docker, Kubernetes, OpenShift, Jira, Confluence, Zephyr, or similar tools.
Experience or familiarity with generative AI, prompt engineering, agentic tools, AI-assisted automation, and emerging coding/testing practices.
Strong analytical, debugging, troubleshooting, communication, collaboration, and problem-solving skills.
