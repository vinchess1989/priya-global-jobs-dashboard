Position: DevOps Engineer




Location: Singapore




Type of Employment: Full-Time




Compensation: -




Purpose of the Position: The DevOps Engineer will be responsible for designing, implementing, and maintaining scalable, secure, and reliable cloud infrastructure and CI/CD pipelines. The role focuses on enabling efficient software delivery, improving system reliability, and driving automation across the development and operations lifecycle.




Key Result Areas and Activities:

Design, implement, and manage CI/CD pipelines to support automated build, test, and deployment processes.
Provision and maintain cloud infrastructure (e.g., AWS) using Infrastructure as Code (IaC) tools such as Terraform.
Monitor system performance, availability, and reliability using tools such as CloudWatch, Prometheus, or Grafana, and proactively address issues.
Automate operational processes, including deployment, scaling, backup, and recovery procedures.
Collaborate with development teams to improve application performance, security, and deployment efficiency.
Manage containerized applications using Docker and orchestration tools such as Kubernetes.
Implement security best practices, including access control, vulnerability management, and compliance requirements.
Troubleshoot and resolve infrastructure and application-related issues in a timely manner.
Maintain documentation for infrastructure, processes, and system configurations.




Essential Skills:

Strong experience with cloud platforms such as AWS
Proficiency in CI/CD tools (e.g., GitLab CI/CD, Jenkins, GitHub Actions)
Experience with Infrastructure as Code (e.g., Terraform, CloudFormation)
Knowledge of containerization (Docker) and orchestration (Kubernetes)
Strong scripting skills in Bash, Python, or similar
Experience with monitoring and logging tools (e.g., CloudWatch, Prometheus, ELK stack)
Solid understanding of networking, security, and system architecture




Desirable Skills :

Familiarity with Agile/Scrum methodologies
Knowledge of DevSecOps practices
Experience working in government or regulated environments
Certification in cloud platforms (e.g., AWS Certified Solutions Architect, Azure Administrator)




Qualities:

Strong problem-solving and analytical thinking skills
Proactive and ownership-driven mindset
Ability to work independently and in cross-functional teams
Good communication skills to bridge technical and non-technical stakeholders
Adaptable and able to thrive in fast-paced environments
