Job Summary

We are looking for an experienced Senior DevOps Engineer with strong expertise in cloud infrastructure, Kubernetes, Docker, CI/CD automation, Infrastructure as Code, monitoring, and production troubleshooting. The candidate will be responsible for managing and optimizing cloud infrastructure, designing scalable and secure deployment solutions, implementing automation, improving system reliability, and driving DevOps best practices across development and operations teams.

Roles And Responsibilities


Design, implement, manage, and maintain scalable, highly available, and secure infrastructure across cloud platforms such as AWS, Microsoft Azure, and Google Cloud Platform (GCP).
Provision, configure, maintain, and troubleshoot infrastructure components, including virtual machines, networking, storage, load balancers, firewalls, and access management.
Develop, maintain, and optimize CI/CD pipelines for automated application builds, testing, deployments, and release management.
Deploy, manage, and troubleshoot containerized applications using Docker and Kubernetes.
Implement deployment strategies such as rolling updates, blue-green deployments, canary releases, and automated rollbacks.
Automate infrastructure provisioning and configuration management using Terraform, Infrastructure as Code tools, and shell scripting.
Configure and manage cloud networking, including VPCs or virtual networks, subnets, routing, DNS, security rules, and load balancing.
Implement monitoring, centralized logging, dashboards, and alerting solutions using Prometheus, Grafana, ELK Stack, Loki, and cloud-native monitoring tools.
Perform advanced troubleshooting and root cause analysis for production incidents involving cloud infrastructure, Kubernetes, networking, storage, applications, and CI/CD pipelines.
Implement DevSecOps practices, including vulnerability scanning, container security, secrets management, access control, and secure deployment processes.
Design and support highly available infrastructure, backup and recovery strategies, disaster recovery, and business continuity processes.
Optimize infrastructure utilization, application performance, scalability, and cloud costs.
Establish infrastructure standards, reusable automation frameworks, deployment procedures, and operational documentation.
Collaborate with development, QA, security, architecture, and infrastructure teams to improve software delivery and operational reliability.
Provide technical guidance, review infrastructure configurations and automation code, and mentor engineers on DevOps best practices.
Participate in solution design, infrastructure assessments, technical consulting, and continuous improvement initiatives.
Participate in Agile/Scrum ceremonies, including sprint planning, daily stand-ups, sprint reviews, and retrospectives.
Collaborate with development, QA, and infrastructure teams to plan and deliver DevOps tasks within sprint timelines.


Required Skills


Minimum 5+ years of experience in DevOps engineering, cloud infrastructure management, automation, and production support.
Experience with CI/CD tools (e.g., GitLab, Jenkins) and version control system (e.g., Git)
Hands-on experience with at least one major cloud platform, such as AWS, Microsoft Azure, or Google Cloud Platform (GCP).
Strong experience in Kubernetes, Docker, container orchestration, Helm, cluster administration, and troubleshooting.
Hands-on experience with Terraform or equivalent Infrastructure as Code tools.
Strong knowledge of monitoring and logging tools such as Prometheus, Grafana, ELK Stack, Loki, and cloud-native monitoring solutions.
Proficiency in Linux administration, shell scripting, networking, DNS, load balancing, and application connectivity troubleshooting.
Experience in production incident management, root cause analysis, performance optimization, and service reliability improvement.
Good understanding of cloud security, identity and access management, network security, container security, and DevSecOps practices.
Knowledge of Python or shell scripting, infrastructure cost optimization, disaster recovery planning, and high-availability architecture.
Experience with security tools such as Trivy, SonarQube, and cloud security monitoring solutions.
Strong communication, analytical, consulting, problem-solving, and technical leadership skills.
