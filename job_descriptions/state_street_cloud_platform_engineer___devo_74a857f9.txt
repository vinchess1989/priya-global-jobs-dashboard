What You Will Be Responsible For

As Cloud Platform Engineer you will:

Configure and manage the infrastructure deployments on Azure Cloud.

Design, implement and manage infrastructure as code[IaC] using terraform and Azure DevOps.

DevOps CI/CD process to deploy infrastructure/services to azure

Responsible for cloud platform build, release and delivery pipelines

Build the IaC framework from ground up applying all best practices.

Author reusable terraform modules and templates

Manage resources, using Azure Terraform modules, and automated infrastructure management.

Developing, deploying, and maintaining tools built from the ground up in support of self-service, quality, security, and compliance initiatives.

Qualifications:

Bachelor's degree in a Technical or Analytical field required, Master’s preferred.

Azure Cloud Platform Certification preferred.

Five years or more of cloud / infrastructure experience.

Demonstrated Azure deployment experience.

Deep understanding of Microsoft Azure technologies and services.

Working experience with global azure deployments.

Working experience with highly segmented networks in public and private clouds.

Working experience with Infrastructure as Code technologies in Azure.

Prior enterprise cloud architecture/design experience a huge plus.

Excellent communication, documentation and troubleshooting skills.

An innovative approach to work, constantly looking to upgrade the system to more efficient and effective new technologies and processes.

Strong analytical and troubleshooting skills.
