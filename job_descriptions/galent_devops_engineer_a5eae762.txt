Role : DevOps Engineer

Location : Halifax, NS (Hybrid)




Top 3 Skills:

CI/CD & GitHub Actions
Jenkins / Terraform / Ansible / SonarQube
Kubernetes / Docker / Maven




We are looking for a DevOps Engineer with strong experience in CI/CD, GitHub Actions, Jenkins, and cloud/container technologies to support application teams and migration initiatives.




Key Responsibilities:

Build, debug, and support CI/CD pipelines and migrate applications to GitHub Actions.
Work with Jenkins, GitHub Actions, Maven, Artifactory, SonarQube, Terraform, UCD, and Ansible.
Develop and maintain Maven POM/Settings and support NPM, PyPI, and .NET builds.
Work with Docker and Kubernetes, including deployments, Helm, Kubectl, namespaces, PV/PVC, and troubleshooting.
Automate DevOps processes using Groovy, Shell, or Python.
Collaborate with application teams to troubleshoot and resolve DevOps issues.




Must Have:

5+ years of DevOps experience with strong CI/CD expertise.
GitHub Actions & Jenkins
Maven / Terraform / Ansible / SonarQube
Docker & Kubernetes
Strong troubleshooting and communication skills.
