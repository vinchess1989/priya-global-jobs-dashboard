About Our Client

This organisation operates within the technology and telecoms industry in Singapore.

Job Description


Develop and maintain technical documentation, including user manuals, guides, and online help resources.
Collaborate with developers, engineers, and other stakeholders to gather and clarify technical information.
Translate complex technical concepts into understandable language for various audiences.
Ensure that all documentation is accurate, consistent, and adheres to established standards.
Update and revise existing documentation to reflect changes in products or processes.
Manage multiple documentation projects and meet deadlines effectively.
Incorporate user feedback to improve documentation quality and usability.
Work with visual designers to create diagrams, charts, and other visuals to complement written content.


The Successful Applicant

A Successful Technical Writer Should Have


Proven experience in creating technical documentation or similar content.
Strong written communication skills, with an ability to explain complex topics clearly.
Proficiency with documentation tools and software.
An understanding of technology and telecoms concepts and terminology.
Great attention to detail and a commitment to producing high-quality work.
Ability to collaborate effectively with technical teams and other stakeholders.
Create and maintain technical documentation: API references, developer guides, architecture overviews, and release notes
Collaborate with engineering teams to understand system design, codebases, and workflows well enough to document them accurately. Bring in consistency of the technical documents to the functional documents (such as functional specification documents/user guides)
Translate technical specifications into user-facing documentation (onboarding guides, how-tos, FAQs, user guides)
Establish and maintain documentation standards, style guides, and templates across client engagements or as per client policies or Thoughtworks policies.
Review and edit documentation contributed by engineers to ensure consistency, clarity, and accuracy
Manage documentation in tools like Confluence, GitBook, Markdown-based static site generators (e.g., MkDocs), or client-specific platforms
Leverage GitHub copilot for documentation


What's on Offer


Opportunity to document innovative cloud and digital products.
Collaborate with engineers, architects, and product leaders.
Flexible hybrid work model with a high-performing team.
