Position: Senior Azure DevOps Engineer
Experience: 5+ Years
Location: Sydney

Key Responsibilities

Design, develop, and maintain scalable DevOps platforms, automated CI/CD pipelines, and cloud infrastructure.
Manage and optimize Microsoft Azure environments for performance, scalability, security, and high availability.
Deploy, configure, and manage containerized applications using Docker, Kubernetes, and Helm.
Build, maintain, and optimize CI/CD pipelines using Jenkins and Git.
Automate infrastructure provisioning, configuration management, and deployments using Ansible and scripting technologies.

Collaborate with development, infrastructure, and security teams to enhance release efficiency, platform stability, and operational reliability.
