9-12 years of IT experience. Strong hands-on experience with AWS Cloud. Expertise in Terraform for Infrastructure as Code. Strong DevOps and CI/CD experience. Experience with Jenkins, GitHub Actions, GitLab CI/CD, Azure DevOps. Experience with Docker and Kubernetes. Linux Administration. Shell Scripting / Python. Git Version Control. Monitoring tools such as CloudWatch, Grafana, Prometheus, ELK. Strong understanding of Networking, IAM, Security, and Cloud Architecture.

Design, deploy, and maintain scalable and secure AWS cloud infrastructure. Develop and manage Infrastructure as Code (IaC) using Terraform. Build, configure, and maintain CI/CD pipelines for application and infrastructure deployments. Automate provisioning, configuration management, and deployment processes. Manage and optimize cloud environments for performance, availability, and cost efficiency. Implement containerization and orchestration solutions using Docker and Kubernetes. Configure monitoring, logging, and alerting solutions for proactive incident management. Collaborate with Development, QA, Security, and Operations teams to improve release processes. Implement security best practices, IAM policies, and cloud governance controls. Perform infrastructure troubleshooting, root cause analysis, and performance tuning. Ensure high availability, disaster recovery, backup, and business continuity solutions. Support DevSecOps initiatives and automate security checks in CI/CD pipelines. Create and maintain technical documentation, deployment procedures, and architectural diagrams. Mentor junior engineers and provide technical guidance on cloud and DevOps best practices.
