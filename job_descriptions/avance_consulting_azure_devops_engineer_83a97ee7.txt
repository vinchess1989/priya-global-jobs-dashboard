Role Overview

We are seeking an experienced Azure DevOps Engineer to design, implement, and manage cloud infrastructure, CI/CD pipelines, automation frameworks, and platform reliability solutions within Microsoft Azure environments. The ideal candidate will have strong hands-on experience with Azure DevOps, Infrastructure as Code (IaC), container platforms, and cloud-native application deployments.

The role requires close collaboration with development, QA, architecture, security, and operations teams to deliver scalable, secure, and highly available enterprise solutions.




Key Responsibilities

DevOps & CI/CD Automation

Design, build, and maintain Azure DevOps CI/CD pipelines.
Automate application build, test, deployment, and release processes.
Implement DevSecOps practices within delivery pipelines.
Support blue-green and canary deployment strategies.
Improve deployment frequency while reducing release risks.

Azure Cloud Engineering

Provision and manage Azure infrastructure using Infrastructure as Code.
Implement and support Azure Virtual Machines, Azure App Services, Azure Functions, Azure Storage, Azure SQL Database, Azure Key Vault, and Azure Kubernetes Service (AKS).
Ensure cloud environments meet security, compliance, and governance standards.

Infrastructure as Code (IaC)

Develop reusable Terraform modules and templates.
Automate infrastructure provisioning and environment management.
Manage environment consistency across Development, QA, UAT, and Production.

Containerization & Kubernetes

Deploy and manage applications using Docker containers.
Administer Kubernetes / AKS clusters.
Implement Helm Charts and deployment automation.
Troubleshoot container orchestration issues.

Monitoring & Reliability

Implement observability solutions using Azure Monitor, Application Insights, Log Analytics, Grafana, and Prometheus.
Establish proactive alerting and incident management processes.
Support production releases and platform stability.

Security & Compliance

Implement security best practices across Azure workloads.
Integrate security scanning tools into CI/CD pipelines.
Manage secrets, certificates, and access controls.
Support compliance and audit requirements.

Collaboration & Support

Work closely with developers, architects, and QA teams.
Participate in Agile ceremonies and release planning.
Provide Level 3 platform support and root cause analysis.
Drive continuous improvement initiatives.
