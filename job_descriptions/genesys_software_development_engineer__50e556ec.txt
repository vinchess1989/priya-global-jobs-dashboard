Software Development Engineer in Test (SDET), T2

“When my family and my friends ask me about the company, and what I’m doing there, I always answer with this sentence: I’m working together with the most talented people, full of empathy, highly skilled team members and peers, where we can count on each other in every case, because we know we can solve the most complex problems together, to give the best experience to our customers. And go out for some fun when we finished the day.”

– Director, Quality Assurance at Genesys

QA at Genesys is strongly connected with wall-to-wall CI/CD and test automation, and this is a fact, not a promise. We believe in total test automation over endless manual regression cycles, the right tools and integration over fragmented processes, and fly-in-formation collaboration over separated silos.

As a Software Developer in Test, you will join a collaborative global team that thrives on technical problem-solving and design challenges, working in an agile environment with the capability to deliver the full landscape of testing. Our team builds AI-driven backend services where outputs are nondeterministic and behavior spans multiple cooperating services and agents, which calls for new approaches to API validation, reliability and test automation.

We are looking for an enthusiastic Software Test Engineer to be a key participant in creating a Quality First culture. You will develop, troubleshoot, test and debug software components and test automation projects of moderate scope and complexity, share responsibility for planning and implementation with the team, and take on increasing responsibility as a solid technical contributor.

Minimum qualifications:


3+ years of hands-on experience developing and executing automated test scripts with Java and/or TypeScript (e.g. REST Assured, Selenium WebDriver, Playwright)
3+ years of experience in QA in an agile software organization
Solid understanding of REST APIs, HTTP, JSON and authentication concepts (OAuth/JWT), with hands-on API test automation experience
Knowledge of professional software engineering practices and best practices for the full software development life cycle
Experience with GitHub, Jira, and running automated tests in CI/CD pipelines (e.g. Jenkins)


Preferred qualifications:


Experience with SQL databases, scripting languages and cloud technology (AWS)
Experience with microservices, contract testing, and asynchronous or event-driven systems (e.g. messaging/event streams, gRPC, GraphQL)
Experience debugging with logs, traces and metrics using observability tools
Interest in or initial exposure to AI in testing (nondeterministic testing, LLM output evaluation, AI skills and agents)


What you will do:


Work with development and program management teams to define, develop and execute test cases that validate and harden our software and its components.
Ensure overall software functionality remains intact as new features are implemented.
Build and maintain automated API, integration and contract tests for backend services, including asynchronous flows, and integrate them into CI/CD pipelines.
Investigate test failures and production issues in backend components, and help find root causes.
Contribute to reliability and basic performance testing, and flag risks and quality gaps early.
Represent the quality aspect with a strong quality mindset.
Mentor others on best practices for test automation and CI/CD.
