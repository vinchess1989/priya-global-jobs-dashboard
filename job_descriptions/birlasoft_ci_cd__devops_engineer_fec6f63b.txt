Job Description: CI/CD Engineer – Grade 5A

Role: CI/CD Engineer / DevOps Engineer

Grade: 5A/5B

Experience: Typically 5–8 years relevant experience

Role Level: Individual Contributor / Senior Engineer

Role Summary

We are looking for a hands-on CI/CD Engineer responsible for designing, implementing, maintaining, and troubleshooting automated build, deployment, and release pipelines. The resource should have strong experience with DevOps practices, source-code management, pipeline automation, containerization, and cloud-native deployment.

Key Responsibilities


Develop and maintain automated CI/CD pipelines for application build, testing, deployment, and release.
Configure pipelines using Jenkins, Azure DevOps, GitHub Actions, GitLab CI/CD, or similar platforms.
Manage source-code repositories and branching strategies using Git.
Automate infrastructure and deployment activities using Terraform, Ansible, or equivalent IaC/configuration tools.
Work with Docker and Kubernetes for containerized application deployments.
Integrate automated testing, code-quality checks, and security scanning into pipelines.
Implement artifact management using tools such as JFrog Artifactory, Nexus, or equivalent.
Troubleshoot pipeline failures, deployment issues, environment-related defects, and integration problems.
Create deployment scripts using PowerShell, Bash, Python, or similar scripting languages.
Support cloud-based deployments on Microsoft Azure, AWS, or GCP.
Maintain CI/CD documentation, configuration standards, and operational runbooks.
Collaborate with development, testing, infrastructure, cloud, and security teams.


Required Technical Skills


Jenkins / Azure DevOps / GitHub Actions / GitLab CI/CD
Git and branching/version-control concepts
Docker and Kubernetes
Terraform and/or Ansible
Bash / PowerShell / Python scripting
Azure / AWS / GCP
Maven / Gradle / npm or similar build tools
Artifactory / Nexus
YAML-based pipeline configuration
CI/CD troubleshooting and deployment automation
Secrets management using Azure Key Vault, AWS Secrets Manager, HashiCorp Vault, or similar
Understanding of FinOps
Microservices deployment, monitoring, fine tuning
Production troubleshooting and deployment management


Preferred Skills


SonarQube
Snyk, Trivy, Checkmarx or similar security tooling
Monitoring tools such as Prometheus, Grafana, Azure Monitor
Exposure to Argo CD or GitOps practices
