About the Role

Experience: 3–6 years

Role: Technical Documentation, Knowledge Management & AI Enablement

We are looking for a Technical Writer with a Software Development background and hands-on AI/RAG knowledge, rather than a traditional Technical Writer.

This is a hybrid role combining:

40% – Technical Documentation: Creating API documentation, architecture documents, developer guides, implementation manuals and product documentation.
25% – AI / RAG & Knowledge Management: Building AI-searchable knowledge repositories using LLMs, embeddings and vector databases.
20% – Software Engineering Understanding: Reading source code, understanding APIs, databases, architecture and development workflows.
15% – Automation & Cross-functional Collaboration: Using Python, AI tools and Git/Azure DevOps to automate documentation and maintain knowledge accuracy.







Responsibilities-




Own and maintain all internal and customer-facing technical documentation.
Build and manage a centralized, version-controlled knowledge repository covering product architecture, APIs, workflows, configurations, use cases, and implementations.
Work with developers and product teams to capture and document technical knowledge.
Design and implement a RAG-based knowledge system using product documentation, code repositories, and technical artefacts.
Use AI to generate customer-specific user manuals, implementation guides, training material, and technical documentation.
Support AI-assisted code generation using product knowledge, architecture, and coding standards.
Ensure documentation stays synchronized with product releases and changes.
Establish documentation standards, review processes, and knowledge management practices.




Required Skills




Strong understanding of software architecture, APIs, databases, and development workflows.
Excellent written and spoken English, particularly technical writing.
Hands-on experience with Python or another programming language.
Practical understanding of LLMs, RAG, embeddings, vector databases, and AI coding tools.
Familiarity with Git, Markdown, documentation tools, and Azure DevOps.
Ability to understand source code and translate technical concepts into clear documentation.




Ideal Candidate

A technically competent engineer who enjoys documentation, knowledge organization, and AI automation. Someone who can understand how a product works, capture that knowledge systematically, and make it usable by both people and AI.




Required Skills




Technically strong professional.
Excellent English communication skills.
