Azure DevOps Engineer (FTE)

Company: LTM

Experience: 5+ Years

Location: Hyderabad / Gurgaon / Noida

Employment Type: Full-Time

Shift: 1:30 PM - 10:30 PM




Role Overview:

Seeking a hands-on DevOps Engineer with strong Kubernetes and Terraform expertise to manage CI/CD, cloud infrastructure deployments, security, troubleshooting, and operational support across multiple applications.




Mandatory Skills:

Strong hands-on experience with Kubernetes (AKS / EKS / GKE / On-prem).

Strong experience with Terraform, including working with existing modules and creating new modules.

CI/CD pipeline development and maintenance; YAML-based pipelines.

Cloud platform experience – Azure preferred; AWS/GCP also acceptable.

Azure DevOps preferred; experience with other CI/CD tools is acceptable.

Infrastructure as Code (IaC), environment provisioning, and deployment automation.

Production release and rollback processes.

Security knowledge covering:

Secret management.

Infrastructure security, networking, firewall rules, and resource management.

Security integration within CI/CD pipelines.

Strong troubleshooting and operational support skills.




Good to Have:

Monitoring and SRE experience
Datadog
Python automation
Kafka exposure
