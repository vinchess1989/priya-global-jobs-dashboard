About the opportunity

A large national organisation is looking for a hands-on Cloud Operations Engineer to help build and run its cloud platforms across AWS & Azure. This is a role where you'll own infrastructure as code day to day, keeping a busy multi-cloud environment secure, reliable and cost-effective, while working closely with application teams and vendors.

It's also a chance to get in early on how AI-enabled automation can change cloud operations. Alongside core platform work, you'll help introduce better automation tools and practices, and build a community of practice around the technologies the team has chosen.

The role


Provide first and second-level support for cloud issues, troubleshooting across the infrastructure
Build and maintain cloud infrastructure as code using Terraform
Help deliver cloud projects from design and cost analysis through to build
Introduce and improve automation tools and processes, including AI-enabled automation
Take part in the team's on-call support rotation
What you'll bring

Hands-on infrastructure as code (IaC) experience, especially Terraform, building secure, reusable, version-controlled infrastructure
Experience building, deploying and supporting workloads in AWS and/or Azure
Containerisation experience with Docker and Kubernetes
Competency in at least one scripting or programming language, plus CI/CD and change control experience
Strong troubleshooting skills and clear written communication, including technical documentation
Great to have: SRE and observability, AWS ECS, cloud security and cost management, Entra ID/IAM/DNS, or experience with 24/7 mission-critical systems.

Culture


Close collaboration with application teams and vendors
A team that values finding better ways of working and owning its impact
Room to share knowledge and help build a community of practice
