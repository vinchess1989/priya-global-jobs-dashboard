Cloud Platform Engineer

Claremont, Cape Town




We’re looking for a Cloud Platform Engineer to help build, automate and maintain secure, reliable cloud infrastructure across Azure and AWS.




Joining the Group IT Operations team, you’ll combine hands-on cloud engineering with operational support and infrastructure modernisation. You’ll work closely with development, security and infrastructure colleagues to improve how environments are deployed, monitored and maintained.




The role




Build and operate Azure and AWS infrastructure across compute, networking, identity, storage and platform services.
Develop reusable Terraform modules and standardise environments to reduce configuration drift.
Build infrastructure deployment pipelines using GitHub, including validation, compliance checks and security scanning.
Improve availability, disaster recovery, monitoring and incident response.
Troubleshoot infrastructure issues and manage patching, performance and cloud costs.
Deliver migrations, upgrades and deployments, supporting development teams with production releases.
Maintain clear documentation, runbooks and auditable change processes.
Share knowledge and mentor colleagues in cloud engineering, infrastructure as code and automation.




What you’ll bring




Proven experience managing enterprise infrastructure, including servers, storage, networking and virtualisation.
Experience modernising infrastructure and services using cloud technologies.
Practical knowledge of Azure and/or AWS, Terraform and CI/CD pipelines.
Strong knowledge of containerisation, scripting and Windows Server and/or Linux administration.
Familiarity with backup, disaster recovery, business continuity and database technologies.
A security-focused approach to infrastructure design and operations.
Strong troubleshooting skills and the ability to explain technical issues clearly to different audiences.
The ability to manage competing priorities and deliver projects to agreed timescales.




Technology environment




The wider environment includes Docker, Kubernetes, PowerShell, Python, GitHub, GitLab, ArgoCD, Octopus Deploy, Azure/AWS PaaS, New Relic, Cloudflare, HashiCorp tooling, Zerto, VMware and Dell EMC storage.




Qualifications




A degree in Computer Science or an equivalent field, alongside relevant cloud administration and infrastructure as code and/or containerisation accreditations.
