We are looking for an experienced Azure DevOps Engineer with strong expertise in CI/CD, infrastructure support, application deployments and Microsoft SQL Server administration.

Key Responsibilities

Support application and infrastructure deployments across environments.
Manage CI/CD pipelines, releases and production support.
Troubleshoot connectivity, certificates, authentication and infrastructure issues.
Support SQL Server provisioning, configuration and decommissioning.
Manage database access, logins, users, roles and permissions.
Handle database deployments, backups, restores, SQL Agent jobs and performance troubleshooting.
Execute DR, rollback and change management activities.
Maintain operational documentation and collaborate with Agile teams.
Mandatory Skills

Strong troubleshooting and problem-solving skills.
Windows Server, IIS, networking and certificate management.
PowerShell and Shell scripting.
Jenkins, Azure DevOps CI/CD pipelines and Chef cookbooks.
Microsoft SQL Server administration, SSMS and T-SQL, including provisioning, authentication, permissions, backup/restore, SQL Agent jobs and database troubleshooting.
ServiceNow (Incident, Change and Release Management).
Jira, Agile/Scrum and Bitbucket (branching, PRs and repository management).
Good to Have

GitHub Actions and database deployment tools (Liquibase/Flyway).
IBM MQ, API integrations and connectivity troubleshooting.
Monitoring tools: AppDynamics, Splunk, Elastic or Grafana.
SQL Server Always On, failover clustering and DR testing.
SQL performance tuning, execution plans and indexing.
Banking or financial services experience.
