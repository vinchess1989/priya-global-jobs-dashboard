I'm working with an exciting software start-up in Dublin that is continuing to grow its engineering team and is looking to appoint a Senior DevOps Engineer.




This is a hands-on role for someone who enjoys working closely with software engineers, improving cloud environments, deployment processes and reliability across a modern microservices based product.




The company is still at a stage where good ideas can have a real impact, so they are looking for someone experienced who can come in, get involved quickly and help improve how things are done.




(Hybrid - Dublin City Centre - 3 days per week on-site)




The role...




You'll work closely with the wider engineering team across cloud infrastructure, Kubernetes, CI/CD, observability and production support.

This is not a management role and there is no expectation to build or lead a Platform function. The focus is on finding a strong Senior DevOps Engineer who wants to stay hands-on and have real ownership across the environment.




Responsibilities...




Support and improve cloud infrastructure across AWS and/or Azure
Work with Kubernetes and containerised applications
Build and maintain CI/CD pipelines
Support microservices-based applications in production
Improve reliability, scalability and operational performance
Troubleshoot infrastructure and production issues
Support monitoring, logging and observability
Work with software engineers to improve deployment and release processes
Use Infrastructure as Code to manage cloud environments
Support cloud security and access controls
Work with basic networking including VPCs/VNets, subnets, routing and security groups
Identify opportunities to automate repetitive operational tasks
Contribute to incident resolution and root-cause analysis




Technical environment...




AWS
Azure
Kubernetes
Docker
Terraform
CI/CD
Microservices
Cloud networking
Monitoring and observability
.NET-based applications




AWS is preferred, but strong Azure experience will also be considered.




About you...




You'll likely come from a DevOps, Cloud Engineering, SRE or Infrastructure Engineering background and have strong hands-on experience across cloud environments and modern deployment tooling.




You'll ideally have experience with:




AWS and/or Azure
Kubernetes
Docker
Terraform or another Infrastructure as Code tool
CI/CD pipelines
Microservices environments
Cloud networking
Monitoring and observability
Production support and troubleshooting
Working closely with software development teams




Experience with technologies such as ECS, EKS, Grafana, Prometheus, Argo CD, Azure DevOps, Python, PowerShell or Bash would also be useful.




Why apply?




This is a great opportunity to join a growing software company at a stage where your experience can make a real difference.




You'll have plenty of hands-on ownership, work closely with senior engineering leadership and help improve the systems and processes that support the company's next stage of growth.




Negotiable salary of €80,000-€90,000 depending on experience.
