Role: Senior DevOps Engineer

Location: Sydney




Job Description:

Key Responsibilities

EKS Platform Engineering:

Design, implement, and maintain highly available and secure Kubernetes clusters using Amazon EKS, including node pool management, upgrade strategies, and disaster recovery.
Ensure Kubernetes security best practices (RBAC, pod security, network policies).
Configure Kubernetes networking, ingress, autoscaling (HPA, Karpenter/Cluster Autoscaler).
Manage secrets and configuration (Vault)

CI/CD Pipeline Management: Build and optimize CI/CD pipelines (Bitbucket, Jenkins, Ansible) to automate code deployment and infrastructure changes, ensuring safe, rapid, and reliable releases.

Automation: Develop and maintain automation tools and scripts (Python/Shell/Bash),Optimize deployment strategies (blue-green, canary, rolling updates)

Observability & Monitoring: Implement and enhance monitoring, alerting, and logging solutions to gain real-time visibility into system health.

Performance & Cost Optimization: Proactively analyse system capacity and optimize AWS resource utilization, balancing performance with cost-efficiency.

Security & Compliance: Implement security best practices, including RBAC, network policies, secrets management, and image scanning within EKS.

Collaboration: Collaborate with cross-functional teams to align infrastructure goals with business objectives.

Continuous Improvement: Identify areas for optimization and efficiency improvements within the infrastructure and automation processes. Stay up-to-date with industry trends and emerging technologies to recommend enhancements.




Required Skills:

Technical Skills:

Deep knowledge of Kubernetes (EKS) and container orchestration
Strong experience with AWS Cloud
Proficiency in Docker and container lifecycle management
Hands-on experience with Terraform (preferred)
Experience with CI/CD tools (Git, Jenkins, Ansible, etc.)
scripting skills (Python, Bash, or Go)
SRE & DevOps Practices
Familiarity with incident response and on-call rotation
understanding of networking
Knowledge of security and compliance in cloud environments
