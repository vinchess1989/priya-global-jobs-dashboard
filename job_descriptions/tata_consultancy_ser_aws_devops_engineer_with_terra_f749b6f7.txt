Experience Range: - 08 To 12 Years

JOB LOCATION: Bengaluru, Chennai & Hyderabad




JOB DESCRIPTION




Key Skills: Git (GitLab, GitHub, Bitbucket), Maven, Jenkins, Chef, Ansible, Docker, Kubernetes, Puppet, Slack, Shell Scripting (Python, Linux), Terraform, AWS Services.




Must Have Skills:




In-depth and working knowledge on AWS Cloud Services through the Infra as a code using infrastructure provisioning and configuring through code using Terraform for Account build, Networking, Storage, Compute, Audit & Config services, End Points, Backup and Identity Access Management (IAM).
Experience in DevOps tools such as Packer (AMI build), Ansible/Puppet (Configuration management), HashiCorp terraform (for Infrastructure deployment) & HashiCorp Vault (Secrets management), Terraform, Ansible, Serverspec tools for build and provisioning of the infrastructure in AWS with one touch Jenkins pipelines.
Should have strong experience/background in Windows PowerShell, Python, Shell Scripting.
Possess good hands-on knowledge on CI/CD tools such as Jenkins and Groovy DSL scripting.
Any cloud with this is an added advantage
