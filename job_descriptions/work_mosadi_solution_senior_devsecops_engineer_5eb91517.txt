DevSecOps Engineer

Job Purpose




As a DevSecOps Engineer, you will play a key role in integrating security practices into DevOps processes, ensuring the highest level of security across the software development lifecycle.




This role is suited for a seasoned professional with deep expertise in DevOps, security, and automation. You will provide mentorship to team members and collaborate with various stakeholders to enhance the organisation's overall security posture.




Key Responsibilities




1. Security Automation Leadership




- Play a key role in the development and optimisation of security automation scripts and tools within CI/CD pipelines.

- Champion the implementation of advanced automated security testing processes.




2. Vulnerability Management and Remediation




- Oversee and manage vulnerability scanning and assessment processes.

- Ensure swift identification and remediation of security vulnerabilities.




3. Security Monitoring




\- Lead the design, implementation and maintenance of comprehensive security monitoring solutions.




4. Incident Response




- Drive incident response efforts.

- Analyse security events and contribute to the continuous improvement of incident response capabilities.




5. Infrastructure as Code (IaC) Excellence




- Enforce security best practices in Infrastructure as Code (IaC) scripts.

- Collaborate with DevOps teams to integrate advanced security measures into infrastructure provisioning.




6. Secure Configuration Management




- Implement secure configuration management practices for infrastructure components.

- Set and monitor secure configuration baselines in collaboration with operations teams.




7. Security Governance and Compliance




\- Lead the establishment of security governance policies and compliance standards.




8. Collaboration and Mentorship




- Collaborate with cross-functional teams, providing guidance on security practices in DevOps processes.

- Mentor and coach junior and intermediate DevSecOps engineers.




Qualifications and Experience




- Bachelor's degree in Computer Science, Information Security or a related discipline, or equivalent practical experience.

- 5+ years of relevant experience across DevOps, cloud engineering, cybersecurity or platform security.

- Proven experience leading DevSecOps initiatives and embedding security into enterprise delivery pipelines.

- Strong practical experience securing AWS and Azure cloud environments.

- Advanced understanding of CI/CD, Infrastructure as Code, container security and automated vulnerability management.

- Expert scripting and automation capabilities using Python and/or Bash.

- Strong knowledge of IAM, encryption, secrets management, secure configurations and security incident response.

- Experience with Linux, Docker, ECS/Fargate, cloud monitoring and production operations.

- Working knowledge of SQL, REST APIs and enterprise integration troubleshooting.

- Relevant AWS, Azure, DevSecOps or advanced security certifications are advantageous.
