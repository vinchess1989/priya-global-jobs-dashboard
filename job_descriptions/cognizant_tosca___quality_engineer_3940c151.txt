What makes Cognizant a unique place to work? The combination of rapid growth and a unique place international and innovative environment! This is creating many opportunities for people like YOU — people with an entrepreneurial spirit who want to make a difference in this world.

At Cognizant, together with your colleagues from all around the world, you will collaborate on creating solutions for the world's leading companies and help them become more flexible, more innovative, and successful. Moreover, this is your chance to be part of the success story.

Position Summary

Senior Quality Engineer who can work on Implements, maintains, and reviews payments application functionalities of point of sale and self checkout to ensure all the end to end business flows working as expected after the new changes deployed on the POS and SCO with all the hardware combinations. Very good experience with automated testing frameworks. Need to be aware of Instore, Connex, Qwikcilver, Linkly, Pywin Auto, Playwright, Python, GitHub Copilot, Rest API

Mandatory Skills


Experience with all phases of software testing including test planning, functional testing, reporting, regression testing etc.
Strong experience Automation testing tools like TOSCA, Playwright and Selenium.
Good experience working on Jira
Strong experience on creating Automation frameworks using TOSCA, Playwright and Selenium
Good to have Automation, CI/CD tools using Azure DevOps
Good exposure to Retail domain including Point of Sale and Infra
Excellent written and oral communication, quick learner and should be able to work independently without much supervision
Good exposure to payments applcations like Instore, Connex, Qwikcilver, Linkly, Pywin Auto, GitHub Copilot


Duties And Responsibilities


Knowledge of test planning, designing, test execution and defect management activities
Good experience in End-to-end testing, Functional testing, Manual and Automation testing experience
Strong knowledge in Automation tools like TOSCA, Playwright, Selenium and web service testing - REST & SOAP APIs, Postman or SOAP UI tool knowledge or any other web service testing tool for REST API
Good to have knowledge of Point-of-sale systems, retail basic knowledge, SAP system knowledge
Strong experience in Agile methodology and knowledge of Atlassian Platform (JIRA, Confluence), qtest, Google sheets
Ability to work independently and interface with different project stakeholders
Good knowledge in creating Automation frameworks using Selenium and Tosca
Good knowledge in Automation, CI/CD tools using Azure DevOps
Good exposure to Retail domain including Point of Sale and Payments
Excellent written and oral communication, quick learner and should be able to work independently without much supervision.
Understand and analyze the requirements (through review of requirement document) to identify the testable requirements
Prioritize the requirements based on the time required; Review/create the requirement traceability matrix
Create automation test scripts and share created test scripts with test lead for review.
Conduct pilot automation test run to validate the test scripts.
Test the defect and update the status, if required; Conduct root cause analysis of the defects logged; Prepare Test summary Report and share the same for review/ Review the test results/test reports submitted by the test analyst.
Participate in the defect triages to gather evidence for defect identification on periodic basis for defect prioritization and fix.
Script Development/Execution using Selenium with Java, Playwright with Typescript and TOSCA automation tools and provide the update with customers.
