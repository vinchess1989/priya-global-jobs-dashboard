Job Description

Rakuten Group, Inc. is a global leader in internet services and has a diverse ecosystem spanning across e-commerce, fintech, communications and more serving approximately 1.8 billion members worldwide. Founded in Tokyo in 1997, the Group operates in over 30 countries and regions with more than 30,000 employees. 

Based in Singapore's Central Business District, Rakuten Asia Pte. Ltd. serves as the regional headquarters for Asia, driving value through areas such as advertising product development, product strategy, and data management to support Rakuten Group's global ecosystem. Learn more at: https://global.rakuten.com/corp/

The AI & Data Division (AIDD), creates powerful, customer-focused search, recommendation, data science, advertising, marketing, price, and inventory optimization solutions to a variety of businesses in Rakuten group. As part of AIDD, AILab builds new solutions that have the potential to transform how users interact with Rakuten service. Our goal is to drive innovation by developing new products and capabilities that deliver significant impact over longer timeframes using AI.

We are building the next generation of AI-powered shopping experiences — autonomous agents that search, compare, reason, and transact on behalf of users. We are looking for a DevOps / Site Reliability Engineer to own the reliability, releases, observability and cost of our production services. You will run multi-cluster Kubernetes workloads, including LLM-powered applications, build automation with modern tooling and AI agents, and keep services fast, secure and stable under peak traffic. We value engineers who automate first, make decisions based on data, respect production, and communicate clearly.

Responsibilities


Deploy, scale and operate services on multi-environment, multi-cluster Kubernetes, including disaster recovery failover.
Maintain and improve CI/CD pipelines and standardize the release process: versioning, canary, blue-green and automated rollback.
Build and run the observability stack (metrics, logs, tracing); define SLIs / SLOs and error budgets and reduce alert noise.
Operate LLM applications in production: model latency (TTFT), error rate, rate limiting, model version migration, and token cost monitoring.
Participate in on call; lead incident response, root cause analysis and blameless postmortems, and turn the findings into automation or runbooks.
Own capacity planning and load testing; evaluate the capacity limits of each layer and tune accordingly.
Manage edge and security: CDN caching, WAF / bot protection rules, certificates, access control and compliance remediation; drive supply chain security practices such as image scanning, signing and SBOM.
Manage infrastructure and configuration as code (IaC / GitOps) to minimize manual work.
Build internal tools and AI agent workflows for releases, health checks, alert triage and root cause analysis, with clear safety guardrails.
Drive cost optimization (FinOps): resource quota governance, idle resource cleanup and LLM cost analysis.
Write and maintain operational documentation, and collaborate with development, product and platform teams.


Mandatory Qualifications


3+ years of experience in DevOps / SRE / infrastructure (5+ years for Senior).
Solid Linux and networking fundamentals (TCP/IP, DNS, HTTP/HTTPS, TLS, load balancing, reverse proxies); able to troubleshoot production issues independently.
Production Kubernetes experience: Deployment / StatefulSet / Service / Ingress, resources and scheduling, HPA, probes and troubleshooting; proficient with Helm.
In-depth experience with at least one CI/CD tool (Jenkins / GitHub Actions / GitLab CI / Argo CD, etc.) and a good understanding of Git branching and release strategies.
Familiar with the Prometheus ecosystem (PromQL, Alertmanager, Grafana) and experienced in designing SLO-based alerts.
Proficient in at least one language for automation: Python / Go / Shell.
Experience with on-call and production incident handling; able to write clear postmortem reports.
Excellent problem solving, teamwork and communication skills.


Desired Qualifications


Experience in building AI Infrastructure (e.g RL environment)
Daily use of AI coding / ops agents (Claude Code, Copilot, etc.), or experience building automation such as MCP servers
IaC / GitOps: Terraform / OpenTofu, Argo CD / Flux, Kustomize; Policy as Code (OPA / Kyverno).
Advanced observability: OpenTelemetry, distributed tracing, log pipelines (Fluent Bit / Vector), eBPF tooling.
Security and compliance: image scanning (Trivy), signing (cosign / Sigstore), SBOM / SLSA, secrets management (Vault, etc.).
CDN / WAF experience: caching and security configuration on Akamai, Fastly or Cloudflare.
Multi-cluster / multi-AZ disaster recovery, global traffic failover, chaos engineering.
Public cloud experience: AWS, Azure or GCP (CKA / CKS or cloud vendor certifications preferred).
Database operations basics: monitoring, capacity and backup for MySQL and Redis.
Experience keeping high-concurrency services stable under peak traffic.
