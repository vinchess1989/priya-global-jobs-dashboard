Lead Mobile Release Engineer with 6+ years of experience to own and lead the mobile application delivery lifecycle across iOS and Android. This role will serve as the single point of contact for the mobile release function and act as the technical lead for release engineering across the team.

You will be responsible for driving release strategy, standardizing delivery processes, coordinating cross-functional stakeholders, and building secure, automated, and highly reliable pipelines from code merge through internal distribution and production rollout. The ideal candidate combines deep expertise in mobile release tooling with strong DevOps/platform engineering fundamentals and the leadership skills to guide developers, QA, product, and security teams through a predictable release process.

Requirements

Key Responsibilities


Act as the primary owner and single point of contact for all mobile release engineering activities across iOS and Android
Lead the end-to-end mobile release lifecycle, including build orchestration, internal testing, beta distribution, store submission, phased rollout, and production release
Define and enforce release standards, governance, checklists, timelines, and go/no-go criteria
Build and maintain CI/CD pipelines for mobile applications using GitHub Actions, Azure DevOps, Jenkins, or Bitrise, integrated with Fastlane
Manage release workflows for App Store Connect and Google Play Console, including TestFlight, Firebase App Distribution, release tracks, phased rollouts, and store compliance requirements
Own and secure mobile code-signing processes, including certificate and provisioning profile management using Fastlane Match or equivalent tooling
Improve build reliability, speed, and developer experience by optimizing macOS runners, caching, dependency management, and artifact handling
Partner with mobile developers to support native iOS/Android, React Native, and Flutter delivery workflows
Drive shift-left quality and security practices by integrating unit tests, UI automation, static analysis, dependency scanning, and mobile security checks aligned to OWASP MASVS
Implement and review post-release observability using Crashlytics, Sentry, and New Relic to monitor app health, regressions, and release quality
Manage supporting infrastructure on AWS and/or Azure using Terraform and Ansible
Support internal tooling and backend services used by the mobile ecosystem with Docker and Kubernetes where required
Coordinate closely with engineering, QA, product, security, and leadership to plan releases, manage dependencies, communicate risks, and resolve blockers
Mentor engineers on release best practices, improve team maturity, and drive continuous improvement across delivery processes
Own release metrics such as build success rate, deployment frequency, build duration, failed submissions, rollback rates, and release stability


Required Skills And Qualifications


6+ years of experience in DevOps, Platform Engineering, Release Engineering, or CI/CD, with at least 2-3 years focused on mobile release engineering
Proven experience acting as a technical lead, release lead, or primary point of contact for a delivery or platform function
Strong hands-on experience with Fastlane, Xcodebuild, and Gradle
Proven experience building and operating iOS and Android CI/CD pipelines on macOS runners
Deep understanding of App Store Connect, Google Play Console, TestFlight, Firebase App Distribution, release tracks, phased rollouts, signing requirements, and store review processes
Strong knowledge of CocoaPods, Swift Package Manager, and Android build/release configuration
Experience supporting both native mobile apps and at least one cross-platform stack such as React Native or Flutter
Proficiency in Bash, Python, or Ruby for release and build automation
Strong hands-on experience with AWS and/or Azure and Infrastructure as Code using Terraform
Working knowledge of Docker and Kubernetes
Experience integrating security tooling such as MobSF, SonarQube, dependency scanning, or similar mobile security controls
Solid understanding of OWASP MASVS and secure mobile delivery practices
Strong stakeholder communication, decision-making, incident coordination, and ownership mindset


Preferred Qualifications


Experience with Bitrise, MacStadium, AWS EC2 Mac, or other Apple build infrastructure providers
Experience managing release planning for multiple apps, teams, or environments simultaneously
Familiarity with ArgoCD or Flux for managing backend services that support mobile platforms
Experience with JFrog Artifactory, Azure Artifacts, private CocoaPods registries, or Maven repositories
Experience optimizing runner usage, cloud costs, and build minutes at scale
Experience mentoring engineers or leading a small release/platform function
