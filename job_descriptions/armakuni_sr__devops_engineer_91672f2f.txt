We are looking for an experienced Sr. DevOps Engineer to design, implement, and maintain scalable DevOps solutions across AWS environments. The role will focus on CI/CD, cloud infrastructure, Infrastructure as Code, containerization, deployment automation, and improving development and deployment practices across teams.

The ideal candidate should have 4+ years of strong hands-on experience with DevOps tools, AWS cloud services, container technologies, and CI/CD, along with the ability to lead and drive DevOps best practices.




Key Responsibilities

Design, implement, and maintain CI/CD pipelines using tools such as Jenkins, GitHub Actions, GitLab CI, CircleCI, and AWS DevOps services.
Manage and maintain distributed, multi-tier cloud infrastructure on AWS with a focus on performance, scalability, reliability, and availability.
Implement Infrastructure as Code (IaC) using Terraform and AWS CloudFormation to automate and standardize infrastructure provisioning.
Manage containerized applications using Docker, Docker Compose, and Kubernetes.
Work with AWS CodePipeline for automated application deployments.
Troubleshoot and resolve deployment and infrastructure issues across development, staging, and production environments.
Manage software releases, maintenance windows, and environment configurations across the SDLC.
Configure and maintain web servers, including IIS, Windows Server, Apache, and Nginx.
Develop and maintain automation scripts using Python and Node.js.
Manage version control using Git, SVN, and TFS.
Evaluate and adopt emerging DevOps tools, technologies, and practices to improve development and deployment workflows.
Promote knowledge sharing, collaboration, and DevOps best practices across cross-functional teams.
Lead initiatives to improve automation, reliability, scalability, and efficiency of deployment processes.




Requirements

Bachelor’s degree in Computer Science, Information Technology, or a related discipline.
4+ years of hands-on experience in DevOps, CI/CD, and cloud infrastructure.
Strong hands-on knowledge of AWS cloud services and infrastructure.
Strong experience with Docker, Docker Compose, and cloud-native container technologies.
Intermediate proficiency in Kubernetes for container orchestration and management.
Practical experience with AWS CodePipeline and automated deployment processes.
Strong understanding of IIS, Windows Server, Apache, and Nginx.
Proficiency in Python and/or Node.js scripting.
Experience with Git, SVN, and TFS.
Familiarity with build tools used for web and mobile application development.
Experience working with IDEs such as Visual Studio, VS Code, and Eclipse.
Strong troubleshooting, problem-solving, communication, and leadership skills.
