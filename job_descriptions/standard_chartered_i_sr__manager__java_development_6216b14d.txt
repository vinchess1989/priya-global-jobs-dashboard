Job Summary

The position is for a Manager to discharge activities in the areas of Delivery as primary KRA, Release Management / Infrastructure and Development as secondary KRA

Key Responsibilities


Software development * deliveries (in-house and Vendor).
Involving all stake holder teams to validate & deploy (test and production) deliveries.
Taking care of the configuration management side of software releases
Monitor and support environments including Network, WAS, DB and OS
Pro-active identification and resolution of issues (environment, application).
Ensure the process is adhered to at every stage.
Handle infrastructure needs of test environments.
Support automation initiatives by developing scripts
Pro-actively identify and develop tools as needed for the job
Keep teams informed of right status


Regulatory & Business Conduct


Display exemplary conduct and live by the Group’s Values and Code of Conduct.
Take personal responsibility for embedding the highest standards of ethics, including regulatory and business conduct, across Standard Chartered Bank. This includes understanding and ensuring compliance with, in letter and spirit, all applicable laws, regulations, guidelines and the Group Code of Conduct.
Lead to achieve the outcomes set out in the Bank’s Conduct Principles.
Effectively and collaboratively identify, escalate, mitigate and resolve risk, conduct and compliance matters.


Key stakeholders


FSS Mgmt, PSS and other infra related key vendors and stakeholders


Skills And Experience

Skill sets would include


Hands-on working experience in Java Application (Java development not a must). Java 17, Spring boot
3.x, Maven / Gradle, JUnit, Messaging concepts (MQ, Solace), Web security, Linux shell commands and basic scripting, Git, Containerization (Kubernetes, Docker / podman), Devops Database - SQL, Data model design
Working experience in Linux Platform (A must).
Knowledge on other middleware applications like web sphere WAS, MQ.
Shell scripting knowledge (a must).
DevOps (Jenkins, Ansible, Github) exposure / experience – (A must).
Knowledge on other script language (perl, python)
Advanced level knowledge on database SQLs.


Role Specific Technical Competencies


Working experience in Linux Platform
Hands-on working experience in Java Application
Java 17, Spring boot 3.x, Maven / Gradle, JUnit, Messaging concepts (MQ, Solace), Web security, Linux shell commands and basic scripting, Git, Containerization (Kubernetes, Docker / podman), Devops
Database - SQL, Data model design
Knowledge on Web sphere
Knowledge on other middleware applications like Web Methods or web sphere, MQ
Shell scripting knowledge a must
Knowledge on other script language (perl, python, jython)
DevOps tools Ansible/Git/bitbucket/Jenkins/rundeck -Advance & real time project support Docker and Kubernetes Intermediate level


Qualifications


Bachelor’s in engineering
8-12 years of experience
