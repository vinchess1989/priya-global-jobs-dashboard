Key Responsibilities


Design, implement, and maintain cloud infrastructure on AWS and Azure.
Build and optimize CI/CD pipelines for automated build, testing, and deployments.
Implement Infrastructure as Code (IaC) using Terraform.
Manage containerized applications using Docker, Kubernetes, and Helm.
Integrate security controls, vulnerability scans, and compliance checks into DevOps workflows.
Implement monitoring, logging, alerting, and observability solutions.
Automate operational tasks using Python, Bash, or PowerShell scripting.
Troubleshoot infrastructure, deployment, and application-related issues.
Collaborate with Development, QA, Security, and Operations teams.
Ensure high availability, scalability, security, and performance of production systems.
Maintain infrastructure and deployment documentation.
Participate in Agile ceremonies and provide regular project updates.


Requirements & Skills


6-10 years of experience in DevOps and Cloud Engineering.
Hands-on experience with AWS and Azure.
Strong expertise in CI/CD tools such as Jenkins, GitLab CI/CD, GitHub Actions, or Azure DevOps.
Experience with Terraform for Infrastructure as Code.
Strong knowledge of Docker, Kubernetes, and Helm.
Experience with DevSecOps, including SAST, DAST, and vulnerability management.
Proficiency in monitoring tools such as Prometheus, Grafana, ELK, CloudWatch, or Azure Monitor.
Strong scripting skills in Python, Bash, or PowerShell.
Good understanding of cloud networking, Linux administration, and Git.
Excellent troubleshooting, communication, and stakeholder management skills.


Preferred Skills


AWS/Azure certifications.
Exposure to GCP, ArgoCD, FluxCD, Ansible, Chef, or Puppet.
Knowledge of SRE practices and service mesh technologies.
Experience with Kafka, RabbitMQ, FinOps, and cloud security frameworks.
Experience in Telecom, eCommerce, or Financial Services domains.
