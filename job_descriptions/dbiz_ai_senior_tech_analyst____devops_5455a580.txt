Savan Belliappa

Location: Australia – Sydney, Melbourne, Adelaide, Brisbane, Canberra, Perth




Requirements and Skills:

We are seeking an experienced Senior Tech Analyst – DevOps to support and enhance our software delivery lifecycle through automation, cloud infrastructure management, and continuous integration/continuous deployment (CI/CD) practices. The role will work closely with development, QA, security, and infrastructure teams to improve system reliability, scalability, and deployment efficiency.




Key Responsibilities:




Design, implement, and maintain CI/CD pipelines for application deployments.
Manage and support cloud infrastructure (AWS, Azure, or GCP).
Automate infrastructure provisioning using Infrastructure as Code tools such as Terraform, Ansible, or CloudFormation.
Monitor system performance, application health, and availability using monitoring tools.
Troubleshoot build, deployment, and production issues in a timely manner.
Collaborate with developers to streamline release processes and environment management.
Implement security best practices across pipelines and infrastructure.
Manage containerized environments using Docker and Kubernetes.
Support version control and branching strategies using Git.
Optimize system scalability, reliability, and cost efficiency.
Maintain technical documentation, SOPs, and architecture diagrams.
Mentor junior team members and provide technical guidance where required.

Required Skills & Experience:




5+ years of experience in DevOps / Cloud Engineering / Infrastructure Automation.
Strong experience with CI/CD tools such as Jenkins, GitHub Actions, GitLab CI, Azure DevOps, etc.
Hands-on experience with AWS / Azure / GCP.
Experience with scripting languages such as Bash, Python, or PowerShell.
Knowledge of Docker, Kubernetes, and container orchestration.
Experience with Infrastructure as Code tools.
Strong understanding of Linux/Windows server administration.
Experience with monitoring tools such as Prometheus, Grafana, Splunk, Datadog, or similar.
Good understanding of networking, security, and system architecture.
Strong problem-solving and communication skills.




Salary: AUD$85,000 and above (excluding Super)
