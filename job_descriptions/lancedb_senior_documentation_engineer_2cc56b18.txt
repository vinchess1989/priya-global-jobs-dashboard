About LanceDB

AI advances at the speed of its research, and research moves at the speed of its data. LanceDB is the AI-native Multimodal Lakehouse: one system where a researcher curates petabytes of video, audio, and every signal derived from them with a few lines of Python, and the next training run starts as fast as the next idea. Customers like Runway, Midjourney, and Netflix build the future of AI on LanceDB, from frontier and world models to robots and autonomous vehicles.

About The Role

As the Documentation Engineer at LanceDB, you will make Lance and LanceDB easier to understand, adopt, and use in production. You'll work at the intersection of engineering, technical writing, and developer experience, turning complex data infrastructure concepts into clear explanations and working examples.

You'll partner closely with engineering, product, and our open-source community to document new features, build runnable examples, and keep guidance accurate as the product evolves. This role will own documentation as part of the product, with a particular emphasis on content that both developers and AI agents can discover, understand, and use reliably, while also building the tooling that keeps it accurate.

This is an opportunity to define how documentation supports a growing ecosystem of AI-assisted development and have a meaningful impact on how developers and AI agents learn and build with LanceDB.

What You'll Do


Core documentation: Create and maintain quickstarts, tutorials, conceptual guides, API references, and troubleshooting documentation for Lance and LanceDB.
Documentation for AI agents: Design documentation agents can use reliably, including structured API descriptions, explicit prerequisites, complete examples, and clear error and recovery guidance. Evaluate it through agent-driven tasks to find where missing context or ambiguous instructions prevent agents from completing workflows correctly.
Runnable examples: Build examples and sample applications that demonstrate workflows such as data ingestion, vector search, filtering, indexing, and multimodal data management.
AI-assisted workflows: Use AI coding assistants and other AI tools to research the codebase, draft and revise content, generate examples, and automate maintenance, verifying outputs against product behavior and tested code.
Documentation tooling: Maintain documentation tooling and automate checks for code examples, API references, links, and content quality.
Partner closely with engineering and product teams to document new features alongside releases and keep existing guidance aligned with product changes.
Develop and continuously improve documentation structure, navigation, and search so developers can find the right information at each stage of their journey.
Use community questions, support feedback, and documentation usage to identify gaps and prioritize improvements.
Represent LanceDB with open-source contributors, reviewing documentation changes and establishing clear contribution guidelines.


What We're Looking For


8+ years of experience in documentation engineering, developer-focused technical writing, software engineering, or a related role
A proven track record of technical documentation, shown through a portfolio that explains complex concepts clearly and helps developers complete real tasks
Experience designing documentation for consumption by AI agents, with an understanding of how content structure, context, and API clarity affect agent performance
Demonstrated fluency with AI tooling, including coding assistants and LLM-based workflows, and sound judgment about how to validate their outputs
Strong Python skills and the ability to write, run, and debug examples using APIs and SDKs
Familiarity with databases, SQL, and data workflows, plus an interest in learning vector search and multimodal AI infrastructure
Experience with Git, pull requests, Markdown, and documentation workflows integrated with software development
Demonstrated ability to learn a product by reading code, experimenting with APIs, and collaborating with engineers
Strong editorial judgment, attention to technical accuracy, and the ability to prioritize and work independently


Nice to Have


Experience documenting databases, data infrastructure, or AI and machine learning tools
Familiarity with LanceDB, Lance, Apache Arrow, or related technologies
Experience with TypeScript or Rust and documenting APIs across multiple languages
Experience with documentation platforms, generated API references, and CI-based testing of code examples
Experience building agent workflows, documenting tool interfaces, or evaluating agents against developer tasks
Contributions to open-source projects or experience supporting a developer community
