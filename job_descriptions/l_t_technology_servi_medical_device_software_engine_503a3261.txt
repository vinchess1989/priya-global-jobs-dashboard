Key Responsibilities

Execute the end-to-end medical-device software development lifecycle in compliance with ISO 13485 and IEC 62304.
Work on software requirements, architecture/design, development, integration, verification, validation, release and maintenance.
Perform Software FMEA (sFMEA) and software risk analysis aligned with ISO 14971.
Define software risk-control measures and ensure implementation and verification.
Maintain end-to-end traceability across requirements → risks → design → code → tests → verification evidence.
Support design reviews, configuration/change management, defect analysis and regulatory/QMS audits.

Mandatory Skills

Strong hands-on experience with ISO 13485, IEC 62304 and ISO 14971.
Practical experience preparing and maintaining Software FMEA.
Experience across the complete regulated medical-device software lifecycle.
Strong knowledge of design controls, risk management, V&V and traceability.
Experience with tools such as Azure DevOps, Jira, DOORS, Polarion or Jama is preferred.
