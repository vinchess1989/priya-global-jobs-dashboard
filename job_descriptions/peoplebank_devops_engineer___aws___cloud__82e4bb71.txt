Our client is an established Australian software company developing technology solutions that help make workplaces safer. With a strong focus on innovation, automation and continuous improvement, they are looking to bring on a DevOps Engineer to support the ongoing development and optimisation of their cloud infrastructure and software delivery environment.

This is an opportunity to join a collaborative engineering team, work with modern cloud technologies and build your capabilities across AWS, infrastructure as code, CI/CD and automation, with guidance from an experienced Senior DevOps Engineer.

Reward & Benefits
• Competitive salary package commensurate with experience
• Work alongside experienced engineers with opportunities for technical mentoring
• Hands-on exposure to AWS, Terraform/OpenTofu, Docker and GitOps
• Opportunity to develop skills across cloud infrastructure, Kubernetes, security and automation
• Be part of an innovative engineering environment embracing AI and modern development practices

The Opportunity
You'll contribute to the ongoing management and improvement of cloud infrastructure, deployment pipelines and automation processes, helping ensure reliable, scalable and efficient software delivery.
Working with a modern technology stack including AWS, GitHub, CircleCI, Docker, Linux, Terraform/OpenTofu and Argo CD, you'll take ownership of defined infrastructure changes, pipeline improvements and repeatable deployment tasks.

Your responsibilities will include:
• Supporting and improving CI/CD pipelines across build, testing and deployment workflows.
• Working with AWS and the AWS CLI to manage and troubleshoot cloud resources.
• Implementing infrastructure changes using Terraform or OpenTofu.
• Managing Git and GitHub workflows, including branches, pull requests and version control.
• Supporting Docker-based applications and containerised deployments.
• Using Linux command-line tools to investigate issues, review logs and troubleshoot problems.
• Contributing to automation, monitoring and operational improvements.
• Exploring AI-assisted development and automation tools to improve engineering efficiency.

You'll initially focus on defined changes and non-production environments, with the opportunity to progressively expand your responsibilities across infrastructure, cloud security, cost management, Kubernetes and platform engineering.

About the organisation & culture
Our client is an established Australian software provider focused on developing innovative solutions that improve workplace safety, compliance and operational efficiency. Innovation, collaboration and continuous improvement are central to their engineering culture. Their teams embrace emerging technologies and modern engineering practices, with a strong focus on delivering quality solutions and improving the experience for both customers and developers. You'll join a supportive and collaborative engineering team, working closely with experienced technical professionals who value knowledge sharing, initiative and ongoing development.

Skills & Experience
To be successful in this role, you will need to meet most of the following criteria:
• Experience in a DevOps, Cloud, Infrastructure or Software Engineering role.
• Hands-on experience with AWS and familiarity with the AWS CLI.
• Exposure to infrastructure as code using Terraform or OpenTofu.
• Good working knowledge of Git and GitHub, including branching and pull requests.
• Experience with CI/CD pipelines, ideally using CircleCI or GitHub Actions.
• Familiarity with Docker and containerisation.
• Confidence working in Linux environments and using command-line tools to troubleshoot issues.
• Basic scripting skills using Python, Bash or PowerShell.
• An understanding of cloud security fundamentals, including IAM, access controls and secure deployment practices.
• Strong problem-solving skills, attention to detail and a willingness to learn new technologies.
• An interest in AI coding assistants and using AI tools to support development and troubleshooting. A tertiary qualification in Computer Science, Software Engineering or IT is desirable. AWS certifications will also be viewed favourably.
