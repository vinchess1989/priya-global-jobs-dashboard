ABOUT THE POSITION

This is a remote position.

We are seeking a skilled AWS DevSecOps Engineers to join our technology team. The ideal candidates will have strong experience in AWS cloud environments, combined with hands-on Security Operations (SecOps) expertise. This role focuses on securing, maintaining, and optimizing AWS infrastructure while ensuring compliance with security best practices and operational standards.


The successful candidates will play a key role in implementing security controls, managing vulnerabilities, maintaining web application security, and supporting the continuous improvement of cloud security posture.





Responsibilities


Perform security hardening of AWS environments in accordance with industry best practices and security standards.

Configure, manage, and optimize AWS Web Application Firewall (WAF) policies and rules.

Conduct operating system and application patch management activities across cloud infrastructure.

Implement and maintain AWS security services including IAM, Security Hub, GuardDuty, CloudTrail, AWS Config, and KMS.

Monitor, detect, and respond to cloud security threats and vulnerabilities.

Automate security controls, compliance checks, and infrastructure deployments using Infrastructure as Code (IaC).

Collaborate with development, infrastructure, and security teams to embed security throughout the SDLC.

Support security audits, risk assessments, and compliance initiatives.

Review and improve cloud configurations to ensure adherence to security baselines and governance requirements.

Troubleshoot and resolve security and infrastructure-related incidents within AWS environments.




Qualifications

Matric and a tertiary qualification in Information Technology, Computer Science, Engineering, or a related field.

AWS Certified




Experience

Minimum 5 years' experience in DevOps, Cloud Engineering, or DevSecOps roles.

Proven experience working within AWS cloud environments.

Hands-on experience in SecOps, cloud security, vulnerability management, and incident response.

Experience managing and configuring AWS WAF.

Experience with server patching, security remediation, and hardening activities.

Knowledge of Infrastructure as Code (Terraform, CloudFormation, or similar).




Skills

AWS Services (EC2, VPC, IAM, S3, RDS, CloudTrail, Config, Security Hub, GuardDuty, KMS).

AWS WAF administration and rule management.

Linux and/or Windows server administration.

CI/CD tools such as Jenkins, GitHub Actions, GitLab CI/CD, or Azure DevOps.

Scripting skills in Python, Bash, or PowerShell.

Container technologies such as Docker and Kubernetes (advantageous).

Security frameworks and best practices (CIS Benchmarks, NIST, ISO 27001).
