Introduction

Azure DevOps Engineer with 5–10 years of experience in designing, implementing, and maintaining CI/CD pipelines using Azure DevOps and GitHub. Strong hands-on expertise in Kubernetes, Helm Charts, Docker, container orchestration, Kubernetes networking, and Ingress Controllers. Experienced in monitoring and observability using OpenTelemetry, ClickStack, and Grafana, with a focus on integrating security and code-quality checks using SonarQube and Rapid7. Knowledge of Azure/AWS cloud environments, SQL Server, PostgreSQL, and C# .NET applications is required. The role involves troubleshooting production issues, optimizing deployment processes, and supporting primarily on-premises infrastructure.

Duties & Responsibilities

Design, develop, and maintain CI/CD pipelines using Azure DevOps and GitHub.

Deploy, manage, and troubleshoot containerized applications on Kubernetes.

Configure and maintain Helm Charts for application deployment and release management.

Build, manage, and optimize Docker containers and containerized workloads.

Configure Kubernetes networking, Ingress Controllers, traffic routing, and load balancing.

Implement monitoring, alerting, and observability solutions using OpenTelemetry, ClickStack, and Grafana.

Integrate security scanning and code-quality checks into CI/CD pipelines using SonarQube and Rapid7.

Automate build, deployment, and release management processes following CI/CD best practices.

Support and troubleshoot C# .NET applications running in containerized environments.

Monitor platform performance, investigate production incidents, and resolve infrastructure and deployment issues.

Collaborate with developers, QA, security, and infrastructure teams to improve deployment reliability.

Support database connectivity and deployment-related issues involving SQL Server and PostgreSQL.

Work with primarily on-premises infrastructure, with exposure to Azure and/or AWS cloud environments.

Desired Experience & Qualification

5–10 years of experience in DevOps, Azure DevOps, platform engineering, or related roles.

Strong hands-on experience with Kubernetes, Helm, Docker, Azure DevOps, and GitHub.

Proven experience building and maintaining CI/CD pipelines and automated release processes.

Strong knowledge of Kubernetes networking, Ingress Controllers, traffic routing, and container orchestration.

Experience with monitoring and observability tools such as OpenTelemetry, ClickStack, and Grafana.

Hands-on experience integrating DevSecOps and code-quality tools, particularly SonarQube and Rapid7.

Good understanding of SQL Server and PostgreSQL databases.

Exposure to Azure and/or AWS cloud environments and on-premises infrastructure.

Experience supporting or deploying C# .NET applications is advantageous.

Strong production troubleshooting, incident resolution, analytical, and problem-solving skills.

Ability to collaborate effectively with development, security, QA, and infrastructure teams.
