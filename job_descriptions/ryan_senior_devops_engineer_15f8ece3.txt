The DevOps Engineer designs and implements a fully automated continuous integration and continuous delivery (CI/CD) ecosystem, Internal Developer Portal (IDP), and secure cloud networking across Amazon Web Services (AWS), Microsoft Azure, and on-premises environments. This position combines a software development foundation with cloud infrastructure, automation, and platform engineering to help engineering teams build, test, and deploy software faster and more reliably. The role also contributes to scalable cloud network architecture, self-service tooling, network-aware CI/CD pipelines, and integrated developer platform capabilities that standardize software delivery across the organization.

Duties and Responsibilities, as They Align to Ryan’s Key Results

Key Responsibilities

People


Champion a DevOps culture focused on an automation-first mindset, continuous improvement, collaboration, and transparency.
Partner with development teams to improve reliability, performance, and deployment practices.


Client

Internal Developer Portal (IDP)


Architect and implement an Internal Developer Portal to provide self-service infrastructure, application templates, and deployment workflows.
Enable “golden paths” for engineering teams to accelerate onboarding and reduce cognitive load.
Integrate the IDP with continuous integration and continuous delivery (CI/CD) systems, cloud infrastructure, identity management, and observability platforms.
Maintain service catalogs, documentation standards, and ownership metadata.
Continuously improve developer experience through feedback and platform enhancements.


Value

Continuous Integration and Continuous Delivery (CI/CD) Platform Engineering


Design, implement, and maintain fully automated CI/CD pipelines for Java, .NET, and Node.js applications.
Build standardized deployment workflows across Amazon Web Services (AWS) and/or Microsoft Azure environments.
Implement automated testing, security scanning, and quality gates within pipelines.
Establish reusable pipeline templates and shared libraries to enforce best practices.
Optimize build and deployment performance, reliability, and observability.


Cloud and Infrastructure Automation


Design and manage cloud infrastructure in AWS and/or Azure using infrastructure as code, with Terraform required.
Build reusable Terraform modules and enforce governance through policy-as-code.
Implement secure, scalable networking and cloud-native architecture patterns.
Ensure high availability, scalability, and disaster recovery readiness.


DevOps and Platform Best Practices


Implement monitoring, logging, and alerting strategies for both infrastructure and applications.
Integrate DevSecOps practices, including vulnerability scanning and secrets management.
Lead proof-of-concept initiatives to evaluate and introduce new tools, platforms, and automation processes.


Required Qualifications


10 or more years of progressive experience in software engineering, DevOps, cloud engineering, or platform engineering.
Demonstrated evolution from software development into cloud infrastructure and automation.
Six or more years of hands-on experience with CI/CD tools, such as Harness, CloudBees, Jenkins, and Azure DevOps, and modern software delivery practices.
Deep development expertise in Java and/or Node.js application environments.
Strong hands-on experience with AWS and/or Azure, including networking, serverless, and other managed cloud infrastructure.
Advanced proficiency with Terraform and infrastructure as code principles.
Experience designing scalable cloud-native architectures.
Strong knowledge of Windows Server and Microsoft SQL Server, including SQL Server Availability Groups.
Strong scripting skills using Python, PowerShell, Bash, or similar technologies.
Experience with automation technologies such as Terraform, Ansible, and AWS CloudFormation.
Strong understanding of secure software delivery, Git branching strategies, and DevSecOps practices.
Experience with containerization technologies such as Docker and Kubernetes.
Experience leading technical evaluations and proof-of-concept initiatives for new tools and processes.
Excellent collaboration skills with the ability to work cross-functionally across engineering, security, and operations teams.
Clear, transparent communication style with a bias toward documentation and shared ownership.


Preferred Qualifications


Experience building or implementing a commercial Internal Developer Portal, such as Harness IDP, Port, or a similar platform.
Experience implementing platform engineering concepts and developer self-service models.
Familiarity with service mesh, application programming interface (API) gateways, or cloud-native networking.
Experience implementing security automation and compliance guardrails.
Knowledge of observability platforms, including Datadog, Prometheus, Elasticsearch, Logstash, and Kibana (ELK), and cloud-native tools.
Experience in multicloud or hybrid cloud environments.


Education And Experience


Bachelor’s degree or higher in computer science, engineering, mathematics, information systems, or a related technical field.


Certificates and Licenses


Valid driver’s license required.
AWS and/or Azure certifications preferred; professional-level or specialty certifications preferred.
Additional certifications in DevOps, Kubernetes, or cloud technologies are a plus.


Supervisory Responsibilities

This position has no supervisory responsibilities.

Work Environment


Standard indoor working environment.
Occasional long periods of sitting while working at a computer.
Position requires regular interaction with employees at all levels of the Firm, as well as interaction with external vendors and clients as necessary.
Independent travel requirement: up to 10%.
