About the Role




We are seeking a Senior DevOps Engineer with 7+ years of experience to support and evolve our AWS-based infrastructure. This role requires strong hands-on experience with AWS, Terraform, ECS, EC2, Lambda, CI/CD, networking, security, and observability. You’ll collaborate closely with engineering, product, and data teams to improve the reliability, automation, security, scalability, and performance of our cloud infrastructure.




Candidates must be available to work 2:00 PM - 11:00 PM IST. This is the standard working schedule for this position and is mandatory.




Responsibilities




Provision, maintain, and improve AWS infrastructure using Terraform, including networking, IAM, compute, databases, and shared services.
Operate and maintain production workloads across Amazon ECS, EC2, AWS Lambda, and API Gateway.
Manage CI/CD pipelines using GitHub Actions, Jenkins, Bitbucket, and Bitbucket Pipelines, including Jenkins shared libraries.
Manage monitoring, observability, and alerting using CloudWatch, Prometheus, Grafana, New Relic, PagerDuty, and similar tools.
Maintain a security-first approach to cloud infrastructure, proactively identifying and remediating security risks and vulnerabilities using tools such as Wiz and AWS-native security services.
Manage IAM, Secrets Manager, KMS policies, certificates, and secure access controls, following least-privilege and cloud security best practices.
Lead production troubleshooting, root cause investigations, reliability improvements, and performance optimizations.
Automate operational workflows using scripting and tools such as Python, Bash, Packer, and Ansible.




Qualifications




Bachelors Degree, 7+ years of experience in DevOps, Cloud Infrastructure, SRE, or Platform Engineering roles.




Required Skills




Strong hands-on experience with AWS services including ECS, EC2, Lambda, API Gateway, S3, IAM, Route 53, RDS, ElastiCache, CloudWatch, and Load Balancers.
Advanced experience with Terraform for Infrastructure-as-Code and managing AWS resources.
Strong experience with Docker and Amazon ECS for running production containerized workloads.
Strong CI/CD experience with GitHub Actions, Jenkins, Bitbucket, Bitbucket Pipelines, or similar platforms.
Strong understanding of AWS networking including VPCs, routing, security groups, load balancers, NAT Gateways, DNS, VPC endpoints, and private connectivity.
Strong understanding of cloud security fundamentals, including IAM, least-privilege access, secrets management, encryption, vulnerability remediation, and secure infrastructure configuration.
Experience with cloud security and auditing tools such as Wiz, CloudTrail, GuardDuty, AWS Config, or equivalent platforms.
Experience with monitoring and observability tools such as CloudWatch, Prometheus, Grafana, and New Relic.
Strong Linux system administration, troubleshooting, and shell scripting skills.
Experience supporting production systems, troubleshooting complex infrastructure issues, and leading root cause analysis (RCA).




Preferred Skills




Familiarity with PHP/Laravel environments, including Laravel workloads running on AWS Lambda using Bref.
Experience supporting Java-based microservices.
Experience with Kubernetes/EKS, including operating MongoDB or Elasticsearch workloads.
Experience with Packer and Ansible for AMI creation and infrastructure automation.
Relevant AWS or Kubernetes certifications.
