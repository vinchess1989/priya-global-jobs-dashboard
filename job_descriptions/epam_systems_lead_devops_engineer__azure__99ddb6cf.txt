Drive cloud transformation for Canada's #1 retail brand through hands-on DevOps engineering and infrastructure automation. Join our Cloud Operations & Automation team to build enterprise-grade Azure and GCP platforms while delivering innovative solutions.

At EPAM, you'll work on cutting-edge technologies, solve complex challenges, and shape the future of digital innovation. With access to continuous learning, mentorship, and global projects, your expertise will drive meaningful change.

Req.#1036604900

The recruiting efforts for this position are intended to fill an existing vacancy to backfill a role.

Responsibilities


Develop and deploy Infrastructure as Code using Terraform to build scalable Azure cloud infrastructure and services
Automate Linux and Windows systems administration using Bash, PowerShell, and Python in enterprise environments
Build and maintain CI/CD pipelines using Jenkins, Ansible, ADO, and other automation tools for development programs
Implement security best practices and compliance validation through automated infrastructure hardening and monitoring
Collaborate with architects, security engineers, and project leads to deliver enterprise-grade cloud native solutions
Create comprehensive technical documentation and communicate project timelines, dependencies, and progress effectively


Requirements


5+ years of technical experience in development, operations, or full-stack implementations with proven DevOps expertise
Expert-level proficiency in Azure cloud services and advanced Infrastructure as Code development using Terraform
Advanced Linux server administration skills with strong networking fundamentals including VNETs, subnetting, and security groups
Expert knowledge of build automation tools including Jenkins, Artifactory, Ansible, and Azure DevOps (ADO)
Experience with container technologies including Docker, Kubernetes, and Helm in production environments
Computer Science or Engineering degree or equivalent relevant experience with Agile Scrum methodology knowledge (Optional)
