Responsibilities

We are seeking a Public Cloud DevOps Engineer with expertise in both Azure and AWS, with one being the primary platform and the other as secondary. Proficiency in Infrastructure as Code (IaC) is essential, as it is our primary approach to infrastructure management. Strong scripting skills in any programming language are also required. Strong hands-on skills required on:


AWS:
Responsible for the creation and management of endpoints, building and maintaining Amazon Machine Images (AMIs), and patching EC2 instances.
Expertise in deploying, configuring, and managing EC2 instances and related services.
Ability to handle and manage reverse proxy configurations to ensure efficient routing and load balancing.
Familiarity with network activities, including VPC configurations, security groups, and network ACLs, is highly desirable.
Azure:
Responsible for the creation and management of endpoints, building and maintaining Azure Virtual Machine images, and patching Azure Virtual Machines,
Expertise in deploying, configuring, and managing Azure Virtual Machines and related services.
Ability to handle and manage reverse proxy configurations using Azure Application Gateway or Azure Front Door for efficient routing and load balancing.
Familiarity with network activities, including Azure Virtual Network configurations, Network Security Groups (NSGs), and Azure Firewall, is highly desirable.
Containerization: Experience with Docker, particularly in deploying and managing applications on Kubernetes.
Infrastructure as Code (IaC): Proficient in using Ansible and Terraform, including the ability to write Terraform configurations and manage them from the ground up.
Continuous Integration/Continuous Deployment (CI/CD): Skilled in writing Jenkins or Github Actions pipelines and YAML configuration files.
CI/CD Solution Implementation: Capable of setting up complete CI/CD solutions to streamline development and deployment processes.
Operating Systems: Proficient in troubleshooting OS issues, with a strong focus on Linux and networking.


Candidates should have a proven track record of successful experiences in production within cloud environments, along with strong written and verbal communication skills.

Mastery of Agile methodology is essential, as is the ability to collaborate effectively within a distributed, cross-country team
