We are looking for a skilled and experienced DevOps Engineer with 4 to 5 years of experience to manage, automate, and optimize cloud infrastructure and software deployment processes.

The ideal candidate should have strong experience in cloud platforms, CI/CD pipelines, containerization, infrastructure automation, and production monitoring. The role involves working closely with development, QA, and engineering teams to ensure the reliability, security, scalability, and performance of cloud-based healthcare and IoT applications.

Key Requirements


4 to 5 years of hands-on experience in DevOps, cloud infrastructure, or Site Reliability Engineering.
Experience working with healthcare technology, medical devices, or IoT-based applications.
Strong experience with at least one major cloud platform: AWS, Azure, or Google Cloud Platform (GCP).
Hands-on experience with CI/CD tools such as Jenkins, GitHub Actions, GitLab CI/CD, or Azure DevOps.
Proficiency in Docker and Kubernetes for containerization and orchestration.
Experience with Terraform, Ansible, or equivalent infrastructure automation tools.
Strong knowledge of Linux administration, shell scripting, and networking fundamentals.
Experience with Git and source code management workflows.
Knowledge of monitoring and logging tools such as Prometheus, Grafana, ELK Stack, or CloudWatch.
Scripting experience using Python, Bash, or Shell.
Understanding of cloud security, IAM, SSL/TLS, firewall configurations, and secure deployment practices.
Strong troubleshooting, analytical, and problem-solving skills.


Key Responsibilities


Develop and manage CI/CD pipelines to automate application build, testing, and deployment processes.
Deploy and manage containerized applications using Docker and Kubernetes.
Automate infrastructure provisioning and configuration using Infrastructure as Code (IaC) tools such as Terraform and Ansible.
Monitor application performance, server health, and infrastructure availability using appropriate monitoring and logging tools.
Manage Linux-based servers, networking configurations, and cloud environments.
Implement security best practices, including access management, encryption, vulnerability management, and secrets management.
Troubleshoot infrastructure, deployment, and production issues to ensure minimal downtime.
Implement backup, disaster recovery, and high-availability strategies.
Collaborate with software development, testing, and product engineering teams to improve deployment efficiency and system reliability.
Maintain technical documentation, deployment procedures, and operational processes.
