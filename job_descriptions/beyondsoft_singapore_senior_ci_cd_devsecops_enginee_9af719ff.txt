Responsibilities


Design, build and maintain CI/CD pipelines that automate build, test, security scanning and deployment
Integrate security controls and vulnerability scanning into every stage of the software delivery lifecycle
Provision and manage infrastructure using Infrastructure as Code tools such as Ansible or Terraform
Manage container platforms and Kubernetes clusters, and cloud infrastructure
Maintain source code, artifact and configuration repositories
Implement monitoring, logging and observability for environments and pipelines
Ensure compliance with agreed security frameworks and remediate vulnerabilities together with development and operations teams
Document pipelines and operating procedures and support release management



Qualifications


Bachelor's degree in Software Engineering, Computer Science or equivalent
Understanding of DevSecOps principles and practices, with special focus on full automation, consistent environments within the lifecycle and process observability
Integrates security into every stage of the software delivery lifecycle, ensuring applications and infrastructure are secure by design
Drive compliance with agreed security frameworks
Responsible for designing and maintaining a secure system architecture for application development and deployment
Experience in automation of software production, integration, testing and deployment including dynamic deployment of running environment
Experience in Cloud infrastructure and Kubernetes
Experience in infrastructure provisioning and platform configuration with Configuration Management tools like Ansible or Terraform or equivalent, deployment observability and analysis
Experience in system administration with main OS events management and scripting languages, Linux system observability and analysis
Source Code Management and GitOps principles, pipeline automation
Repositories deployment, configuration and management
Data parsing & manipulation, Extract, Transform and Load solutions and Stream Management solutions
Knowledge of DevOps tools and technologies, including but not limited to Jenkins, GitLab CI/CD, Docker, Kubernetes, Ansible, Terraform, and cloud platforms such as AWS, Azure, or Google Cloud
