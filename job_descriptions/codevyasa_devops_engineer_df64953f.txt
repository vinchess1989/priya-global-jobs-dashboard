Responsibilities


Design, implement, and manage CI/CD pipelines for seamless deployment.
Manage and optimize cloud infrastructure on AWS.
Deploy, monitor, and maintain containerized applications using Kubernetes.
Automate infrastructure provisioning using tools like Terraform/CloudFormation.
Monitor system performance, troubleshoot issues, and ensure high availability.
Collaborate with development teams to streamline release cycles.
Implement security best practices across infrastructure and deployments.


Requirements


Strong experience in DevOps practices and tools.
Hands-on experience with AWS services (EC2 S3 RDS, IAM, VPC, etc. ).
Solid experience with Kubernetes (deployment, scaling, troubleshooting).
Experience with CI/CD tools (Jenkins, GitHub Actions, GitLab CI, etc. ).
Proficiency in scripting (Bash, Python, or similar).
Understanding of containerization (Docker).
Good knowledge of monitoring tools (Prometheus, Grafana, CloudWatch).
