Role Description

We are seeking a highly experienced and hands-on DevOps CI/CD Engineer to own the implementation, administration, optimization, and governance of our enterprise GitHub and CI/CD ecosystem. This is a technical ownership and engineering role — not a traditional support position. You will be responsible for designing and maintaining scalable CI/CD workflows, establishing enterprise GitHub standards, troubleshooting complex pipeline issues, and driving adoption of modern DevOps and DevSecOps practices across engineering teams. You will work closely with development, QA, operations, security, architecture, and cloud engineering teams to build reliable, secure, and highly automated software delivery processes. The ideal candidate brings deep expertise in GitHub Enterprise, GitHub Actions, Azure DevOps, Git, Docker, Azure, AWS and AKS, combined with strong troubleshooting, automation, and stakeholder-management capabilities. 8+ years of overall technical IT experience, with significant hands-on experience in DevOps, CI/CD, or Platform Engineering. Proven experience managing and supporting GitHub Enterprise environments. Strong hands-on experience with GitHub Actions and Azure DevOps. Deep understanding of Git, branching strategies, pull requests, code reviews, and repository governance. Proven experience designing, implementing, troubleshooting, and optimizing CI/CD pipelines. Hands-on experience with Docker and Azure Kubernetes Service (AKS). Strong hands-on experience with Microsoft Azure. Experience implementing DevSecOps practices within CI/CD pipelines. Strong troubleshooting and debugging skills. Experience writing automation scripts using PowerShell, Bash, Python, or similar technologies. Demonstrated ability to work independently and collaborate effectively across global engineering teams. Strong communication, analytical, and problem-solving skills

Skills

GitHub, CI/CD, GitHub Actions, Azure DevOps, DevOps, DevSecOps, Azure Kubernetes Service, Docker, Microsoft Azure, PowerShell
