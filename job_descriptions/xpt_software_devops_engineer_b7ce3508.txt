We are looking for an experienced DevOps / Platform Engineer for an immediate contract opportunity in Sydney. In this role, you will be responsible for maintaining and optimizing CI/CD pipelines, automating deployment workflows, and supporting enterprise Linux/RHEL environments and application infrastructure.


Key Responsibilities



Build, maintain, and optimize CI/CD automation pipelines using Jenkins.


Manage containerized workloads and environments using Podman / Docker.


Automate infrastructure provisioning and deployment using Cookbook or similar deployment automation tools.


Administer, configure, and troubleshoot RHEL (Red Hat Enterprise Linux) servers and system services.


Develop scripts for task automation using Python and Linux Bash Shell Scripting.


Support backend services built on Java Spring Boot.


Monitor system health, logs, and performance metrics using the Elastic Stack (ELK).


Mandatory Skills & Qualifications



Containerization: Podman / Docker


Programming & Scripting: Python, Linux Bash Shell Scripting


Frameworks: Java Spring Boot


Operating Systems: Red Hat Enterprise Linux (RHEL)


Monitoring & Logging: Elastic Stack (ELK)


CI/CD: Jenkins


Deployment Automation: Cookbook (Chef) or equivalent deployment tools
