Role: Senior DevOps Engineer

Location: Hybrid - Leicester

Employment Type: Full-time

Salary: £65,000 - £75,000 + Benefits




Are you a passionate DevOps Engineer with extensive experience in cloud technologies, automation, and modern software delivery practices? We're looking for a Senior DevOps Engineer to play a key role in driving platform innovation, enabling development teams, and delivering scalable, secure, and highly automated cloud solutions.




This is an opportunity to work within a technology-focused environment where continuous improvement, experimentation, and automation are at the heart of everything we do. You'll collaborate with Software Engineers, Architects, QA teams, and Security specialists to build and enhance cloud-native platforms that enable rapid and reliable product delivery.




We're seeking an experienced engineer who thrives in a fast-paced environment, enjoys solving complex technical challenges, and wants to influence the future direction of cloud and DevOps practices.




What You'll Do




Design, build and maintain enterprise-scale CI/CD pipelines using Azure DevOps and YAML
Automate infrastructure provisioning and configuration through Infrastructure-as-Code using Terraform
Develop, manage and support cloud environments across Development, Test, Pre-Production and Production
Drive automation initiatives that improve deployment speed, reliability and operational efficiency
Implement automated testing and quality controls throughout the software delivery lifecycle
Manage source control repositories, branching strategies and release processes
Build and maintain containerised platforms using Docker and Kubernetes
Support cloud migration and application modernisation initiatives
Implement DevSecOps practices and embed security throughout development and deployment pipelines
Monitor, troubleshoot and optimise application and infrastructure performance
Work closely with development teams to improve application reliability, scalability and resilience
Create and maintain technical documentation, architectural designs and operational standards
Collaborate with Architects and stakeholders to define and deliver cloud solutions
Mentor junior engineers and promote DevOps best practices across engineering teams
Participate in on-call support for critical business systems and services
Identify opportunities for continuous improvement, automation and platform enhancement




Required Experience




5+ years' experience in DevOps, Platform Engineering, Cloud Engineering or Site Reliability Engineering
Strong experience designing and managing CI/CD pipelines using Azure DevOps
Extensive Infrastructure-as-Code experience using Terraform
Strong commercial experience with Microsoft Azure cloud services
Experience deploying and managing Docker containers and Kubernetes platforms
Knowledge of cloud-native architectures and microservices-based applications
Experience implementing DevSecOps principles and security-focused automation
Strong scripting skills using PowerShell and Bash
Experience working with Git and source control best practices
Experience supporting Windows and Linux server environments
Strong understanding of networking principles, application hosting and cloud infrastructure
Experience with SQL Server and NoSQL database platforms
Excellent troubleshooting, analytical and problem-solving skills
Strong communication skills with the ability to work effectively across technical and non-technical teams
Experience working within Agile delivery environments

Nice to Have

Experience with monitoring and observability platforms such as Dynatrace, Grafana or OpenTelemetry
Experience using security tooling including SonarCloud, Prisma Cloud or CrowdStrike
Azure certifications such as AZ-104, AZ-305 or AZ-400
Exposure to Platform Engineering and self-service infrastructure models
Experience within large-scale, high-availability environments
Cloud cost optimisation and FinOps experience
Experience driving engineering best practices and technical transformation initiatives




This role is ideal for a Senior DevOps Engineer who enjoys combining hands-on technical delivery with strategic platform improvement. You'll be given the opportunity to shape cloud adoption, influence engineering standards, and build modern, automated solutions that enable development teams to deliver software faster, safer and more efficiently.




If you're passionate about cloud technologies, automation, Kubernetes, DevOps culture and continuous improvement, we'd love to hear from you.
