Job Description:




Location: Sandton, Gauteng

Relevant Experience: 8+ Years

Employment Type: Permanent/contract




Role Summary

We are seeking an experienced Azure DevOps Engineer to design, implement, and manage scalable cloud infrastructure, CI/CD pipelines, and automation solutions on Microsoft Azure. The ideal candidate will have strong expertise in Azure services, Infrastructure as Code (IaC), containerization, and DevSecOps practices.




Key Responsibilities

• Design, build, and maintain Azure cloud infrastructure and DevOps solutions.

• Develop and manage CI/CD pipelines using Azure DevOps, GitHub Actions, or similar tools.

• Automate infrastructure provisioning using Terraform, ARM Templates, or Bicep.

• Implement and manage containerized workloads using Docker and Kubernetes (AKS).

• Monitor application and infrastructure performance using Azure Monitor, Log Analytics, and Application Insights.

• Implement security best practices, vulnerability management, and DevSecOps controls.

• Collaborate with development, testing, and operations teams to streamline software delivery.

• Manage source control, branching strategies, and release management processes.

• Troubleshoot deployment, performance, and infrastructure issues.

• Ensure high availability, scalability, and disaster recovery of Azure environments.




Required Skills & Experience

• Strong experience with Microsoft Azure cloud services.

• Hands-on experience with Azure DevOps and CI/CD pipeline implementation.

• Proficiency in Terraform, ARM Templates, or Bicep.

• Experience with Docker, Kubernetes (AKS), and container orchestration.

• Strong scripting skills in PowerShell, Bash, or Python.

• Experience with Git-based source control systems.

• Knowledge of networking, security, identity management, and monitoring in Azure.

• Understanding of Agile, DevOps, and Site Reliability Engineering (SRE) practices.

• Experience with Infrastructure as Code (IaC) and automation frameworks.




Preferred Qualifications

• Microsoft Azure certifications such as:

o Azure Administrator Associate (AZ-104)

o Azure DevOps Engineer Expert (AZ-400)

o Azure Solutions Architect Expert (AZ-305)

• Experience in banking, financial services, or regulated environments.

• Exposure to multi-cloud environments (AWS/GCP) is advantageous.
