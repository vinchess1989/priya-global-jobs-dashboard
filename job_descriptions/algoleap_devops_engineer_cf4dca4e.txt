Owns delivery automation for every migration workstream. Builds the CI/CD pipelines, infrastructure as code and release processes that let the team ship the web application, APIs, functions and database changes to Azure safely and repeatedly.

Key Responsibilities

‒ Build and maintain multi-stage YAML pipelines in Azure DevOps covering build, test, security scanning and deployment.

‒ Author and maintain infrastructure as code (Terraform) for all environments.

‒ Manage configuration and secrets through Key Vault and pipeline variable groups.

‒ Define branching strategy, pull request policies and quality gates; wire automated test suites into the pipelines.

‒ Run release management: deployment slots, blue-green deployment, approvals and rollback.

‒ Automate database deployments (DACPAC or migration-based) alongside application releases.

Required Skills And Experience

‒ Deep Azure DevOps experience: Repos, Pipelines, Boards, Artifacts and YAML pipeline authoring.

‒ Infrastructure as code with Bicep or Terraform in production.

‒ Strong Git workflow knowledge and build experience for .NET applications.

‒ Scripting with PowerShell or Bash for automation.

‒ Deploying to Azure App Service, Functions and Azure SQL from pipelines.

‒ Secrets management, service connections and pipeline security best practices.

Preferred Qualifications

‒ AZ-400 certification.

‒ Container experience (Docker, Azure Container Apps or AKS).

‒ Code quality and security tooling such as SonarQube or dependency scanning.
