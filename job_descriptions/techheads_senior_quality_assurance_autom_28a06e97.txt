Senior Test Automation Engineer | Greenfield Healthcare Technology

Permanent ¦ Hybrid ¦ Limerick

€60,000 - €75,000 DOE + Excellent Benefits




Help build the next generation of healthcare technology.

Are you an experienced Software Test Automation Engineer with a background in MedTech, medical devices, diagnostics or regulated healthcare software?

We're partnering with a leading global healthcare technology organisation in Limerick on an exciting greenfield software development project.

This is an opportunity to join a growing engineering team developing a modern enterprise software platform that integrates web applications, APIs, backend services and connected medical hardware.

You'll have the opportunity to shape automation frameworks, influence testing practices and help ensure the reliability of technology used in healthcare environments.




The Opportunity

As a Senior Software Test Automation Engineer, you'll play a key role in developing and implementing automated testing solutions across a complex, integrated software platform.

You'll work closely with software developers, systems engineers and other technical teams to validate end-to-end functionality, identify integration issues and establish robust automated testing practices. This is a hands-on engineering role, offering the opportunity to contribute to automation architecture and testing strategy while remaining actively involved in coding and technical problem-solving.




What You'll Be Doing

Design, develop and maintain automated test frameworks for enterprise web applications and APIs.
Develop automated tests using Python, TypeScript or C#.
Work with Playwright, Selenium or similar automation frameworks.
Perform system-level, integration and end-to-end testing across interconnected software components.
Validate data integrity and application behaviour using SQL.
Test workflows involving APIs, backend services and connected hardware.
Investigate complex defects and collaborate with engineering teams to identify root causes.
Integrate automated tests into CI/CD pipelines using Azure DevOps, Git and related tools.
Contribute to test coverage, traceability and quality practices appropriate to a regulated healthcare environment.
Help shape the automation approach for a new software platform from an early stage.




What We're Looking For

5+ years' experience in software QA, test automation or software development in test.
Strong hands-on experience writing automation code using at least one of Python, TypeScript or C#.
Commercial experience with Playwright, Selenium or comparable web automation tools.
Experience automating REST API testing.
Practical SQL skills, including writing queries to validate backend data.
Strong understanding of system integration, end-to-end testing and troubleshooting.
Experience using Git and CI/CD tools, ideally Azure DevOps.
Ability to work closely with developers and take ownership of automation solutions.




MedTech & Healthcare Experience – Highly Desirable

We are particularly interested in engineers who have worked in environments involving:

Medical-device software development or verification and validation.
Healthcare technology, diagnostics or clinical software platforms.
Regulated software development and testing, including GxP or IEC 62304 environments.
Software integration with medical devices, instruments or connected hardware.
Healthcare interoperability standards such as HL7 or FHIR.
Quality and compliance practices involving traceability, validation evidence and controlled releases.




Why Consider This Opportunity?

Greenfield project: Help establish automation frameworks and testing practices from the beginning.
Meaningful technology: Contribute to software that supports healthcare innovation.
Modern engineering environment: Work across web applications, APIs, backend services and connected systems.
Technical ownership: Influence automation architecture while remaining hands-on.
Long-term opportunity: Join an established global healthcare technology organisation.
Hybrid working: Limerick-based, with 3–4 days onsite.
Permanent position: Competitive salary and benefits package.




Interested?

If you're a Software Test Automation Engineer with strong coding skills and an interest in MedTech or regulated healthcare software, we'd love to hear from you.
