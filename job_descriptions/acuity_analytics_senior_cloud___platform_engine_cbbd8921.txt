About the role




We're looking for a Senior Cloud Engineer to build and run enterprise Azure platform capabilities for a team that works on a big data analytics platform in a large, regulated environment.




This is a hands-on engineering role for someone who treats infrastructure as software: secure, automated, tested and maintainable. You'll enable data and application teams with reliable, compliant and scalable cloud solutions.




The key ingredients for this role are solid Azure background, experience with Azure Databricks, Azure Data Lake Storage (ADLS), Terraform, Powershell/Python, ADO, strong communication skills, excellent English, systems-level thinking, strong ownership.




Responsibilities




Independently design, develop and operate enterprise-grade Azure platform components using Terraform, PowerShell and Azure DevOps.
Apply software engineering practices to infrastructure and automation: reusable design, automated testing, code reviews and version management.
Own platform changes end-to-end, from implementation through CI/CD and release to operational handover.
Run handover sessions and share knowledge with Operations, Service Desk and the four other DevOps teams, and present your results clearly.
Support ops colleagues during incidents.
Contribute to engineering standards and best practices and develop a specialty within the team.




Required skills




5+ years of hands-on experience engineering and operating enterprise Azure platforms
Solid experience in Azure Databricks, platform side only (workspaces, access and networking via Terraform), and Azure Data Lake Storage (ADLS)
Expert level Terraform skills as your primary IaC tool
Expert level experience with Azure DevOps pipelines (build and release): YAML, reusable templates, approvals and environments
Advanced scripting skills in PowerShell (preferred) or Python, including automated testing and artifact/version management
Professional-level software engineering applied to infrastructure: IaC, reusable design, automated deployments and tests, code reviews and version management. This is not portal-based or point-and-click work.
Networking: VNets, private endpoints and NSGs
Identity and security: managed identities, service principals and role assignments
Experience working in a regulated environment
A proactive, can-do mindset, systems-level thinking, strong troubleshooting, advanced communication skills in English and a quality-first approach (automation first, documentation discipline)




Highly advantageous




Hub-and-spoke network architectures
Wider Microsoft Entra ID integration, including app registrations
Azure AI Search, Azure Cosmos DB, Azure Data Factory
Azure Monitor, Log Analytics, Application Insights
German language proficiency
