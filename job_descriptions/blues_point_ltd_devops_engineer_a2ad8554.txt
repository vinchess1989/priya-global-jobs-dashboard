DevOps Engineer

Remote UK | £65,000–£70,000 per annum

Are you an experienced DevOps Engineer who enjoys improving deployment processes, supporting cloud-hosted applications and making systems more reliable, secure and efficient?

We’re looking for a hands-on DevOps Engineer to support and enhance a portfolio of bespoke business applications, microservices and cloud-hosted services running on Microsoft Azure.

This is an application-focused role, combining deployment management, automation, monitoring and operational support. You’ll work closely with software developers, infrastructure specialists and security teams to ensure applications run smoothly, deployments are consistent and issues are resolved quickly.

You’ll have the opportunity to improve existing processes, strengthen automation and help shape the way applications are deployed, monitored and supported across development, test and production environments.

While you’ll need a strong understanding of Azure, Docker, Kubernetes, Helm and Terraform, responsibility for wider enterprise infrastructure, networking and overall cloud architecture sits with the Infrastructure team. Your focus will be on the application platform and its day-to-day operation.

The Role

Your responsibilities will include:

Supporting, maintaining and improving production applications, microservices and distributed systems hosted in Microsoft Azure.
Managing and enhancing deployment processes, CI/CD pipelines and release workflows using Azure DevOps and Git.
Supporting containerised applications running on Docker and Kubernetes, including deployments and configuration management using Helm.
Developing and maintaining Infrastructure as Code using Terraform to enable consistent, repeatable and controlled deployments.
Maintaining Azure application environments and supporting services, including App Services, Azure Functions, Storage, Key Vault and Azure Kubernetes Service (AKS).
Monitoring application health, availability and performance, implementing effective logging, alerting and observability.
Investigating and resolving issues across applications, APIs, integrations, databases and supporting services.
Managing application configuration, secrets, environment variables and deployment settings across multiple environments.
Supporting Linux-hosted services, scheduled jobs and background processing workloads.
Identifying opportunities to improve automation, operational efficiency, deployment reliability and support processes.
Working with development teams to improve application monitoring, supportability and deployment standards.
Collaborating with Infrastructure and Cyber Security teams to resolve issues and deliver platform improvements.
Maintaining clear technical documentation, operational procedures and support runbooks.
About You

You’ll be a practical, technically capable DevOps Engineer with experience supporting live applications and improving the processes and platforms that keep them running reliably.

You’ll ideally have:

Strong experience supporting production applications, microservices and distributed systems.
Hands-on experience with Microsoft Azure, particularly application hosting, deployment and operational support.
Experience with Azure DevOps, Git, CI/CD pipelines and modern software delivery practices.
Strong experience with Docker, Kubernetes and Helm in production environments.
Experience developing and maintaining Terraform-based Infrastructure as Code within Azure.
Good Linux administration skills, ideally with Ubuntu, including troubleshooting, configuration, monitoring and performance optimisation.
Experience with monitoring, logging, alerting and observability tools such as Azure Monitor, Application Insights, Prometheus or Grafana.
The ability to troubleshoot complex application, API, integration and platform issues.
Experience managing application configuration, secrets and environment-specific deployment settings.
Familiarity with Azure services such as App Services, Functions, Storage Accounts, Key Vault and AKS.
Experience supporting data platforms such as SQL Server, PostgreSQL, Cosmos DB and/or Redis.
An understanding of secure software delivery, DevSecOps and operational resilience.
Strong problem-solving skills and the ability to work collaboratively with technical teams and business stakeholders.

Experience with Bash, PowerShell or Python for scripting and automation would also be beneficial.

Technology Environment

You’ll be working across a modern cloud and application technology stack, including:

Cloud platform: Microsoft Azure, App Services, Azure Functions, Storage, Key Vault, AKS
DevOps and deployment: Azure DevOps, Git, CI/CD pipelines
Containers and orchestration: Docker, Kubernetes, Helm
Infrastructure as Code: Terraform
Monitoring and observability: Azure Monitor, Application Insights, Prometheus, Grafana
Operating systems and scripting: Ubuntu Linux, Bash, PowerShell, Python
Application platforms: Microservices, REST APIs, distributed applications and background processing services
What’s on Offer?
Salary of £65,000–£70,000 per annum, depending on experience.
Fully remote working within the UK.
The opportunity to work with a modern Azure-based application platform.
A varied, hands-on role combining cloud technologies, automation, deployment engineering and problem-solving.
The chance to improve operational processes and make a tangible difference to application reliability and delivery.

If you’re passionate about DevOps, enjoy getting to the root of technical problems and want to help build more reliable, automated and maintainable application environments, we’d love to hear from you.
