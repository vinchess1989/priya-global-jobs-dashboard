Job Description

We are looking for a highly skilled Platform DevOps Engineer with a strong development background to join our dynamic engineering team. In this role, you will bridge the gap between software development and IT operations, ensuring the reliability, scalability, and security of our cloud infrastructure and deployment pipelines. Since our core product is built on .NET/C#, your ability to collaborate closely with development teams and understand their ecosystem will be crucial.

Responsibilities:


Infrastructure Management: Design, provision, and maintain secure and scalable cloud infrastructure on AWS, utilizing services like EKS (Elastic Kubernetes Service) and ECS (Elastic Container Service).
CI/CD Pipeline Automation: Build, maintain, and optimize robust CI/CD pipelines using GitLab CI and Azure DevOps to ensure smooth and automated software delivery.
Infrastructure as Code (IaC): Utilize Terraform for provisioning and managing cloud resources and Ansible for configuration management and application deployment.
Software Development & Automation: Write high-quality, maintainable code for automation, tooling, and system integrations using Python
Platform Reliability: Monitor system performance, troubleshoot complex infrastructure issues, and implement proactive solutions to ensure high availability and minimal downtime.
Cross-Functional Collaboration: Work closely with our .NET development teams to streamline the development lifecycle, optimize application architecture for the cloud, and foster a culture of DevOps best practices.


Qualifications


Experience: Minimum of 4 years of hands-on experience in a DevOps, Platform Engineering, or Software Engineering role.
Development Background: Proven background in software development with strong algorithmic and problem-solving skills.
Highly proficient in Python, with hands-on experience developing automation scripts, tools, and solutions to improve infrastructure, deployment, and operational processes.
Cloud Platforms: Extensive experience with AWS ecosystem, with deep knowledge of container orchestration using EKS and ECS.
CI/CD Tools: Strong hands-on experience with GitLab CI and Azure DevOps.
Automation & IaC: Proficiency in Infrastructure as Code (IaC) using Terraform and configuration management using Ansible.
Source Control: Advanced knowledge of Git and branching strategies.


Nice to have:


NET Ecosystem: Experience or background working with .NET / C# technologies. A strong understanding of the .NET software development lifecycle will give you a significant advantage, as you will be supporting a product built on this stack.
Certifications: AWS Certified DevOps Engineer, Certified Kubernetes Administrator (CKA), or similar credentials.
