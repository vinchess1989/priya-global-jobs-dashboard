Requirement

Skilled Azure DevOps/Cloud Engineer to design, implement, and manage scalable, secure, and efficient cloud infrastructure and data platforms on Microsoft Azure.

Experienced in concepts such as Continuous Integration and Continuous Deployment, including hands on implementation experience in one or more tool e.g., GitHub, Azure Devops, GitLab Runner, Jenkins and AWS- CI/CD.

Strong experience with Azure Networking and access management.

Good experience with monitoring, logging, and alerting solutions to ensure the health, performance, and cost efficiency of the cloud platform.

Strong proficiency in Microsoft Azure services, including VMs, networking, Azure SQL Database, Data Lake Storage, and Azure AI services.

Strong programming experience in Shell scripting / Python.

Implementing applications in private/public cloud infrastructure and container technologies like Kubernetes and Docker/Docker Swarm.

Experience with Database server like MS-SQL, MySQL, PostgreSQL etc.

Good command on usage of GIT.

Experience working with Windows and Linux Based Infrastructure.

Experience working with IAC tools like Terraform, etc. IAC with mix of Helm Charts, Docker files, Terraform, Ansible, bash & YAML.

Excellent troubleshooting skills - Troubleshoot and resolve complex issues related to Azure services, infrastructure, and deployment pipelines, often as part of an on-call rotation.

Experience working as Databricks and Unity Catalog administration

Must Have

Azure, Terraform, GitHub, Azure Devops CICD

Good understanding of bash, powershell, YAML scripting.
