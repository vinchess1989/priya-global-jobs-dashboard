Job Description

My client, a technology-focused organisation, is seeking an experienced Senior DevOps Engineer to support the development, automation and optimisation of its cloud infrastructure and software delivery processes.




Job Responsibilities

Design, implement and maintain scalable, secure and highly available cloud infrastructure, primarily using AWS.
Develop and optimise CI/CD pipelines to streamline software deployment, testing and release management.
Automate infrastructure provisioning, configuration and management through Infrastructure as Code (IaC) technologies, including Terraform and Pulumi.
Manage containerised applications and orchestration environments using Docker and Kubernetes.
Collaborate closely with software engineering teams to support applications developed using TypeScript, Node.js and related technologies.
Implement effective monitoring, logging and alerting solutions to improve system performance, availability and reliability.
Identify opportunities to strengthen cloud security, optimise infrastructure costs and improve operational resilience.
Provide technical leadership, troubleshoot complex infrastructure issues and promote DevOps best practices across engineering teams.




Experience Required

5+ years' experience in DevOps Engineering, Cloud Engineering, Site Reliability Engineering or a related technical role.
Strong hands-on experience designing, deploying and managing production environments within AWS.
Proven experience implementing Infrastructure as Code using Terraform and/or Pulumi.
Extensive knowledge of containerisation technologies, particularly Docker and Kubernetes.
Demonstrated expertise in building, maintaining and improving CI/CD pipelines.
Strong understanding of Linux/Unix environments, networking, cloud security and infrastructure troubleshooting.
Experience supporting modern web applications and backend services, ideally involving TypeScript, JavaScript and Node.js.
Proficiency in scripting and automation using Python, Bash or similar languages.
Excellent problem-solving, communication and stakeholder management skills, with the ability to work independently and collaborate across technical teams.




Desirable Skills

Experience managing container orchestration environments using AWS ECS or Amazon EKS.
Familiarity with GitOps methodologies and automated infrastructure deployment practices.
Knowledge of monitoring and observability solutions such as Prometheus, Grafana or AWS CloudWatch.
Experience working with SQL databases and RESTful API-based applications.
Understanding of modern software development practices, including automated testing, version control and code reviews.
Exposure to cloud-native architecture, microservices and distributed applications.
Experience implementing DevSecOps practices, including vulnerability management, secrets management and automated security testing.
Previous experience mentoring engineers or contributing to technical architecture decisions.




Educational Requirements

Bachelor's degree or third-level qualification in Computer Science, Software Engineering, Information Technology or a related discipline.
Relevant AWS, Kubernetes or Terraform certifications would be advantageous.
