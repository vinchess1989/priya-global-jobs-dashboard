About the Role



We are looking for a skilled Cloud Engineer to design, implement, and support scalable cloud infrastructure and platform solutions. The ideal candidate will have hands-on experience with public cloud technologies, infrastructure automation, container platforms, and DevOps practices. You will work closely with development, security, and operations teams to ensure cloud environments are secure, reliable, and optimized.



Key Responsibilities


Design, deploy, and maintain cloud infrastructure on AWS, Azure, or Google Cloud Platform (GCP).
Implement Infrastructure as Code (IaC) using tools such as Terraform, CloudFormation, or ARM/Bicep templates.
Build and manage CI/CD pipelines to support application deployment and delivery.
Deploy, manage, and troubleshoot containerized applications using Docker and Kubernetes.
Monitor system performance, availability, and security across cloud environments.
Collaborate with development teams to improve scalability, reliability, and operational efficiency.
Implement cloud security best practices, including identity and access management, encryption, and vulnerability remediation.
Automate operational processes and routine administrative tasks.
Support incident management, root cause analysis, and disaster recovery planning.
Maintain technical documentation, architecture diagrams, and operational procedures.


Required Qualifications


Bachelor's degree in Computer Science, Information Technology, Engineering, or related discipline.
3+ years of experience in cloud engineering, infrastructure engineering, DevOps, or system administration.
Strong experience with at least one major cloud platform: AWS, Azure, or GCP.
Experience with Infrastructure as Code tools such as Terraform, CloudFormation, or Bicep.
Experience with containerization technologies including Docker and Kubernetes.
Knowledge of Linux and Windows server administration.
Experience with scripting or programming languages such as Python, Bash, PowerShell, or Go.
Hands-on experience with CI/CD tools such as GitHub Actions, GitLab CI, Jenkins, or Azure DevOps.
Understanding of networking concepts including DNS, VPN, load balancing, firewalls, and VPC/VNet architecture.
Strong troubleshooting and problem-solving skills.
