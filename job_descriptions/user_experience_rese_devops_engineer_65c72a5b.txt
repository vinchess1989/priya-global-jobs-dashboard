Key Responsibilities:

Provision, configure, and support AWS cloud infrastructure across enterprise environments, including compute, networking, storage, databases, containers, and related cloud services.
Develop and maintain Infrastructure as Code (IaC) and support automation of infrastructure provisioning, configuration, patching, and operational activities using Terraform, Ansible, AWS Systems Manager, Python, and Shell scripting.
Support CI/CD and DevOps workflows, including infrastructure deployment, configuration management, source-code management, security scanning, and automated operational processes.
Monitor infrastructure availability, performance, capacity, and security using cloud and enterprise monitoring/logging solutions; troubleshoot infrastructure and production issues and support root-cause analysis.
Implement and maintain infrastructure security controls, including IAM and least-privilege access, system hardening, patch management, vulnerability remediation, security findings, and audit/compliance requirements.
Collaborate with application, cybersecurity, network, cloud platform, and service provider teams, and maintain technical documentation, SOPs, operational runbooks, and infrastructure standards.




What We Are Looking For:

Bachelor's degree in Computer Science, Information Technology, Engineering, or a related discipline, or equivalent professional experience.
Minimum 3–5 years of relevant experience in ICT infrastructure, cloud engineering, DevOps, systems engineering, or infrastructure operations, with hands-on exposure to AWS environments.
Good knowledge of AWS services covering compute, networking, storage, databases, IAM, monitoring, and related cloud infrastructure services.
Hands-on experience with Terraform, Ansible, or equivalent Infrastructure as Code and configuration-management technologies.
Experience with CI/CD and source-control platforms such as GitLab CI/CD, Jenkins, GitHub Actions, Bitbucket, or equivalent technologies.
Good understanding of cloud and infrastructure security, including IAM, least privilege, vulnerability management, system hardening, patching, security findings remediation, and audit/compliance requirements.
Experience with scripting and automation using Python, Shell/Bash, AWS Systems Manager, or equivalent technologies.
Good analytical, troubleshooting, communication, and collaboration skills, with the ability to work effectively with application, infrastructure, cybersecurity, network, and service provider teams.
