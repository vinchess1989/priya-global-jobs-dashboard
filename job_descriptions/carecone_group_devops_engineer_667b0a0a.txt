JD:– high level "Onshore dev ops with cicd pipeline experience min 10+, snowflake experience will be ideal."




What you’ll do

• Design, build and maintain CI/CD pipelines for application and data workloads, from build and test through to deployment and release.

• Automate build, test, security scanning and deployment steps, so releases are repeatable and need less manual effort.

• Keep pipelines, infrastructure and environment configuration as code in source control.

• Build in the controls a bank expects: approvals, change records and evidence for audit.

• Work with developers, testers and platform teams to shorten feedback loops and cut failed releases.

• Monitor pipeline health, troubleshoot failures, and keep improving reliability and speed.

• Document reusable pipeline patterns so other teams can pick them up.




What you’ll bring

• [10+ years, confirm level] in DevOps or release engineering, with hands-on experience building pipelines.

• Working depth in at least one CI/CD toolset, for example Jenkins, GitLab CI, Azure DevOps or GitHub Actions

• Scripting and automation skills, for example Python, Bash or PowerShell.

• Infrastructure as code, for example Terraform, and container basics such as Docker and Kubernetes.

• Solid Git workflow, artifact management, and test automation inside pipelines.

• Experience on a major cloud platform [confirm: AWS or Azure].

• Practical understanding of secure delivery (DevSecOps) in a regulated environment.

• Clear communication, and comfort owning a problem from first alert to fix.




Nice to have

• Snowflake experience, ideally promoting Snowflake objects and data pipelines through environments with version control and CI/CD.

• Familiarity with data pipeline tooling, for example dbt.

• Banking or financial services delivery experience.
