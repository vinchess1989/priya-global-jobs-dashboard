We are seeking a skilled DevOps Engineer to design, implement, and maintain scalable infrastructure and deployment pipelines in the cloud. The ideal candidate has strong hands-on experience with Infrastructure as Code (IaC), Ansible, Terraform, and AWS, and is passionate about automation, reliability, and operational excellence.




You will work closely with engineering, security, and operations teams to build resilient, automated cloud environments that support fast and reliable software delivery.




Responsibilities:

CI/CD and Automation

Design, implement, and maintain CI/CD pipelines to automate build, test, and deployment processes.
Integrate automated testing and deployment into development workflows.
Improve software delivery speed and reliability through automation.




Infrastructure as Code

Develop and maintain Infrastructure as Code (IaC) using tools such as Terraform, CloudFormation, or Ansible.
Automate provisioning and management of cloud infrastructure.




Cloud Infrastructure Management

Deploy and manage infrastructure on cloud platforms.
Ensure infrastructure scalability, availability, and reliability.




Containerization and Orchestration

Build and manage containerized applications using Docker.
Deploy and manage applications using Kubernetes or other container orchestration platforms.




Monitoring and Logging

Implement monitoring, logging, and alerting solutions to maintain system health.
Analyze system performance and identify areas for improvement.




Collaboration and Development Support

Work closely with development teams to streamline deployment workflows.
Support developers in troubleshooting infrastructure and deployment issues.




Security and Compliance

Implement security best practices across infrastructure and CI/CD pipelines.
Manage access control, secrets management, and vulnerability scanning.




Continuous Improvement

Identify opportunities to automate operational tasks.
Evaluate and adopt new DevOps tools and practices to improve system efficiency.




Job Requirements:

Bachelor's degree in Computer Science, Software Engineering, or a related field.
Minimum 3 years of experience working with DevOps tools and cloud environments, with exposure to GitOps practices, Infrastructure as Code, and containerized applications.
Proficiency in infrastructure as code (IaC) tools such as Terraform, Ansible, or CloudFormation for automating infrastructure provisioning
Knowledge of Docker and containerization
Exposure to Kubernetes concepts or container orchestration
Familiarity with cloud platforms such as AWS, Azure, or GCP
Understanding of Linux systems and shell scripting
Knowledge of Git and version control workflows, familiar with Gitlab
Familiarity with automation and DevOps practices
