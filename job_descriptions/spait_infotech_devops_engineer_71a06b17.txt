Key Responsibilities:

Manage and maintain cloud infrastructure and servers.
Automate software build, testing, and deployment processes.
Develop and maintain CI/CD pipelines.
Monitor application performance and system availability.
Work with developers and IT teams to improve deployment processes.
Manage containerization tools such as Docker and Kubernetes.
Maintain cloud platforms such as AWS, Azure, or Google Cloud.
Troubleshoot technical issues and ensure system reliability.
Implement security best practices and infrastructure monitoring.

Required Skills:

Knowledge of AWS, Azure, or Google Cloud.
Experience with Docker and Kubernetes.
Understanding of Jenkins, GitHub Actions, or GitLab CI/CD.
Knowledge of Linux and Windows servers.
Basic scripting skills using Python, Bash, or Shell.
Understanding of Git and version control.
Knowledge of Terraform and Infrastructure as Code (IaC).
