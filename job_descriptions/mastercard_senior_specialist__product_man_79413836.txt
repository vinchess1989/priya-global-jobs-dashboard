Title And Summary

Senior Specialist, Product Management

Overview

We are seeking a highly motivated Senior Specialist, Product Management to join Mastercard's API Consultancy & Standards (API Gold Standards) team within Developer Experience.

This role is responsible for driving API quality, governance, and developer experience initiatives across Mastercard's API ecosystem. The successful candidate will work closely with product teams, engineers, service owners, and stakeholders to ensure Mastercard APIs meet Gold Standards for usability, security, consistency, and market readiness.

The role combines product management, API governance, developer experience, and data-driven decision making to help scale Mastercard's API quality programmes, assessments, tooling, and lifecycle processes. The position offers the opportunity to contribute to AI-powered capabilities that improve productivity, automate assessments, and enhance developer outcomes.

This is a global role requiring collaboration across multiple regions, business units, and technology teams.

Role

Partner with Product Managers and engineering teams to execute the API Gold Standards roadmap and strategic initiatives.

Conduct API assessments, reviews, and consultations to ensure alignment with Mastercard's API governance and quality standards.

Support API lifecycle activities, including onboarding, Early API Specification Reviews (EASR), readiness assessments, rescoring, and offboarding.

Analyse assessment outcomes and developer feedback to identify opportunities for product, process, and tooling improvements.

Contribute to the design and evolution of API quality frameworks, standards, and governance processes.

Help define requirements for internal tools and automation capabilities that improve assessment efficiency and API quality.

Support the adoption of AI-driven solutions that automate reviews, testing, documentation analysis, and governance activities.

Work directly with API service teams to provide actionable recommendations that improve developer experience and API usability.

Collaborate with engineering, product, QA, UX, and platform teams to drive successful delivery of API Gold Standards initiatives.

Monitor industry trends, API best practices, and emerging technologies to continuously evolve Mastercard's standards and assessment methodologies.

Create and maintain reporting, metrics, and insights that demonstrate API quality, programme effectiveness, and developer experience outcomes.

Support the continuous improvement of developer documentation, onboarding journeys, and API discoverability.

All About You

Bachelor's degree in Computer Science, Engineering, Business, or a related field.

Experience in product management, API platforms, developer tools, platform products, or related technology domains.

Strong understanding of REST APIs, API specifications, developer documentation, and API lifecycle management.

Experience working with cross-functional teams in a complex, matrixed global organisation.

Ability to analyse technical information and translate findings into actionable business recommendations.

Strong problem-solving skills with a data-driven mindset.

Excellent written and verbal communication skills with the ability to influence stakeholders at multiple levels.

Experience working with Agile delivery methodologies and product development practices.

Familiarity with API governance, security, standards, and developer experience principles is highly desirable.

Experience using analytics, automation, AI, or productivity tools to improve operational efficiency is a plus.

Demonstrated ability to manage multiple initiatives simultaneously while maintaining attention to detail.

Passion for developer experience, continuous improvement, and delivering high-quality customer outcomes.

Preferred Qualifications

Experience with OpenAPI specifications and API design standards.

Experience working with developer portals, API gateways, or API management platforms.

Knowledge of AI-assisted tooling, automation, or developer productivity solutions.

Understanding of financial services, payments, or platform-based technology ecosystems.
