About the role

We are seeking an experienced Azure DevOps Engineer to design, implement, and manage cloud infrastructure, CI/CD pipelines, automation frameworks, and platform reliability solutions within Microsoft Azure environments. The ideal candidate will have strong hands-on experience with Azure DevOps, Infrastructure as Code (IaC), container platforms, and cloud-native application deployments. The role requires close collaboration with development, QA, architecture, security, and operations teams to deliver scalable, secure, and highly available enterprise solutions.

Key responsibilities

Design, build, and maintain Azure DevOps CI/CD pipelines.

Automate application build, test, deployment, and release processes.

Implement DevSecOps practices within delivery pipelines.

Support blue-green and canary deployment strategies.

Provision and manage Azure infrastructure using Infrastructure as Code.

Implement and support Azure Virtual Machines, Azure App Services, Azure Functions, Azure Storage, Azure SQL Database, Azure Key Vault, and Azure Kubernetes Service (AKS).

Develop reusable Terraform modules and templates.

Deploy and manage applications using Docker containers.

Administer Kubernetes / AKS clusters.

Implement observability solutions using Azure Monitor, Application Insights, Log Analytics, Grafana, and Prometheus.

About you

ADO skills required.

Knowledge of AKS.

Understand architectural level but also be hands on.

Understand code, know DevOps & DevSecOps.

Hands-on experience as a Platform Engineer.
