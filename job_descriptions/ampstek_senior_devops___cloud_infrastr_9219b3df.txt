Job Summary




We are looking for an experienced Senior DevOps Engineer with strong expertise in DevOps, Cloud Infrastructure, CI/CD, and Automation. The ideal candidate should have hands-on experience designing and maintaining CI/CD pipelines, managing cloud infrastructure across Azure, AWS, or GCP, and implementing Infrastructure as Code (IaC) using Terraform and other automation tools.




The candidate should also have strong experience with Docker, Kubernetes, Helm, monitoring tools, and DevSecOps practices to ensure reliable, secure, and scalable cloud environments.




Key Responsibilities




Design, build, implement, and maintain CI/CD pipelines for application development and deployment.
Manage, provision, and maintain cloud infrastructure across Azure, AWS, or GCP.
Automate infrastructure provisioning and configuration management using Terraform, ARM Templates, Bicep, and other IaC tools.
Develop and maintain automated deployment processes using Azure DevOps, Jenkins, GitHub Actions, and GitLab CI/CD.
Implement and manage containerization solutions using Docker and Kubernetes.
Deploy and manage Kubernetes applications using Helm charts.
Implement DevSecOps practices by integrating security checks into CI/CD pipelines.
Manage source code repositories and version control using Git, GitHub, Bitbucket, and Azure Repos.
Monitor system performance, availability, security, and reliability using Prometheus, ELK Stack, Splunk, and Azure Monitor.
Troubleshoot production issues, perform root cause analysis, and implement preventive measures.
Optimize cloud infrastructure, deployment workflows, and system performance.
Collaborate with development, security, infrastructure, and operations teams to improve delivery efficiency.
Follow automation, security, and infrastructure management best practices.




Mandatory Skills




Cloud Platforms: Azure, AWS, or GCP.
CI/CD Tools: Azure DevOps, Jenkins, GitHub Actions, GitLab CI/CD.
Infrastructure as Code (IaC): Terraform, ARM Templates, Bicep.
Containerization & Orchestration: Docker, Kubernetes, Helm.
Version Control: Git, GitHub, Bitbucket, Azure Repos.
Monitoring Tools: Prometheus, ELK Stack, Splunk, Azure Monitor.
DevOps Practices: CI/CD, DevSecOps, Infrastructure as Code (IaC).
Minimum 8+ years of experience in DevOps, Cloud Infrastructure, CI/CD, and Automation.
