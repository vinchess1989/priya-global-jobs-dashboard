Hiring: Senior Azure DevOps Engineer




We are seeking a Senior Azure DevOps Engineer to support enterprise cloud platforms and digital service delivery initiatives.

🔹 Design, implement, and maintain CI/CD pipelines, deployment automation, and Infrastructure as Code (IaC) solutions.

🔹 Strong hands-on experience with Microsoft Azure infrastructure, platform services, networking, identity, security, and monitoring.

🔹 Manage multiple environments, complex release processes, configuration management, and production deployments.

🔹 Develop automation scripts, utilities, APIs, and internal tools using modern programming languages and software-development best practices.

🔹 Support microservices, APIs, distributed applications, and cloud-based development tools.

🔹 Implement monitoring, logging, alerting, observability, secrets management, incident response, and recovery processes.

🔹 Troubleshoot application, integration, build, pipeline, infrastructure, and deployment issues while collaborating with development, security, and operations teams.
