Job Summary

Our client is seeking an experienced Azure DevOps Engineer to design, build and maintain reliable CI/CD pipelines and containerised application platforms. The successful candidate will work with Azure DevOps, GitHub, Docker, Kubernetes and Helm, supporting C# .NET applications in a primarily on-premises environment with Azure cloud exposure. This role requires strong expertise in deployment automation, Kubernetes networking, observability, DevSecOps and production troubleshooting, with a focus on secure, stable and efficient software delivery.

Responsibilities
Design, build and maintain automated CI/CD pipelines using Azure DevOps and GitHub to support consistent application delivery.
Deploy, manage and troubleshoot containerised C# .NET applications on Kubernetes using Helm charts.
Support and optimise Docker container workloads, improving deployment reliability and platform performance.
Configure Kubernetes networking, Ingress Controllers and traffic routing to ensure effective application connectivity.
Implement and maintain monitoring, alerting and observability solutions using OpenTelemetry, ClickStack and Grafana.
Integrate SonarQube and Rapid7 security and code-quality controls into CI/CD pipelines and release processes.
Automate release workflows and apply CI/CD best practices to improve deployment consistency and efficiency.
Collaborate with development teams to enhance build, deployment and operational processes for C# .NET applications.
Investigate and resolve production incidents, platform failures and deployment issues across containerised environments.
Support infrastructure and application operations in primarily on-premises environments with Azure cloud exposure.
Assist with database-related troubleshooting and application connectivity involving SQL Server and PostgreSQL.
Maintain operational documentation and work with cross-functional teams to improve platform stability and service delivery.
Competencies
Strong analytical thinking and structured troubleshooting of complex infrastructure and application issues.
Clear technical communication with development, security and operations stakeholders.
Ownership and accountability for deployment reliability, platform stability and operational outcomes.
Sound judgement when investigating production incidents and identifying practical solutions.
Ability to work effectively under pressure while resolving urgent platform and deployment issues.
Adaptability to changing technical priorities, environments and delivery requirements.
Collaborative approach to improving development workflows and operational processes.
High attention to detail in configuration, automation, monitoring and security controls.
Proactive approach to continuous improvement, reliability and problem prevention.
Technical Skills
5 to 10 years of relevant experience in DevOps engineering, deployment automation or related technical environments is mandatory.
Strong hands-on experience with Kubernetes administration, deployment and troubleshooting is mandatory.
Practical experience with Helm charts and Kubernetes application deployment is mandatory.
Strong experience with Docker and containerised workloads is mandatory.
Proficiency in Azure DevOps and GitHub for CI/CD pipeline development and maintenance is mandatory.
Experience with Kubernetes networking, Ingress Controllers and traffic management is mandatory.
Strong understanding of CI/CD best practices, release automation and deployment processes is mandatory.
Experience with observability tools including OpenTelemetry, ClickStack and Grafana is mandatory.
Experience integrating DevSecOps and code-quality tools including SonarQube and Rapid7 is mandatory.
Working understanding of SQL Server and PostgreSQL is mandatory.
Exposure to Azure and/or AWS cloud environments is mandatory.
Ability to troubleshoot production, platform and application deployment issues is mandatory.
Experience supporting C# .NET application environments is advantageous.
Experience working with primarily on-premises infrastructure and Azure cloud exposure is advantageous.
Strong problem-solving capabilities and effective collaboration with development teams are mandatory.
