Job description:

DevOps Engineer

Location:- Bengaluru, Hyderabad, Chennai

Exp:- 6-9yrs

Job Description

Implement, maintain and support private cloud Infrastructure and resources, ensure robustness, performance and security. Exposure in working with AWS or Azure or hybrid environments is a bonus.
Strong and demonstrated private cloud experience with automation (Terraform)
Strong Kubernetes /Argo CD/ Grafana experience
Knowledge of Keycloak and Kafka, postgreSQL
Ownership Engineer team CI/CD tooling and pipeline (Github action and Git)
Helm (chart authoring and values management)
GitOps workflow as a pattern — app repo → deployment repo → Argo reconciliation
Artifact repository (JFrog/Artifactory)
Secrets management (Vault) and TLS/certificate handling
Ingress and API gateway layer (APIgatewaysix)
Observability: Prometheus, log aggregation, alerting (alongside Grafana)
Partner with Security/Cloud Governance/Architecture on Platform security, compliance and cost management
Good knowledge/experience with network / Linux OS / Docker / SQL Database
Strong scripting language skill on Python/Bash
AI Claude
Infrastructure-as-Code: Terraform and Ansible
Networking fundamentals: firewalls, security groups
desired skills: Java/springboot

 

Mandatory Skills: Enterprise Platform Devops Tools
.

 

Experience: 3-5 Years
.
