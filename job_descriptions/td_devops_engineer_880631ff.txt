Summary

Job Description:

We are seeking a DevOps Engineer to build, maintain, and support modern DevOps platforms on Microsoft Azure, with a strong focus on AKS-based workloads, CI/CD automation, and cloud-native operational excellence.

This role requires strong hands-on experience with DevOps engineering, infrastructure automation, application deployments, and secure production operations. The successful candidate will work closely with development, infrastructure, security, and platform teams to implement scalable DevOps solutions and enable reliable application delivery.

You will contribute to DevOps and release solutions, implement and maintain CI/CD pipelines, support application deployments, and help continuously improve automation, reliability, security, and developer productivity in a regulated banking environment.

Key Responsibilities


Build, maintain, and support DevOps solutions and automation
Contribute to DevOps and release architecture across non-production and production environments
Execute and coordinate application releases, including cutovers and deployment windows
Deploy and support applications on Azure Kubernetes Service (AKS) and Azure App Service
Build and maintain CI/CD pipelines using GitHub Actions
Develop and maintain Helm charts for Kubernetes application deployments
Develop and maintain infrastructure using Terraform (Infrastructure as Code)
Support release readiness, environment parity, deployment validation, and rollback strategies
Create and maintain release documentation, including runbooks, cutover plans, and deployment checklists
Implement DevOps security, governance, and operational best practices
Troubleshoot deployment, pipeline, infrastructure, and production issues
Identify and implement opportunities for automation and continuous improvement
Collaborate with development, security, infrastructure, and platform teams
Participate in production support and operational activities as required


Education & Experience


5+ years of experience in DevOps, Cloud Engineering, Platform Engineering, or a related field
Strong hands-on experience implementing and supporting cloud-based DevOps solutions
Experience working in enterprise or regulated environments
Experience supporting production systems and application deployments


Required Primary Skills


Strong hands-on experience in DevOps / Release Engineering
Hands-on experience with Microsoft Azure, including:
Azure Kubernetes Service (AKS)
Azure App Service
Azure networking, identity, and security concepts
Strong experience with Kubernetes and Helm
Strong experience with Terraform / Infrastructure as Code
Strong CI/CD experience using GitHub Actions
Experience with source control and Git-based development workflows
Solid understanding of deployment strategies, including:
Blue/green deployments
Canary deployments
Rollback strategies
Understanding of DevOps security and secure software delivery practices
Understanding of operational readiness, monitoring, troubleshooting, and production support
Good communication, collaboration, and problem-solving skills
