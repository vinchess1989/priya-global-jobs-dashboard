Are you the engineer everyone turns to when systems need to be faster, more reliable, more secure, and fully automated? Do you thrive on building cloud environments that scale effortlessly while eliminating manual work wherever possible?
 
My client is looking for a Senior Cloud DevOps Engineer to join a growing technology business where you'll have the opportunity to shape cloud strategy, influence architecture decisions, and build highly available systems that support a modern SaaS platform. This is a role for someone who enjoys ownership, modern cloud technologies, automation, and solving complex infrastructure challenges.
 
You'll work alongside talented software engineers, data professionals, and technology leaders while leveraging industry-leading AWS services, Kubernetes, CI/CD pipelines, Infrastructure as Code, and observability tooling.
Duties & Responsibilities

Job Description:
 
As a Senior Cloud DevOps Engineer, you will play a critical role in designing, building, securing, and optimising cloud infrastructure that supports business-critical applications at scale.
 

Responsibilities include:

Designing, implementing, and managing scalable AWS cloud infrastructure
Building and maintaining robust CI/CD pipelines
Managing containerised workloads using Docker and Kubernetes
Deploying and supporting cloud-hosted applications
Implementing Infrastructure as Code practices
Automating deployments and operational processes
Establishing monitoring, logging, and alerting capabilities
Driving cloud security initiatives and best practices
Implementing backup, recovery, and disaster recovery strategies
Troubleshooting production issues and improving platform reliability
Optimising cloud performance, scalability, and cost efficiency
Collaborating with software development teams to streamline deployments
Maintaining infrastructure documentation and operational standards

Skills & Experience:

Strong commercial AWS experience
Experience with AWS services including EC2, ECS, RDS, S3, CloudFront, and Lambda
Advanced Docker and Kubernetes experience
Strong CI/CD experience using GitHub Actions, Jenkins, or similar platforms
Experience with Infrastructure as Code tools such as Terraform, CloudFormation, or Ansible
Experience with monitoring and observability tools including Prometheus, Grafana, and CloudWatch
Knowledge of PostgreSQL and exposure to NoSQL technologies
Strong scripting abilities using Python, Bash, Ruby, or similar languages
Solid understanding of networking, cloud architecture, and security concepts
Experience supporting highly available production environments
Strong troubleshooting and problem-solving skills
Excellent communication and stakeholder engagement skills

Qualification:

Degree in Computer Science, Information Systems, Engineering, Mathematics, or a related field preferred
Relevant AWS certifications highly advantageous
