Job Purpose

The Manager, Platform Engineering (Azure Cloud) is responsible for designing, implementing, automating, and supporting cloud infrastructure on Microsoft Azure. The role focuses on establishing and maintaining secure, scalable, and governing Azure platforms through Azure Landing Zones, Infrastructure as Code (Terraform), Azure DevOps automation, Kubernetes platforms, and enterprise Azure services. The position plays a key role in enabling application teams through reliable, automated, and secure cloud services while ensuring alignment with enterprise architecture, governance, security, and operational standards.

Responsibilities


Design, implement, and maintain Azure Landing Zones aligned with governance, security, and compliance requirements.
Manage Azure subscriptions, policies, RBAC, networking, and resource standards.
Develop and maintain Infrastructure as Code (IaC) solutions using Terraform.
Create reusable Terraform modules and automate infrastructure provisioning.
Build and manage CI/CD pipelines using Azure DevOps.
Deploy, manage, and troubleshoot workloads running on Azure Kubernetes Service (AKS).
Manage Kubernetes resources including networking, storage, scaling, and security configurations.
Utilize Helm Charts for application deployment and lifecycle management.
Implement, support, and optimize Azure services including Application Gateway, API Management (APIM), Storage Accounts, Key Vault, Logic Apps, App Services, and Identity Management.
Monitor platform health, availability, security, performance, and operational effectiveness.
Produce technical documentation, operational procedures, and architecture diagrams.
Support platform incident resolution, root cause analysis, and continuous improvement initiatives.
Collaborate with application, security, and infrastructure teams to deliver cloud solutions aligned with business needs.


Requirements


Bachelor's degree in engineering
Minimum 10+ years IT experience with at least 5+ years of hands-on experience with Microsoft Azure cloud platforms.
Strong experience with Terraform and Infrastructure as Code practices.
Strong experience with Azure DevOps pipelines and repository management.
Solid understanding of Azure networking, security, governance, and identity management.
Hands-on experience with Azure Kubernetes Service (AKS) and Kubernetes administration.
Experience supporting Azure Application Gateway, API Management (APIM), Storage Accounts, Key Vault, Logic Apps, and App Services.
Working knowledge of scripting languages such as PowerShell and Bash.
Strong analytical, troubleshooting, and problem-solving skills.
Experience with Helm Charts preferred.
Azure certifications such as AZ-104, AZ-305, and/or AZ-400 preferred.
Experience with GitOps tools such as ArgoCD or Flux preferred.
Knowledge of cloud security best practices, operational excellence, and cost optimization principles.
Ability to work independently and collaboratively within cross-functional teams.
Strong written and verbal communication skills.
