We are seeking an experienced DevOps Engineer to design, implement and maintain cloud infrastructure and deployment automation solutions. The successful candidate will be responsible for managing AWS cloud environments, containerised applications using Kubernetes, and CI/CD pipelines to ensure scalable, reliable and secure application delivery.


Working Hours: Mon-Fri
Working Location: Central
Salary Package: Up to $7500 (basic) + AWS + VB


Key Responsibilities


Cloud Infrastructure Management: Design, deploy, configure and maintain scalable, highly available cloud infrastructure using AWS services.
Containerisation & Orchestration: Manage containerised applications using Docker and Kubernetes, including deployment, configuration, scaling and troubleshooting.
CI/CD Automation: Design, implement and maintain CI/CD pipelines to automate application build, testing and deployment processes.
Infrastructure as Code (IaC): Automate infrastructure provisioning and configuration management using Terraform, AWS CloudFormation or Ansible.
System Monitoring & Optimisation: Monitor infrastructure performance, availability and resource utilisation, and implement improvements to ensure system reliability.
Troubleshooting & Incident Management: Investigate and resolve infrastructure, application deployment and production environment issues.
Security & Compliance: Implement cloud security best practices, access management, vulnerability remediation and infrastructure hardening.
Collaboration: Work closely with software developers, architects and operations teams to streamline development, deployment and release processes.


Requirements


Degree or Diploma in Computer Science, Information Technology or a related discipline.
Minimum 3–5 years of relevant experience in DevOps, Cloud Engineering or Infrastructure Engineering.
Strong hands-on experience with AWS cloud services, such as EC2, EKS, ECS, S3, IAM, VPC, RDS and CloudWatch.
Proficiency in Kubernetes and Docker, including container orchestration and cluster management.
Experience developing and managing CI/CD pipelines using Jenkins, GitLab CI/CD, GitHub Actions or AWS CodePipeline.
Familiarity with Infrastructure as Code tools such as Terraform, AWS CloudFormation or Ansible.
Proficiency in scripting languages such as Python, Bash or Shell.
Experience with monitoring and logging tools such as Prometheus, Grafana, ELK Stack or CloudWatch.
Good understanding of Linux administration, networking, cloud security and system architecture.
