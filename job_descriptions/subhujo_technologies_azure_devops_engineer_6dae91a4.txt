Introduction

Looking for an Azure DevOps Engineer

Duties & Responsibilities
5 to 10  Years of experience required
Design, build, and maintain CI/CD pipelines using Azure DevOps and GitHub.
Deploy, manage, and troubleshoot applications running on Kubernetes using Helm Charts.
Support and optimize containerized workloads using Docker.
Configure and manage Ingress Controllers and traffic routing.
Implement monitoring, alerting, and observability solutions.
Integrate security and code-quality controls into CI/CD pipelines.
Collaborate with development teams to improve deployment and operational processes.
Troubleshoot and resolve production and platform-related issues.
Desired Experience & Qualification

Required Skills

Strong hands-on experience with:
Kubernetes
Helm
Docker
Azure DevOps
GitHub
Experience with Kubernetes networking, Ingress Controllers, and traffic management.
Strong understanding of CI/CD best practices and release automation.
Experience with observability and monitoring tools:
Open Telemetry
Click Stack
Grafana
Experience with DevSecOps tools:
SonarQube
Rapid7
Good understanding of:
SQL Server
PostgreSQL
Exposure to Azure and/or AWS cloud environments.
Strong troubleshooting and problem-solving skills.

Technical Environment

Applications are in: C# .NET
Container Platform: Docker, Kubernetes, Helm
CI/CD: Azure DevOps, GitHub
Monitoring & Observability: OpenTelemetry, ClickStack, Grafana
Security: SonarQube, Rapid7
Databases: SQL Server, PostgreSQL
Infrastructure: Primarily On-Premises with Azure Cloud exposure
