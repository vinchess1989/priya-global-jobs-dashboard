About Position:




We are seeking a detail-oriented and technically proficient Technical Writer to create, maintain, and enhance technical documentation for software development teams. The ideal candidate will have experience working closely with developers, architects, and product managers to transform complex technical concepts into clear, concise, and user-friendly documentation. This role requires hands-on experience with Markdown, Visual Studio Code, Git, and API documentation, along with a passion for delivering high-quality content that supports product adoption and knowledge sharing.




Role: Technical Writer - Software Documentation
Location: Gurgaon, Noida
Experience: Between 3 to 5 Years
Job Type: Full Time Employment




What You'll Do:




Develop, maintain, and enhance technical documentation including user guides, installation guides, release notes, API documentation, and knowledge base articles.
Create structured documentation using Markdown and documentation best practices.
Collaborate with software developers, architects, product managers, and QA teams to gather technical information and document software features effectively.
Utilize Visual Studio Code to review codebases and understand software architecture for documentation purposes.
Write clear, concise, and user-friendly content for both technical and non-technical audiences.
Create tutorials, onboarding guides, how-to documents, and troubleshooting resources.
Develop and maintain internal knowledge repositories and documentation portals.
Manage documentation workflows, version control, and collaboration processes using Git, GitHub, or GitLab.
Create and maintain diagrams, flowcharts, architecture documents, and visual content to simplify complex concepts.
Ensure consistency, accuracy, completeness, and quality across all documentation assets.
Participate in sprint planning sessions, engineering discussions, and code reviews to stay aligned with product enhancements.
Review and update existing documentation based on product changes, customer feedback, and process improvements.
Work closely with cross-functional teams to ensure documentation is delivered alongside product releases.
Drive documentation standards, templates, and best practices across engineering teams.




Expertise You'll Bring:




3 to 5 years of experience as a Technical Writer in a software development or product engineering environment.
Strong experience creating technical documentation, user manuals, knowledge base articles, and software documentation.
Excellent written communication skills with strong attention to detail and content organization.
Proficiency in Markdown for creating structured and maintainable documentation.
Hands-on experience with Visual Studio Code for reviewing and understanding technical content.
Strong understanding of Git, GitHub, GitLab, and version control workflows.
Experience creating API documentation and developer-focused content.
Ability to understand software architecture, application workflows, and technical concepts.
Experience collaborating with software developers, product owners, architects, and business stakeholders.
Knowledge of software development lifecycle (SDLC) and Agile development methodologies.
Familiarity with documentation tools, content management systems, and collaborative authoring platforms.
Experience creating diagrams, workflows, process documentation, and technical illustrations.
Strong editing, proofreading, and content quality assurance skills.
Ability to simplify complex technical concepts for different audiences.
Excellent stakeholder communication and collaboration skills.
Self-motivated with strong organizational, planning, and multitasking abilities.
