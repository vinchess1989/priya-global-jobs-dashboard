We are looking for a Cloud Platform & Reliability Engineer to help design, scale, and maintain our enterprise infrastructure across multi-cloud environments. In this role, you will focus on system up time, automate core operational processes, and ensure our platforms remain resilient, secure, and observable.




Key Responsibilities

Cloud Infrastructure & Platform Engineering

Work with Azure and AWS cloud platforms.
Manage Kubernetes and container orchestration (Docker).
Build Infrastructure as Code using Terraform, Bicep, or CloudFormation.
Handle platform scalability, resiliency, and capacity planning.
Design and support multi-regional and high availability architectures.

Reliability Engineering & Production Operations

Design and maintain highly available, resilient platforms.
Define and track SLIs, SLOs, and SLAs.
Plan and execute disaster recovery and business continuity plans.

Observability, Monitoring & Performance Engineering

Implement monitoring and alerting strategies.
Work with observability platforms: Dynatrace, Datadog, Splunk, AppDynamics, Prometheus, and Grafana.
Manage log aggregation and performance analysis.

Automation & DevOps Engineering

Implement and support CI/CD pipelines.
Automate tasks using Python, PowerShell, Shell scripting, or Go.
Build auto-remediation and self-healing solutions.

Technical Leadership & Operational Excellence

Partner with Developers, Architects, Product Owners, Cloud Engineers, and Operations teams.
Lead incident reviews, RCAs, and operational readiness assessments.
Establish operational standards, runbooks, and playbooks.
Drive continuous improvement using reliability engineering principles.

Skills & Requirements

Mandatory Skills: Azure Cloud Architecture
Good to Have Skills: AWS Cloud
Containers & Orchestration: Kubernetes, Docker, Helm Charts, Istio
Infrastructure as Code (IaC): Terraform, Bicep, CloudFormation
CI/CD Tools: GitHub Actions, Jenkins, Argo CD
Observability & Monitoring: Dynatrace, Datadog, Splunk, AppDynamics, Prometheus, Grafana
Scripting: Python, PowerShell, Shell Scripting, Go
Core Fundamentals: Linux Administration, Networking Fundamentals, Incident Management & RCA
