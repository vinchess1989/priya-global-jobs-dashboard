Job Title : DevOps Engineer

Experience : 5+ Years

Location : Chennai

Employment Type : Full-Time




Job Description :-




We are looking for an experienced DevOps Engineer with 5+ years of hands-on experience in designing, implementing, and managing CI/CD pipelines, cloud infrastructure, automation, and deployment processes.




Key Responsibilities :-




Design, implement, and maintain CI/CD pipelines for application build, testing, and deployment.
Manage and automate cloud infrastructure using AWS/Azure/GCP.
Develop and maintain Infrastructure as Code (IaC) using Terraform or similar tools.
Work with Docker and Kubernetes for containerization and orchestration.
Manage source code repositories using Git/GitHub/GitLab/Bitbucket.
Implement monitoring, logging, and alerting solutions.
Automate operational processes using Shell/Python scripting.
Troubleshoot application deployment, infrastructure, and production issues.
Collaborate with development, QA, security, and operations teams.
Follow DevOps best practices for security, scalability, availability, and performance.




Required Skills :-




5+ years of experience in DevOps / Cloud / Infrastructure Automation.
Strong experience with CI/CD tools – Jenkins, GitLab CI, Azure DevOps, or similar.
Hands-on experience with Docker and Kubernetes.
Good knowledge of AWS/Azure/GCP cloud services.
Strong experience with Terraform / Infrastructure as Code.
Good understanding of Linux/Unix administration.
Experience with Git and version control systems.
Good scripting knowledge in Shell/Bash or Python.
Experience with monitoring tools such as Prometheus, Grafana, ELK, or similar.
Good understanding of networking, security, and cloud architecture concepts.
