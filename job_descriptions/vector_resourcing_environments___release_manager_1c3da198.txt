Partner | Resourcing & Improvements Manager @ Vector Resourcing

** Please note you will be required to attend site for 2 days a week for the first month then it will become predominantly remote **




Our client is looking for an Environment & Release Manager to take ownership of Azure and Dynamics 365 Finance & Operations environments and releases through a finance transformation. You’ll make sure project and test teams have secure, correctly configured environments when they need them, and that changes move into production in a controlled way. Once the finance programme completes, expected in 8–12 months, the role shifts to around 80% day-to-day release management across a wider SaaS estate and 20% project work and forward planning.




Responsibilities

Own the day-to-day running and scheduling of Azure and Dynamics 365 F&O environments across project and operational teams.
Resolve competing demands for environments, balancing project deadlines, test windows and live service priorities.
Coordinate environment refreshes, access and configuration changes so teams can start testing on time.
Maintain the release calendar and coordinate deployment windows, approvals, dependencies and communications.
Lead release readiness reviews, checking test evidence, outstanding defects and recovery plans before changes go live.
Coordinate production deployments, post-release checks and handover to operational teams.
Take initial ownership of test coordination until the Test Manager joins, then provide cover when needed.
Manage ongoing SaaS releases across services including housing and pensions, coordinating Oracle and Boomi changes around each service’s own test environments.
Plan ahead for supplier updates and upcoming projects so teams can prepare for changes and resolve scheduling conflicts early.
