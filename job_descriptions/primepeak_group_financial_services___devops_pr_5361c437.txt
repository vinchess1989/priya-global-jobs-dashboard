We are seeking a DevOps & Production Operations Engineer to bridge application engineering, infrastructure, security, and support. In this role, you will own the reliability, CI/CD automation, and observability of business-critical applications, data platforms, and AI systems hosted in Azure.

You’ll play a key role in enforcing segregation of duties, automating production deployments, building robust observability tools, and establishing production readiness before go-live.




Key Responsibilities




Production Operations & Reliability: Maintain application operability across DEV, UAT, and PROD environments in Azure. Monitor health, lead incident response, build runbooks, and engineer permanent fixes to reduce manual intervention.
DevOps & CI/CD Automation: Design and optimize deployment pipelines via Azure DevOps and GitHub Actions (including Power Platform ALM and dbt/Snowflake). Implement Infrastructure as Code (Terraform/Bicep) and safe release/rollback mechanisms.
Observability & Monitoring: Build an application-centric telemetry ecosystem using Azure Monitor, Application Insights, Log Analytics, OpenTelemetry, Prometheus, and Grafana to quickly diagnose cross-stack issues.
Access & Production Controls: Work with InfoSec to manage least-privilege production access, enforce auditable release gates, and automate privileged operational tasks.
Production Readiness: Partner with development teams pre-launch to verify monitoring, logging, health endpoints, backup/recovery, and CMDB registration.







Requirements




Production Experience: Proven background operating production applications, ideally within regulated Financial Services or Asset Management environments.
Cloud & DevOps: Strong hands-on expertise with Azure, Azure DevOps, and GitHub Actions (including Power Platform ALM pipelines).
Observability: Experience with Azure Monitor, Application Insights, Log Analytics, or OpenTelemetry.
Automation & IaC: Proficiency in scripting (PowerShell, Python, or Bash) and Infrastructure as Code (Terraform or Bicep).
Technical SDLC Foundation: Solid understanding of modern SDLC, networking/identity concepts (HTTP, DNS, TLS, RBAC), and enough coding experience (.NET, Python, TypeScript) to conduct code/pipeline reviews.




Desirable:

Experience with Azure Container Apps, API Management, Entra ID, Key Vault, Managed Identity, Kubernetes, or Prometheus.
