As a frontier partner, we grow through great people, smart tech, and teamwork between humans and AI.




We are looking for an Azure Cloud Expert Engineer to join our team in Cape Town.




As an Azure Cloud Expert Engineer (T3), you will provide high-level support to our customers, acting as an escalation point for Tier 2 support engineers and working alongside senior engineers to execute complex projects/onboardings.




You will ensure that service level agreements are met whilst delivering reliable resolution of customer technical issues when raised via Cloud Direct support lines, Live chat, e-mail or self-service portals.




What You’ll Do:




Infrastructure Provisioning and Deployment:

Understanding of Networking, Databases, Software, and Servers in the Cloud.
Provision and deploy virtual machines, containers, and other Azure resources as per design specifications.
Implement automation using Azure Resource Manager (ARM) templates, PowerShell scripts, or other automation tools.
Azure PowerShell or similar scripting experience, for the creation of custom scripts to automate support processes where applicable.
Configure networking, security, and identity management components in Azure.
Configuring Virtual machines for Optimum Cost, Performance, and Security.
Demonstrated experience in deploying and managing cloud infrastructure using Infrastructure-as-Code (IaC). Proficiency in Azure DevOps, GitHub, and Visual Studio, with strong expertise in Infrastructure as Code, specifically Terraform, Bicep, and ARM templates.




DevOps, CI/CD & Automation:

Design, implement, and maintain CI/CD pipelines using Azure DevOps Pipelines and GitHub ActionsYAML-based, multi-stage pipelines.
Develop YAML-based multi-stage build and release pipelines.
Create reusable pipeline templates and modules to standardize delivery across customers.
Support application and infrastructure deployments using CI/CD-driven IaC workflows.
Troubleshoot and optimize pipeline performance, reliability, and execution time.




Security and Compliance:

Implement security best practices and compliance standards in Azure environments.
Configure Azure security services such as Azure Security Center, Azure Sentinel, and Azure Active Directory (AAD) for identity and access management.
Conduct security assessments and audits and remediate security vulnerabilities.
Manage role-based access control (RBAC)




Monitoring and Optimization:

Implement monitoring and alerting solutions for Azure resources using Azure Monitor and other monitoring tools.
Perform performance tuning and optimization of Azure infrastructure and services.
Identify and troubleshoot performance issues and bottlenecks.




Disaster Recovery and High Availability:

Design and implement disaster recovery and high availability solutions using Azure Site Recovery (ASR), Azure Backup, and other Azure services.
Test and validate disaster recovery plans and failover procedures.




Data & AI:

Review and resolve Pipeline failures
Timely identification, diagnosis, and resolution of issues that can disrupt data pipelines, ensuring minimal downtime and continuity of data flow
Data source integrations
Performance issues
Data Accuracy




Platform Management:

Monitor for failures
Remediation of failure
Backup storage redundancy
Restoration of data
Recovery time objective (RTO) and Recovery point objective (RPO)




Additionally, the engineer will be expected to:

Assist in mentoring team members.
Create Knowledge Base articles as part of their responsibilities.
Be on call as needed to meet operational requirements.




What We’re Looking For:




3+ years of experience designing, implementing, and managing Azure cloud environments.
Excellent communication and collaboration skills.
Strong understanding of the Microsoft Azure platform and its capabilities
Three or more Azure cloud certifications: AZ-104, AZ-204, AZ-400 (Desirable), DP-203, DP-700, AZ-500, AZ-305, SC-200, SC-300, DP-300
