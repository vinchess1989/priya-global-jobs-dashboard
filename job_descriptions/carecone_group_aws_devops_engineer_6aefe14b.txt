Role- AWS DevOps Engineer

Location- Sydney




Job Description-




We are looking for an experienced AWS DevOps Engineer to design, automate, deploy, and manage scalable and highly available cloud infrastructure and application environments on AWS.

The ideal candidate will have strong hands-on experience with AWS, Terraform, CI/CD, Docker, Kubernetes, Git, and cloud automation, along with good exposure to monitoring, security, and production support.




Key Responsibilities

Design, implement, and manage AWS cloud infrastructure across development, testing, and production environments.
Develop and maintain Infrastructure as Code using Terraform.
Build, manage, and optimize CI/CD pipelines for automated application build, testing, deployment, and release.
Work with AWS services including EC2, S3, IAM, VPC, Lambda, ECS/EKS, CloudWatch, RDS, ALB/NLB, Route 53, and CloudFormation where required.
Develop and maintain automated deployment and infrastructure provisioning processes.
Manage Docker containers and containerized application deployments.
Work with Kubernetes/Amazon EKS for container orchestration and application operations.
Implement branching, version control, and release strategies using Git/GitHub/GitLab/Bitbucket.
Implement monitoring, logging, alerting, and operational dashboards using CloudWatch and other observability tools.
Troubleshoot infrastructure, deployment, networking, performance, and production issues.
Implement AWS security best practices including IAM, least-privilege access, secrets management, encryption, and network security.
Automate repetitive operational activities using Python, Bash, or PowerShell.
Collaborate with developers, architects, QA, security, and operations teams to improve deployment velocity and platform reliability.
Support incident management, root-cause analysis, disaster recovery, and production stability.
Continuously improve cloud infrastructure, DevOps processes, automation, scalability, and cost optimization.




Mandatory Skills

Strong hands-on experience in AWS Cloud and DevOps.
Strong experience with Terraform / Infrastructure as Code (IaC).
Hands-on experience with CI/CD pipelines using Jenkins, GitHub Actions, GitLab CI, Azure DevOps, or similar tools.
Strong experience with Docker.
Good hands-on experience with Kubernetes / Amazon EKS.
Strong knowledge of Git and Git-based workflows.
Experience with Linux administration and troubleshooting.
Strong scripting/automation skills using Python or Shell scripting.
Good understanding of AWS networking concepts including VPC, subnets, security groups, NACLs, load balancers, and Route 53.
Experience with AWS IAM, CloudWatch, S3, EC2, RDS, and other core AWS services.
Good understanding of cloud security, monitoring, logging, scalability, and high availability.
