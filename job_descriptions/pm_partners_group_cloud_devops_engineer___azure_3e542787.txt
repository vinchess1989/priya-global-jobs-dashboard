Cloud DevOps Engineer – Azure

Contract: 12 months

Salary: $1,000 per day + super

About You

You are a hands-on Cloud DevOps Engineer with a strong Azure background and a passion for automation, infrastructure reliability and continuous improvement. You enjoy working collaboratively across engineering and technology teams to deliver secure, efficient and scalable cloud solutions.

The Opportunity

A leading Australian bank is seeking an experienced Cloud DevOps Engineer with strong Microsoft Azure expertise to support the development, automation and optimisation of its cloud infrastructure and deployment processes.

Working closely with engineering, architecture and security teams, you will help build and maintain secure, scalable and reliable Azure environments, improve CI/CD pipelines and drive automation across cloud infrastructure and software delivery.

Key Responsibilities

Design, implement and maintain secure, scalable and resilient infrastructure within Microsoft Azure.
Develop, manage and optimise CI/CD pipelines to automate build, testing and deployment processes.
Implement Infrastructure as Code using Terraform, Bicep or ARM templates.
Automate infrastructure provisioning, configuration management and operational processes.
Monitor cloud environments, troubleshoot issues and optimise performance, availability and costs.
Embed security, governance and compliance controls into cloud infrastructure and deployment workflows.
Collaborate with developers, architects and security teams to improve engineering practices and delivery outcomes.
Support containerisation and orchestration technologies, including Docker and Kubernetes.
Drive continuous improvement across cloud operations, DevOps tooling and platform reliability.

Key Skills and Experience

Proven experience in a Cloud DevOps Engineer, Azure Engineer or Platform Engineering role.
Strong hands-on experience with Microsoft Azure and its core infrastructure services.
Experience with Azure DevOps, including CI/CD pipelines, repositories and release management.
Strong Infrastructure as Code experience using Terraform, Bicep or ARM templates.
Scripting and automation skills using PowerShell, Bash or Python.
Experience with Git-based version control and automated deployment practices.
Understanding of Azure networking, identity and access management, security and monitoring.
Exposure to Docker, Kubernetes and Azure Kubernetes Service (AKS).
Strong troubleshooting and problem-solving skills, with the ability to work across technical teams.

Desirable Experience

Experience working within banking, financial services or another regulated environment.
Knowledge of Azure security, governance and compliance requirements.
Exposure to monitoring and observability tools such as Azure Monitor, Application Insights, Splunk or Datadog.
Experience supporting enterprise-scale Azure environments and production workloads.

Passion: Ability to band together when under pressure to deliver first class results to clients
