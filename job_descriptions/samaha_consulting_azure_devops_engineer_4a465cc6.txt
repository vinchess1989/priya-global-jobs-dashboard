Introduction

We are looking for an experienced Azure DevOps Engineer with strong hands-on expertise in CI/CD pipeline development, Kubernetes, Docker, Helm, Azure DevOps, and GitHub. The candidate will be responsible for automating application deployments, managing containerized workloads, optimizing Kubernetes environments, and implementing monitoring, observability, and DevSecOps practices.

The role involves supporting primarily on-premises infrastructure with exposure to Azure and/or AWS cloud environments. The engineer will work closely with development teams to improve deployment automation, application reliability, security, and production support for C#/.NET applications.

Duties & Responsibilities

Design, build, maintain, and optimize CI/CD pipelines using Azure DevOps and GitHub.

Automate application builds, testing, releases, and deployments.

Deploy, manage, and troubleshoot applications running on Kubernetes.

Manage containerized applications using Docker and Kubernetes.

Create, maintain, and manage Helm charts for application deployment and configuration.

Configure and maintain Kubernetes Ingress Controllers, networking, traffic routing, and load balancing.

Implement monitoring, logging, alerting, and observability using OpenTelemetry, ClickStack, and Grafana.

Integrate code-quality and security tools such as SonarQube and Rapid7 into CI/CD pipelines.

Support and troubleshoot SQL Server and PostgreSQL-related platform or application issues.

Work with on-premises infrastructure and support integrations with Azure and/or AWS cloud environments.

Identify and resolve production incidents, deployment failures, and platform-related issues.

Collaborate with software developers and infrastructure teams to improve deployment processes and operational efficiency.

Follow DevOps, DevSecOps, automation, and release-management best practices.

Desired Experience & Qualification

5–10 years of relevant experience in DevOps engineering, platform engineering, or CI/CD automation.

Strong practical experience with Azure DevOps and GitHub for source control and pipeline management.

Hands-on experience deploying and managing applications using Kubernetes, Helm, and Docker.

Experience with Kubernetes networking, Ingress Controllers, and traffic management.

Strong understanding of CI/CD pipelines, release automation, and deployment strategies.

Experience implementing monitoring and observability solutions using OpenTelemetry, ClickStack, and Grafana.

Practical exposure to DevSecOps and code-quality tools, particularly SonarQube and Rapid7.

Working knowledge of SQL Server and PostgreSQL.

Exposure to Azure and/or AWS cloud platforms.

Experience supporting on-premises infrastructure and troubleshooting production environments.

Good understanding of C#/.NET application deployment and operational requirements.

Strong analytical, troubleshooting, problem-solving, and collaboration skills.
