Senior DevOps / Cloud Engineer – Insurance & Financial Services




We are seeking an experienced Senior DevOps / Cloud Engineer to join a leading insurance and financial services organisation undergoing significant cloud and infrastructure transformation. This is an opportunity to play a key role in building, automating and maintaining secure, scalable and resilient cloud platforms supporting business-critical applications.

You will be responsible for developing cloud infrastructure, implementing automation and improving deployment capabilities across enterprise technology environments. Working closely with software engineering teams, cloud architects, infrastructure specialists and security stakeholders, you will help modernise existing platforms and deliver reliable cloud-native technology solutions.




Key Responsibilities




Design, build and maintain scalable cloud infrastructure across AWS and/or Microsoft Azure.
Develop and manage Infrastructure as Code using Terraform and associated automation tools.
Build, maintain and optimise CI/CD pipelines supporting application development and deployment.
Implement containerisation and orchestration solutions using Docker and Kubernetes.
Support cloud migration and modernisation of legacy enterprise applications.
Develop automation solutions to improve infrastructure provisioning, deployment and operational efficiency.
Implement monitoring, logging, alerting and performance management capabilities.
Collaborate with security teams to ensure cloud environments meet enterprise security and compliance requirements.
Troubleshoot complex infrastructure, deployment and application performance issues.
Support high availability, disaster recovery and operational resilience initiatives.
Provide technical guidance and contribute to cloud engineering standards and best practices.




Experience & Skills Required




5–8+ years' experience in DevOps, Cloud Engineering or Infrastructure Engineering.
Strong hands-on experience with AWS and/or Microsoft Azure.
Proven experience implementing Infrastructure as Code using Terraform.
Strong experience with CI/CD tools such as Azure DevOps, Jenkins or GitHub Actions.
Experience with Docker, Kubernetes and container orchestration.
Strong scripting and automation skills using Python, Bash or PowerShell.
Experience with cloud networking, security controls and identity management.
Knowledge of monitoring and observability tools such as Prometheus, Grafana or Azure Monitor.
Experience supporting enterprise-scale, highly available production environments.
Strong troubleshooting, problem-solving and collaboration skills.




Desirable Experience




Previous experience within insurance, banking or financial services.
Experience supporting insurance platforms, financial applications or regulated technology environments.
Knowledge of DORA, operational resilience and cloud security requirements.
Experience delivering enterprise cloud migration or infrastructure modernisation programmes.
Exposure to GitOps, Helm, Argo CD or advanced Kubernetes deployment practices.
Relevant AWS, Azure, Kubernetes or Terraform certifications.
