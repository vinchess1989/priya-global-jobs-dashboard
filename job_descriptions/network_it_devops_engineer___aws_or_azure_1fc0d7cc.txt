Are you a skilled DevOps Engineer ready for your next career move?

I specialize in connecting talented DevOps professionals with exciting opportunities across software development houses, start-ups, consultancies and large corporates.

I work with organisations that value automation, cloud technologies, modern infrastructure and strong technical talent, both within South Africa and internationally. Whether your expertise lies in cloud infrastructure, CI/CD, automation, containerisation, Kubernetes or the broader DevOps ecosystem, I’d be interested in connecting with you to explore opportunities aligned with your career goals.
Duties & Responsibilities
Requirements:

Relevant IT qualification and experience
Strong DevOps / Infrastructure experience
Strong CI/CD experience and pipeline development
Git and version control experience
Docker and containerisation
Kubernetes advantageous
AWS / Azure / GCP cloud experience
Infrastructure as Code (Terraform / CloudFormation) advantageous
Linux administration and scripting experience
Python / Bash / PowerShell advantageous
Monitoring, logging and observability experience
Networking and cloud infrastructure knowledge
Experience with automation and configuration management
Jenkins / GitLab CI / GitHub Actions / Azure DevOps advantageous
Agile / Scrum experience
Strong problem-solving skills and passion for technology
