Introduction

Our client in the financial services sector is establishing a shared Technology Platform to provide common engineering, deployment, security, integration, and operational capabilities to multiple delivery teams.

The platform will enable teams to build once and deploy consistently across on-premises, private cloud, and AWS environments while consuming standardised platform services and engineering controls. The objective is to eliminate duplicated technology effort, improve engineering consistency, and accelerate delivery across the estate.

The successful candidate will serve as a senior technical resource within the Platform Engineering function and will be responsible for establishing foundational capabilities across Developer Enablement, Engineering Standards, Deployment Automation, and the initial onboarding of workloads onto the target Kubernetes runtime platforms. The role will also provide technical leadership and mentoring to future engineers joining the platform team.

Duties & Responsibilities

Establish the foundational engineering platform consumed by multiple delivery teams.

Define and implement platform standards, engineering patterns, and reusable capabilities.

Develop self-service onboarding capabilities for platform consumers.

Establish platform governance, access controls, and operating standards.

Create reusable engineering assets that reduce duplication across teams.

 

CI/CD and Engineering Standards

Design and implement standard GitHub repository structures.

Implement branch protection, repository governance, and code ownership models.

Build and maintain reusable GitHub Actions workflows.

Design and maintain reusable "golden workflows" and engineering templates consumed by feature teams.

Implement security and quality gates within CI/CD pipelines.

Establish software supply chain controls and artifact management practices.

Implement SAST, SCA, DAST, container scanning, and secrets scanning controls.

 

Deployment Automation & GitOps

Implement GitOps deployment patterns using ArgoCD.

Build and maintain Helm deployment standards.

Configure automated environment promotion pipelines.

Support release orchestration using Octopus Deploy.

Define deployment governance, approval workflows, and rollback mechanisms.

Enable consistent deployments across Kubernetes and VM-based workloads.

 

Kubernetes & Runtime Enablement

Support onboarding of workloads onto Rancher and AWS EKS platforms.

Implement Kubernetes deployment standards and operational patterns.

Configure RBAC, namespaces, security controls, and deployment guardrails.

Support Infrastructure-as-Code implementation and automation.

Enable hybrid deployment patterns across AWS, on-premises, and private cloud environments.

 

Platform Leadership

Act as a senior engineering anchor within the platform team.

Mentor future DevOps and Platform Engineers.

Provide technical guidance to delivery teams adopting platform capabilities.

Participate in architecture, governance, and engineering standards discussions.

Collaborate with Architecture, Operations, and Feature Teams to onboard workloads and evolve platform capabilities.

Desired Experience & Qualification

6–8 years experience in software engineering, infrastructure engineering, cloud engineering, or DevOps.

5 years practical DevOps or Platform Engineering experience.

3 years Kubernetes (KaaS) administration and deployment experience.

Experience implementing enterprise CI/CD platforms and Infrastructure-as-Code solutions.

Experience supporting production environments and developing reusable engineering automation.

Experience working within regulated enterprise environments.

 

Preferred Experience:

Financial Services / Trading Technology experience.

Hybrid cloud experience.

Experience supporting large-scale engineering organisations.

 

Technical Skills Required

Source Control & Developer Enablement: GitHub Enterprise, Repository Governance, Branch Protection, CODEOWNERS, RBAC, Git Workflows

CI/CD & Automation: GitHub Actions, CI/CD Pipeline Development, Automated Testing, Software Supply Chain Security, Artifact Management (Nexus Repository Manager or equivalent)

DevSecOps: SAST, SCA, DAST, Container Security Scanning, Secrets Scanning, Security Gates

Deployment Automation: ArgoCD, GitOps, Helm, Octopus Deploy, Environment Promotion

Kubernetes & Cloud: Kubernetes / KaaS, Rancher, AWS EKS, Container Platforms, Linux Administration

Infrastructure as Code: Terraform (Mandatory)

Desirable / Advantageous: CyberArk, AWS Secrets Manager, Entra ID, Ping Identity, OpenTelemetry, Prometheus, Grafana, Loki, Tempo, Kafka, IBM MQ, Solace, PostgreSQL
