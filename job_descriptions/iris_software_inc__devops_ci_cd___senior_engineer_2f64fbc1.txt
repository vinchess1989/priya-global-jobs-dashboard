Job Description

Mandatory Skills: CI/CD & Source Control (CI/CD + Jenkins + Git), Amazon EC2, Amazon ECR, Docker, SNS, Amazon CloudWatch, Terraform (AWS Provider), AWS CloudFormation, Load Balancing, Auto Scaling, EventBridge

Key Responsibilities


Design and implement scalable CI/CD frameworks using Jenkins and Git to improve deployment reliability and release efficiency.
Define Infrastructure as Code standards and reusable provisioning templates using AWS CloudFormation, AWS CDK, and Terraform.
Lead containerization initiatives using Docker and manage container lifecycle processes through Amazon ECR.
Design and optimize container orchestration strategies using Amazon EKS and AWS Fargate.
Architect and optimize AWS hosting environments leveraging EC2, Auto Scaling, Load Balancers, AWS App Runner, and AWS Lambda.
Drive automation initiatives across infrastructure provisioning, deployment workflows, and environment management.
Define monitoring, logging, and observability standards using Amazon CloudWatch.
Implement event-driven integration patterns using SNS, SQS, and EventBridge to support scalable cloud architectures.
Review infrastructure code, deployment pipelines, and cloud configurations to ensure adherence to engineering standards.
Troubleshoot complex infrastructure, deployment, and platform issues through detailed root cause analysis.
Collaborate with various teams and stakeholders to support end-to-end cloud delivery and operational excellence.
Mentor team members on DevOps practices, cloud engineering standards, and automation strategies.
Drive continuous improvement initiatives for platform reliability, scalability, security, and operational efficiency.


Behavioral Competencies


Demonstrates strong ownership while driving cloud engineering and DevOps excellence.
Collaborate effectively with various teams and business stakeholders to ensure smooth delivery.
Promotes an automation-first culture through proactive process optimization and continuous improvement.
Applies strong analytical thinking to evaluate complex cloud and infrastructure challenges.
Demonstrates adaptability while managing evolving technologies and cloud environments.
Communicate effectively regarding platform health, risks, dependencies, and improvement opportunities.
Maintains high attention to detail across cloud infrastructure, automation, and deployment activities.
Encourages continuous improvement in DevOps processes, automation frameworks, and operational practices.
Supports knowledge sharing and mentoring to strengthen team capabilities.
Balances platform reliability, scalability, and business priorities while driving delivery excellence.
