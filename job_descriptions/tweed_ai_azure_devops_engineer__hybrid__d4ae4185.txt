THIS IS A HYBRID ROLE: PLEASE ONLY APPLY IF WITHIN COMMUTING DISTANCE OF EDINBURGH (WILL BE AUTOMATICALLY REJECTED OTHERWISE)




The Role:

Make releases routine: fast, repeatable and safe.
Own our CI/CD pipelines and Azure infrastructure as code.
 Keep test and production environments secure, observable and cost-effective.
Work closely with developers and coach them on pipelines and Azure.
Help the whole team own building and deploying software, rather than handing it off.




Key Responsibilities:

CI/CD: design, build and maintain YAML pipelines in Azure DevOps, including build, automated test, release approvals and environment gates for test and production.
Infrastructure as code: provision and manage Azure resources with Bicep or Terraform, versioned and deployed through pipelines rather than the portal.
Azure platform: look after App Services, Azure Functions, Azure SQL Database, Storage, Key Vault, networking and, where used, containers (AKS or Container Apps).
Security and access: manage Microsoft Entra ID access, managed identities, service connections and secrets; apply least privilege and keep secrets out of code.
Monitoring and reliability: set up Azure Monitor, Application Insights and alerting; take part in incident response and blameless post-incident reviews.
Database deployment: automate schema changes and migrations for Azure SQL safely across environments.
Cost management: track and reduce Azure spend, for example by right-sizing resources and scheduling non-production environments.
Ways of working: maintain branch policies, pull request checks and repository standards; document processes in the team wiki.
Collaboration: support and coach developers on pipelines, Azure and good release practice.
Scaling: design and configure services to scale with demand, using autoscaling for App Service, AKS or Functions, and load-test before major releases.
Messaging and event-driven processing: build and support asynchronous workflows with Azure Service Bus, including queues, topics, retries and dead-letter handling.




Essential Skills and Experience

[3+] years in a DevOps, platform or cloud engineering role.
Hands-on experience building YAML pipelines in Azure DevOps (or GitHub Actions, with willingness to move to Azure DevOps).
Strong working knowledge of core Azure services: App Service, Functions, Azure SQL, Storage, Key Vault, virtual networks.
Infrastructure as code with Bicep, ARM or Terraform.
Scripting in PowerShell and/or Bash; comfortable with the Azure CLI.
Confident with Git, branching strategies and pull request workflows.
Understanding of Entra ID, role-based access control and secure secret management.
Clear communication: you can explain technical choices to developers and non-technical colleagues.




Desirable Skills:

Containers: Docker, Azure Container Apps or AKS.
Some knowledge of PostgreSQL.
.NET build and deployment experience.
Automated database deployment (SQL projects/DACPAC, EF Core migrations or Flyway).
Observability with Application Insights, Log Analytics and KQL.
Experience in financial services or another regulated environment (audit trails, change control, data protection).
Microsoft certifications such as AZ-400 (DevOps Engineer Expert), AZ-104 (Azure Administrator) or AZ-305 (Solutions Architect).
