Introduction

The DevOps & Infrastructure Technician will be responsible for managing, monitoring, securing and maintaining the server infrastructure supporting GameOnStudios’  WRG/RGS environment and associated game services.
The successful candidate will ensure that production services operate reliably, that software releases are deployed through controlled processes, and that effective monitoring, backup, recovery and security controls are maintained.
The role will work closely with the CTO, software developers, database administrator, compliance representatives and external hosting or platform providers to support existing operations and the introduction of new games and integrations.

Duties & Responsibilities

1. Server and infrastructure management

Administer and maintain the servers, operating systems, application-hosting services and infrastructure within GameOnStudios’ operational control. Manage service configurations, scheduled tasks, storage, network connectivity, domain records and security certificates.
Maintain appropriate separation between development, testing, certification and production environments. Coordinate infrastructure changes and maintenance with hosting providers where services are externally managed.

2. Monitoring, availability and incident response

Implement and maintain monitoring for server health, application availability, API response times, database connectivity, storage capacity and critical background processes.
Configure actionable alerts and investigate service interruptions, application failures and performance degradation. Monitor operational indicators such as failed game launches, integration errors and unresolved transaction processing, escalating application or financial-data issues to the appropriate owners.
Take ownership of incident coordination, provide timely updates, document root causes and track corrective actions.

3. Software deployment and automation

Develop and maintain continuous integration and deployment pipelines for approved game services, APIs and supporting applications.
Automate repeatable deployment and administration tasks using version-controlled scripts and configuration. Ensure releases are tested, authorised, traceable and accompanied by appropriate rollback or recovery procedures.
Coordinate deployments with developers and the database administrator, taking account of active game sessions, in-progress transactions and database compatibility. Perform post-deployment checks before confirming a release as successful.

4. Infrastructure security and access management

Maintain secure server configurations, access controls, firewall rules and remote administration methods. Implement individual user accounts, least-privilege access and multifactor authentication where supported.
Manage service credentials, API secrets and certificate renewals through approved secure processes. Coordinate vulnerability remediation, operating-system updates and dependency patching through change control.
Review privileged access periodically and ensure access is removed promptly when no longer required.

5. Backups, disaster recovery and business continuity

Implement and monitor backups for relevant databases, application configurations, infrastructure configurations and operational records.
Maintain protected backup copies separate from the primary production environment and conduct scheduled restoration tests. A successful backup job alone must not be treated as proof of recoverability.
Develop and maintain recovery procedures with the CTO, database administrator and service providers. Test recovery against agreed targets for restoration time and acceptable data loss, including checks that recovered services and transaction records remain consistent.

6. Database operational support and transaction integrity

Work with the database administrator to monitor database availability, storage utilisation, connectivity, backup status and replication health where applicable.
Assist with infrastructure-related database performance investigations and coordinate approved maintenance or schema releases.
Support the investigation of interrupted or delayed transaction processing using logs and approved diagnostic tools. Any transaction replay, reconciliation or data correction must follow an authorised, documented procedure with the appropriate application and database owners.

7. Compliance support and change control

Maintain infrastructure inventories, configuration baselines, deployment records, access records and operational evidence required by the company’s approved compliance processes.
Support internal audits, security assessments and testing-laboratory requests relevant to infrastructure operations. Ensure production changes follow the applicable approval process and preserve the traceability of deployed software and configuration.
Escalate any proposed change that may affect an approved or certified system configuration before implementation.

8. Documentation, provider coordination and capacity planning

Maintain current infrastructure diagrams, operating procedures, troubleshooting guides, recovery instructions and escalation contacts.
Coordinate technical incidents and maintenance with hosting companies, platform suppliers and other service providers. Track capacity, resource utilisation and infrastructure costs, and recommend improvements as game content, integrations and usage increase.
Provide regular operational reporting to the CTO, highlighting incidents, risks, upcoming maintenance and outstanding corrective actions.
Desired Experience & Qualification
Production operations: Approximately three to five years of relevant experience in DevOps, infrastructure engineering or systems administration, including direct responsibility for live production services.
Server administration: Strong practical experience administering application servers. For a Windows-based deployment, this should include Windows Server, IIS, Windows services and troubleshooting hosted .NET applications. Linux administration should be required where it forms part of the deployed environment.
Deployment and automation: Experience with Git, automated build and deployment pipelines, and scripting using PowerShell, Bash or Python.
Networking and security: Practical knowledge of TCP/IP, DNS, HTTPS/TLS certificates, firewalls, VPNs, access controls and secure remote administration.
Database operations: Experience supporting relational database environments, interpreting database-related errors and coordinating backup, restoration and maintenance activities with a database administrator.
Monitoring and recovery: Demonstrable experience configuring alerts, investigating production incidents, analysing logs and testing backup restoration and recovery procedures.

 

A relevant qualification in information technology, computer science or a related field is desirable. Equivalent practical experience should also be considered.
