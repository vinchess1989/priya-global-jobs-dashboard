This position is listed on behalf of a partner company, who manages all applications and next steps. Our partner is looking for a Senior DevOps Engineer (Azure + AWS) based in Ireland.

As a Senior DevOps Engineer, you will design, deploy, and maintain scalable cloud infrastructure across Microsoft Azure and AWS environments. You will play a key role in ensuring the reliability, security, and performance of cloud-based services supporting a large-scale data science platform. Working with technologies such as Terraform, Kubernetes, Docker, and GitOps, you will automate infrastructure provisioning and streamline deployment processes. You will also develop robust CI/CD pipelines and implement advanced deployment strategies to minimize downtime and operational risks. Collaborating with a geographically distributed engineering team, you will contribute to infrastructure improvements and cloud operations. This role offers the opportunity to take ownership of critical technical initiatives in a dynamic, cloud-focused environment.

Accountabilities

You will be responsible for building and optimizing cloud infrastructure, automating operational processes, and maintaining reliable deployment environments across Azure and AWS.


Design, deploy, and manage scalable cloud infrastructure and services within Microsoft Azure, including Azure Kubernetes Service (AKS), Private Link Services, Azure Networking, and Azure Database for PostgreSQL Flexible Server.
Support the development and deployment of cloud environments primarily based on Azure and AWS.
Implement and maintain Infrastructure as Code (IaC) solutions using Terraform to ensure consistent and reliable infrastructure provisioning.
Establish and enforce best practices for cloud security, networking, governance, and cost optimization, including VNet, NSG, Firewall, and Load Balancer configurations.
Manage tenant onboarding, infrastructure changes, and scripted automation based on predefined templates.
Maintain containerization and orchestration technologies, including Docker and AKS, using Helm and GitOps workflows such as ArgoCD and GitHub Actions.
Develop, maintain, and optimize CI/CD pipelines using GitHub Actions.
Implement advanced deployment strategies, including Blue/Green and Canary deployments, to reduce downtime and operational risks.
Create and maintain automation scripts using Python, PowerShell, and Bash to streamline repetitive tasks and infrastructure provisioning.
Collaborate with a geographically distributed team through established development processes, regular planning sessions, sync-ups, and sprints.
Participate in a rotating on-call schedule to handle critical incidents and maintain high service availability.


Requirements

The ideal candidate combines strong cloud infrastructure expertise with hands-on experience in automation, infrastructure management, and modern DevOps practices.


Strong knowledge of Microsoft Azure, with practical experience using AKS, Private Link Services, Entra ID, Managed Identities, and Private Endpoints.
Good working knowledge of AWS and its core infrastructure components, including EC2, VPC, and IAM.
Experience with Terraform, including developing and managing reusable modules for both Azure and AWS environments.
Solid understanding of GitOps practices and deployment automation using GitHub Actions, ArgoCD, and Helm Charts.
Experience with Infrastructure as Code, cloud automation scripting, and cloud-based deployment processes.
Knowledge of containerization technologies and Kubernetes-based infrastructure management.
Ability to independently manage infrastructure changes, troubleshoot operational issues, and contribute to reliable cloud environments.
Strong collaboration and communication skills, with the ability to work effectively within a geographically distributed team.


Nice-to-have Certifications


Microsoft Certified: Azure Administrator Associate (AZ-104).
Microsoft Certified: Azure DevOps Engineer Expert (AZ-400).
AWS Certified SysOps Administrator – Associate.
AWS Certified DevOps Engineer – Professional.
