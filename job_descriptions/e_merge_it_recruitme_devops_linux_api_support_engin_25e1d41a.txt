DEVOPS LINUX API SUPPORT ENGINEER | 100% REMOTE |R600K PA




LINUX IS YOUR HAPPY PLACE. KUBERNETES DOESN'T SCARE YOU. AWS IS YOUR PLAYGROUND.




Got a knack for fixing things, figuring out why they broke and making sure they don't break again?

We're looking for a DevOps Linux API Support Engineer who loves getting hands-on with cloud infrastructure, containers, automation and all the technical stuff that keeps production environments ticking.

You'll be troubleshooting, supporting, optimising and working with some seriously useful tech. No two days need to look the same.

Oh, and did we mention? You can do it all from home. 100% REMOTE.




WHAT'S ON YOUR TO-DO LIST?

Keep Linux environments running smoothly and troubleshoot those tricky issues.
Get hands-on with Docker and Kubernetes.
Work with AWS services including EC2, VPC, IAM, EKS, S3, CloudWatch and Route53.
Support production environments and get to the bottom of technical gremlins.
Work with networking, security and performance challenges.
Get stuck into Git, CI/CD, automation and Infrastructure as Code.
Use Bash, Python and REST APIs to make life easier.
Help customers and business stakeholders find solutions without getting lost in technical jargon.




WHAT YOU BRING TO THE TERMINAL:

3–5 years' experience in DevOps, Cloud Engineering, Linux Administration or a similar role.
Strong Linux administration, shell scripting and troubleshooting skills.
Hands-on Docker and Kubernetes experience.
Working knowledge of AWS cloud services.
Understanding of Git, CI/CD and Infrastructure as Code.
Bash and/or Python scripting experience.
Experience supporting live production environments.
The communication skills to work with customers and stakeholders.




BADGES ARE A BONUS:

AWS Solutions Architect Associate, or working towards it.
Certified Kubernetes Administrator (CKA).
Certified Kubernetes Application Developer (CKAD).




EXTRA BRAGGING RIGHTS IF YOU KNOW:

Axway API Management and Axway Secure Transport.
API Gateways and Managed File Transfer.
OpenShift and Helm.
Terraform and Ansible.
GitHub Actions and Jenkins.
Azure DevOps.




THE GOOD STUFF:

Location: Wherever your Wi-Fi works!
Work model: 100% Remote
Type: Permanent
Salary: R600K CTC per annum, depending on experience
