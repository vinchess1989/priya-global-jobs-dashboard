Terraform & AWS EKS DevOps Engineer

PROJECT CITADEL / APERTURE  |  SPGI  |  ENGINEERING JOB DESCRIPTION

Seniority: L3/L4 hands-on engineer    

Role focus: Infrastructure-as-code, EKS and CI/CD engineering for Citadel/Aperture migration delivery.

Core responsibilities and requirements

1.  Design, review, refactor and execute Terraform modules for AWS infrastructure and EKS workloads; write production-quality code from day one.

2.  Build and troubleshoot EKS clusters, node groups, Kubernetes workloads, deployments, ingress, networking, IAM/IRSA and storage integrations.

3.  Migrate application deployment pipelines and reusable automation to GitHub Actions with secure runners and environment approvals.

4.  Integrate Terraform planning/apply workflows with GitHub organizations, repositories, pull-request reviews and change approval controls.

5.  Update Dockerfiles, container-image references and build scripts to use approved ChainGuard images and internal Artifactory package endpoints.

6.  Configure AWS integrations including VPC, ECR, load balancers, IAM, certificates/TLS, Secrets Manager and observability as required.

͏

7.Troubleshoot Terraform state, provider/module errors, EKS node readiness, pods, rollout failures and CI/CD runner connectivity.

8.  Work hands-on with Linux (RHEL/Ubuntu), Git, Bash/Python, VS Code, GitHub Copilot and Infrastructure-as-Code testing.

9.  Plan migration validation, disaster recovery/rollback procedures, configuration drift remediation and release readiness checks.

10.  Join daily scrum and repository-owner calls; own engineering deliverables, ServiceNow changes/tasks, customer sign-off, P1/P2 recovery and RCA actions.

Delivery expectations: Independent hands-on coding, direct customer/repository-owner collaboration, flexible overlap with 4–10 PM IST meetings, clear documentation and completed migration validation.

Preferred: Relevant GitHub, Azure, AWS, Terraform or Kubernetes certifications; financial-services change-control experience.
