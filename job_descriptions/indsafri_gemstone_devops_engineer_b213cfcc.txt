Purpose of the Position

The Linux/Windows Systems Administrator is responsible for the installation, configuration,

administration, monitoring, maintenance, and optimisation of Linux servershosting GemStone/S application environments. The role ensuresthe stability, security, performance, and availability of production, test, and development systems while working closely with application development teams, infrastructure teams. This is the primary DevOps role for the Gemstone/s environment.




Responsibilities




Linux Server Administration

Configure, and maintain Linux operating systemsacross development, test, prelive, and production environments.
Coordinate operatingsystem upgrades, patching,and security updateswith I&O and other stakeholders.
Manage user accounts, permissions, groups, and accesscontrols.
Monitor and maintainstorage, file systems,network services, and system services.
Troubleshoot server, operating system, andinfrastructure issues.

GemStone/S Administration

Monitor and maintain GemStone/S environments.
Configure and upgrade GemStone/S environments with seniordevs.
Monitor GemStone processes(stone, netldi, gem, and repository).
Monitor user and bulk processes.
Monitor GemStone backups, replication and recovery procedures.
Monitor repository integrity checksand report repository-related issues.

Deploy Pipeline

Monitor deployment pipelines and respond to issues.
Support application deployments and environment configuration changes (Jenkins, git, Ansible, OS Scripts).
Assist development teams with performance analysisand troubleshooting.




Monitoring and Performance Management

Monitor server health, application availability, disk usage,memory utilisation, and system performance.
Implement proactivemonitoring and alertingmechanisms.
Enhance observability by integrating with organisation tools (DataDog)

Security and Compliance

Enforce Linux security standards and best practices.
Manage SSH access, certificates, firewall configurations, and vulnerability remediation.
Ensure compliance with company securitypolicies and audit requirements.
Participate in security reviewsand incident responseactivities.

Backup, Recoveryand Business Continuity

Monitor daily restore procedures.
Develop, maintain, and test backupand recovery procedures.
Perform regular disaster recovery validation exercises.
Ensure recovery time and recovery point objectives are met.
Maintain documentation of recovery procedures.

Automation and DevOps Support

Maintain and enhance automation scripts for administration and operational tasks (Jenkins and Ansible).
Support CI/CD processes and deployment automation (Jenkins, Ansible, terragrunt and bat/bash).
Implement configuration management and infrastructure-as-code practices where applicable.
Improve operational efficiency through automation.

Documentation

Maintain accurate technical documentation for systems, configurations, procedures, and support activities.
Create and update operational runbooks and troubleshooting guides.
Document architecture changes and system dependencies.

Support and Incident Management

Support the investigation of production incidents.
Conduct root causeanalysis and implementpreventative measures.
Work with internalteams to resolvecomplex issues.




AI

Use approved AI-assisted tools to enhancecoding, testing, troubleshooting, and documentation activities.
Validate and apply appropriate governance to AI-generated outputs, ensuringquality, security, and compliance requirements are met.




Qualifications and experience

Diploma or Degreein Information Technology, Computer Science, Engineering, or a relatedfield.
Relevant Linux certifications will be advantageous.
5+ years of Linux systemsadministration experience.
2+ years supporting enterprise application platforms.
Experience administering mission-critical production environments.
Experience supporting GemStone/S environments is highly advantageous.







Technical Competencies Required




Linux Administration

Red Hat Enterprise Linux, Ubuntu, or similar distributions.
Shell scripting (Bash,Python, or similar).
Systems, networking, storage management, and performance tuning.
MQ configuration

Gemstone

GemStone/S Skills will be advantageous
Backup and recovery procedures.
Performance monitoring and capacity planning.
MFA integration - Client / tokens

Infrastructure

Cloud platforms - AWS advantageous.
TCP/IP networking.

Monitoring and Automation

DataDog (Prometheus).
Git version control.
Ansible or similar automation tools.
CI/CD tooling knowledgeadvantageous.




Behavioural Competencies

Self driven to learn.
Strong analytical and problem-solving abilities.
Excellent troubleshooting skills.
Ability to work independently and take ownership of systems.
Strong communication and documentation skills.
Attention to detail and commitment to operational excellence.
Ability to performeffectively under pressureduring incidents.
Collaborative team player with customer-focused attitude.
