Introduction

Are you a technically minded problem-solver with a passion for cloud technologies, automation and modern infrastructure? Do you enjoy troubleshooting complex production environments, working with container technologies and ensuring systems operate reliably? This is an exciting opportunity for a DevOps Support Engineer to bring their expertise in Linux, Kubernetes and AWS into a dynamic technical environment.

 

The successful candidate will play an important role in supporting and maintaining cloud infrastructure, resolving technical challenges and engaging with customers and business stakeholders to deliver effective support solutions.

Duties & Responsibilities

Minimum Requirements & Technical Expertise:

 

3 to 5 years' experience in DevOps, Cloud Engineering, Linux Administration or a similar technical role
AWS Solutions Architect Associate (or studying towards)
Certified Kubernetes Application Developer (CKAD)
Certified Kubernetes Administrator (CKA)
Strong experience in Linux administration, including shell scripting, networking fundamentals, performance troubleshooting and security best practices
Hands-on experience with Docker containers, Kubernetes administration, Kubernetes fundamentals and container troubleshooting
Working knowledge of AWS cloud services, including EC2, VPC, IAM, EKS, S3, CloudWatch and Route53
Experience with Git, CI/CD concepts, automation and Infrastructure as Code principles
Exposure to programming and scripting languages such as Bash and Python, as well as REST APIs
Proven ability to troubleshoot and support production environments
Experience interacting with customers and business stakeholders

 

Advantageous Experience:

 

Exposure to the following technologies and platforms will be highly beneficial:
Axway API Management and Axway Secure Transport
API Gateway technologies and Managed File Transfer solutions
OpenShift and Helm
Terraform and Ansible
GitHub Actions and Jenkins
Azure DevOps
