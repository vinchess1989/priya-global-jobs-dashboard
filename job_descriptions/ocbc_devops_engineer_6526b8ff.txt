Job Summary

We are seeking a highly skilled , innovative and hands-on DevOps Engineer with strong expertise in CI/CD pipeline development, automation and software engineering practices. The ideal candidate will be responsible for designing, developing and maintaining enterprise-scale CI/CD pipelines using Jenkins and Groovy while leveraging Python scripting and AI-driven capabilities to improve delivery efficiency, developer experience, security and operational excellence.

This role requires a hands-on engineer who can build reusable pipeline frameworks, integrate DevSecOps controls, automate manual processes and explore emerging AI technologies to continuously enhance the organization's software delivery lifecycle.

Roles And Responsibilities


CI/CD Pipeline Engineering
Design, develop and maintain enterprise-scale CI/CD pipelines using Jenkins , Groovy , Python , Shell scripting and REST APIs.
Develop reusable and standardized pipeline libraries, shared components and automation frameworks.
Create and maintain pipeline-as-code solutions to support application build, test, security scanning, release and deployment processes.
Continuously improve pipeline performance, scalability, reliability and developer experience.
Software Development & Automation:
Create automated workflows to eliminate manual tasks and improve engineering productivity.
Apply software engineering best practices including code reviews, testing, version control and documentation.
Develop dashboards, reporting solutions, and self-service automation capabilities for development teams.
Integrate security tools into CI/CD pipelines and implement automated quality gates and security controls throughout the software delivery lifecycle.
AI-Driven Engineering & Innovation:
Identify opportunities to leverage AI and Generative AI technologies to improve DevOps processes and developer productivity.
Design and implement AI-assisted solutions for:
Pipeline optimization
Intelligent troubleshooting
Auto code remediation
Deployment validation
Root cause analysis
Evaluate emerging AI technologies and incorporate them into the DevOps toolchain where appropriate.
Drive continuous improvement by introducing AI capabilities across CI/CD and automation platforms.
Leverage AI-powered code analysis and remediation within CI/CD workflows to proactively detect quality and security issues, recommend code fixes and enhance developer efficiency, code quality and delivery speed.
Infrastructure as Code (IaC) & Configuration Management:
Design and implement IaC solutions using Ansible, Terraform and other automation frameworks for Database and Infra provisioning.
Automate infrastructure provisioning, server configuration, middleware deployment and operational processes.
Integrate infrastructure automation into CI/CD pipelines.
Documentation & Knowledge Sharing:
Maintain technical documentation for CI/CD frameworks, automation solutions, infrastructure code, and operational procedures.
Define and promote engineering standards and best practices across the DevOps ecosystem.
Conduct workshops and knowledge-sharing sessions on DevOps, CI/CD, Ansible, Infrastructure as Code, and AI-driven engineering practices.

Technical Skills


Strong expertise in Jenkins, Groovy, Python, Shell Scripting, Git/Bitbucket, REST APIs and CI/CD Pipeline Development including the development of reusable Jenkins Shared Libraries and Pipeline Frameworks.
Hands-on experience with Infrastructure as Code (IaC), Ansible, configuration management, environment provisioning, automated application deployments and integrating infrastructure automation into CI/CD pipelines.
Sound knowledge of DevSecOps practices, including integration of SAST, SCA and IAST controls within CI/CD pipelines and experience with tools such as Engineering tools , Collaboration tools and DevSecOps tool set.
Minimal Experience in leveraging GenAI and AI-assisted development tools to improve software delivery, pipeline efficiency, automation, code quality, security remediation and developer productivity.
Strong understanding of SDLC, DevOps principles, application lifecycle management, automation frameworks and enterprise-scale software delivery practices.


Requirements


Bachelor’s or Master’s degree in Computer Science, Engineering, or related field.


Experience


Minimum 10 years of hands-on experience in DevOps engineering and tool administration.
