Job Summary

We are seeking an experienced Azure DevOps Engineer with hands-on experience in designing, implementing, and managing DevOps practices using Microsoft Azure. The candidate will be responsible for driving automation, continuous integration, continuous delivery (CI/CD), and infrastructure as code (IaC) to ensure efficient and reliable software deployment pipelines.

Key Responsibilities


Design, build, and maintain scalable and resilient CI/CD pipelines using Azure DevOps services.
Automate infrastructure provisioning and management using tools like ARM templates, Terraform, or Azure CLI.
Collaborate with development, QA, and operations teams to streamline and enhance release management processes.
Monitor, troubleshoot, and optimize system performance and reliability in cloud environments.
Implement automated testing frameworks and ensure quality assurance within the deployment pipelines.
Establish best practices and governance for cloud deployment and security.
Manage version control using Git and Azure Repos.
Define and implement configuration management and container orchestration with Kubernetes, Docker, or Azure Kubernetes Service (AKS).
Engage in capacity planning, disaster recovery, and backup strategies in Azure cloud.
Mentor and guide junior team members and coordinate cross-team DevOps initiatives.
Stay updated with the latest Azure DevOps tools, industry trends, and best practices.


Required Skills And Qualifications


Bachelor’s degree in Computer Science, Engineering, or related field.
Minimum 8 years of experience in DevOps engineering or related roles.
Strong expertise with Azure DevOps, including Pipelines, Boards, Repos, and Artifacts.
Hands-on experience with Infrastructure as Code tools such as ARM templates, Terraform, or Ansible.
Proficiency in scripting languages like PowerShell, Bash, or Python.
Extensive experience with CI/CD tools and practices.
Deep knowledge of cloud platforms, especially Microsoft Azure services (Azure App Services, Azure VMs, Azure Storage, AKS, etc.).
Experience with containerization using Docker and orchestration using Kubernetes or AKS.
Solid understanding of networking, security, and identity management in cloud environments.
Familiarity with monitoring and logging tools like Azure Monitor, Application Insights, and ELK stack.
Strong understanding of Agile and Scrum methodologies.
Excellent problem-solving skills and ability to work collaboratively in a fast-paced environment.
Strong communication skills to interact effectively with technical and non-technical stakeholders
