About the Role

We're looking for a DevOps Engineer to design, build and run DevOps solutions, ideally for Salesforce applications. You'll own our CI/CD pipelines and cloud infrastructure, keeping them scalable, secure and cost-efficient. Salesforce experience is a bonus, but we'll consider strong candidates without it.




What You'll Do

Assess, design and engineer DevOps solutions, with a focus on Salesforce environments where applicable
Build, maintain and test end-to-end CI/CD pipelines for both infrastructure provisioning and application deployment
Automate infrastructure deployment and configuration to improve scalability and flexibility
Manage cloud resources to balance performance and cost
Safeguard the security and compliance of the DevOps environment
Work with cross-functional teams to roll out DevOps practices and provide technical guidance throughout the development lifecycle




What You'll Bring

Hands-on experience provisioning and managing AWS infrastructure
Experience building and maintaining infrastructure using Infrastructure as Code (IaC)
Solid understanding of AWS networking, with the ability to troubleshoot connectivity issues
Proficiency with the AWS CLI and Linux system administration
Experience with infrastructure maintenance, software patching, and backup and restoration
Experience implementing CI/CD pipelines for infrastructure and application deployments
Ability to analyse security and compliance findings (including ABLR reports), assess their impact and carry out the right remediation
