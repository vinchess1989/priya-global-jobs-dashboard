DevOps Engineer - Manchester (3 days Office / 2 days remote)



Our Manchester based client is expanding rapidly and are now seeking a skilled DevOps Engineer to optimise and scale their Azure-based infrastructure, while leading on automation, security, and performance across the software development lifecycle.

My client places their people and product at the heart of everything they do. With a collaborative, open culture, ideas are encouraged from all levels. The working environment is friendly, inclusive, and innovative - with regular socials, flexible working, and a strong focus on continuous improvement and quality delivery.



Key Responsibilities


Design, build and maintain CI/CD pipelines using Azure DevOps
Automate build, test, deployment and infrastructure provisioning processes
Manage Azure resources using Terraform, Bicep or ARM templates
Support applications running in Azure App Services, Function Apps and other services
Integrate tools for automated testing, code quality and security (e.g. SonarCloud, Snyk)
Set up monitoring and incident response with Azure Monitor and Application Insights
Manage secrets and access control to support secure cloud practices
Work closely with developers and stakeholders to deliver scalable, reliable solutions


Skills and Experience:


3+ years' experience in a DevOps or Cloud Engineering role
Practical experience with Azure DevOps and CI/CD pipelines
Proficient in scripting languages such as PowerShell, Bash or Python
Hands-on experience with Docker and containerisation
Version control experience with Git or Azure Repos
Understanding of Agile/Lean methodologies
Familiar with tools for code quality and security
A proactive and detail-oriented mindset


Desirable:


Penetration testing or security certification
Experience using Terraform, Bicep or ARM templates
Familiarity with blue/green and canary deployment strategies


Benefits


Competitive salary
Flexible working options
25 days’ holiday plus public holidays and your birthday off
Private medical and dental insurance
Life assurance and enhanced parental leave
Ongoing professional development
