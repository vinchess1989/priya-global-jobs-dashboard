Staffingine LLC is excited to announce an excellent Fulltime opportunity with one of our top clients !




Position: Senior DevOps Engineer

Location: Mississauga, Canada

Mode: Fulltime

Experience: 10+ Years

Salary: CAD 125,000 per annum + Benefits




Summary

Candidate will need to work closely with software developers, security teams, and system administrators to build scalable, resilient, and self-healing systems.
Candidate needs to be a self-reliant resource and well versed in doing basic java/ config fixes instead of depending on dev team for everything




Candidate needs to be proficient in:

CI/CD & Automation – pipelines and build/release management
Ensure environment consistency
OSE monitoring set up, app dynamics set up, configuration management, helm, tekton, harness, LSE, openshift Kubernetes, docker, autosys, Ansible
Containerization, orchestration set up/ kafka configurations, micro services support
secret management, SLTN process
Python and linux is a plus
github, BB, Jenkins, maven, Grafana, splunk, ELK
high level understanding of networking / firewall/ https/ TCP/IP etc
Good at oracle and mongo queries
Collaborative Mindset: Strong interpersonal skills with the ability to work effectively across cross-functional development and operations teams.
Problem-Solving: Analytical thinker with excellent troubleshooting skills and a methodical approach to root-cause analysis.
Communication: Excellent verbal and written communication skills, with the ability to document technical architectures and present complex concepts clearly
