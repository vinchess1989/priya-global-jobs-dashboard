Role : Automation Tester - Selenium, C#,API, Devops or CI/CD- Core Banking Experience

Job Type: Contract/Fulltime

Location : Sandton, JHB (5 Days Work from Office)

Client: Banking Domain




Qualifications

8+ years of software testing and quality assurance experience.
8+ years of test automation experience.
Strong proficiency with xUnit/NUnit, C#/.NET, and REST API testing.
Hands‑on experience using Postman or Bruno, SQL, and Azure Cosmos DB.
Expertise in Azure DevOps, Azure Pipelines, and CI/CD integration.
Proven experience testing Core Banking or financial services platforms; Finacle experience preferred.




Responsibilities

Own end‑to‑end testing for project and BAU initiatives from planning through release.
Design and execute risk‑based test strategies covering functional, integration, API, regression, end‑to‑end, and UAT testing.
Build, maintain and scale automated test frameworks and regression suites using xUnit/NUnit and C#/.NET.
Develop and run automated API tests with Postman/Bruno and validate data via SQL and Azure Cosmos DB.
Integrate automated tests into Azure DevOps CI/CD pipelines and support continuous testing practices.
Analyse requirements to ensure comprehensive business and technical test coverage.
Manage defects, drive root‑cause analysis and implement quality improvements.
Lead testing for integrations, data migrations and data validation across Core Banking systems.
Mentor junior QA engineers and promote quality engineering best practices across the team.
Collaborate with cross‑functional Agile teams and stakeholders throughout the delivery lifecycle.




If interested, please share your updated CV at damodar@samaha.co.za
