Job Title: Staff Systems Engineer

Location: Cork or Dublin, Ireland

Reports to: Sr IT Architect

Job Overview

We are seeking a Staff Infrastructure Automation Engineer to join our Platform Engineering team and build the software systems that power our infrastructure. This is a hands-on engineering role focused on developing automation platforms, infrastructure-as-code frameworks, developer tooling, and cloud infrastructure services at scale.

You will design and build reusable automation products using Python, Terraform, and Ansible that enable self-service infrastructure provisioning, configuration management, compliance enforcement, and lifecycle automation across our hybrid cloud environments.

The ideal candidate thinks like a software engineer first, applying modern development practices such as API design, testing, CI/CD, version control, code reviews, and platform architecture to infrastructure challenges. Experience with virtualization technologies such as Nutanix, KVM, and VMware is important, but the primary focus of this role is engineering automation solutions rather than day-to-day infrastructure administration. As a Staff Engineer, you will provide technical leadership, influence platform architecture, establish engineering standards, and mentor other engineers in building scalable automation systems.

Job Responsibilities

Automation Platform Development


Design, develop, and maintain infrastructure automation platforms and services using Python and Infrastructure-as-Code technologies.
Build reusable Terraform modules, Ansible frameworks, and internal developer tools that enable self-service infrastructure deployment.
Develop API-driven automation solutions that integrate infrastructure platforms, cloud services, and enterprise systems.
Create automation workflows that eliminate manual operational tasks and improve engineering productivity.


Software Engineering & Platform Development


Write high-quality, testable, maintainable Python code following modern software engineering practices.
Design and implement REST API integrations, automation services, and infrastructure orchestration frameworks.
Develop automated testing strategies for infrastructure code, including unit, integration, and validation testing.
Participate in architecture reviews, code reviews, and technical design discussions.


CI/CD & DevOps Engineering


Build and maintain CI/CD pipelines using GitHub Actions, GitLab CI, Jenkins, or equivalent platforms.
Implement GitOps workflows, policy-as-code, and automated compliance validation.
Create automated release and deployment processes for infrastructure and platform services.
Drive engineering excellence through code quality standards, automated testing, and developer experience improvements.


Infrastructure & Virtualization Engineering


Develop automation and orchestration capabilities for Nutanix, VMware, and KVM-based environments through APIs and Infrastructure-as-Code.
Build scalable provisioning and lifecycle management solutions for compute, storage, and networking resources.
Support hybrid cloud automation across AWS and Azure environments.
Collaborate with infrastructure teams to modernize platforms through automation-first approaches.


Technical Leadership


Define engineering standards and best practices for infrastructure automation and platform development.
Mentor engineers through design reviews, code reviews, and technical guidance.
Lead complex automation initiatives and drive adoption of platform engineering principles.
Influence long-term automation and platform strategy.


Job Qualifications

Software Engineering & Development


5-8 years of experience in software engineering, platform engineering, infrastructure automation, or DevOps engineering roles.
Strong Python development skills with experience building production-quality applications, automation services, APIs, or developer tools.
Experience with software design patterns, testing frameworks, source control, and code review processes.
Strong understanding of API integration, automation architecture, and distributed systems concepts.


Infrastructure Automation


Expert-level Terraform experience, including development of reusable modules, multi-environment architectures, and automation frameworks.
Strong Ansible experience, including role development, framework design, and large-scale automation implementations.
Experience designing Infrastructure-as-Code solutions for enterprise-scale environments.
Strong understanding of GitOps methodologies and automation-first operational models.


CI/CD & Developer Platforms


Experience building CI/CD pipelines using GitHub Actions, GitLab CI, Jenkins, or similar platforms.
Experience implementing automated testing, release automation, and deployment workflows.
Strong Git and software development lifecycle experience.


Infrastructure Technologies


Experience automating at least two of the following platforms through APIs, SDKs, or Infrastructure-as-Code:
Nutanix AHV / Prism / AOS
VMware vSphere / ESXi
KVM / QEMU
Experience with AWS and/or Azure infrastructure services.
Working knowledge of networking concepts, infrastructure architecture, and hybrid cloud environments.

Leadership & Communication


Ability to lead technical initiatives and influence engineering direction.
Strong written and verbal communication skills.
Experience mentoring engineers and driving engineering best practices.


Additional Skills/Preferences


Experience developing internal developer platforms (IDP) or self-service infrastructure portals.
Experience with FastAPI, Flask, Django, or similar Python frameworks.
Experience building automation services, operators, controllers, or orchestration platforms.
Familiarity with Kubernetes, containers, and cloud-native technologies.
Experience with observability platforms such as Prometheus, Grafana, Datadog, or OpenTelemetry.
Experience implementing policy-as-code using Open Policy Agent (OPA), Sentinel, or similar technologies.
