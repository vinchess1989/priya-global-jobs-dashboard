We are seeking a Technical Writer to create, maintain, and standardize high-quality technical and user-facing documentation across software development and client delivery projects. The successful candidate will work closely with engineering, product, and delivery teams to translate complex technical concepts into clear, accurate, and user-friendly documentation while ensuring consistency across technical and functional materials.




Responsibilities

Create and maintain technical documentation, including API references, developer guides, architecture overviews, release notes, and technical specifications.
Translate technical designs and engineering requirements into user-focused documentation such as user guides, onboarding materials, FAQs, and how-to guides.
Collaborate with engineering teams to understand system architecture, application workflows, integrations, and codebases.
Ensure consistency between technical documentation and functional documentation, including Functional Specification Documents (FSDs) and user guides.
Establish and maintain documentation standards, templates, style guides, and governance practices across projects and client engagements.
Review, edit, and improve documentation contributed by technical teams to ensure clarity, accuracy, and consistency.
Manage and maintain documentation repositories and knowledge bases.
Support documentation efforts using platforms such as Confluence, GitBook, Markdown, MkDocs, and client-specific documentation tools.
Leverage GitHub Copilot and related productivity tools to improve documentation quality and efficiency.
Coordinate with stakeholders across Singapore, India, and other global teams to support project delivery and documentation initiatives.




Qualifications




Bachelor's Degree in Technical Communication, Computer Science, Information Technology, Engineering, English, Journalism, or a related discipline.
Minimum 4 years of experience in Technical Writing, Documentation Management, Knowledge Management, or related roles.
Experience working within software development, IT consulting, technology services, or enterprise IT environments.
Proven experience creating technical documentation for software applications, platforms, or enterprise systems.
Strong ability to document APIs, software workflows, technical specifications, architecture designs, and system processes.
Experience creating developer documentation, user guides, release notes, onboarding guides, and knowledge base content.
Ability to translate technical concepts into clear and user-friendly documentation for technical and non-technical audiences.
Experience working directly with software engineers, architects, product teams, and business stakeholders.
Strong editing, proofreading, and documentation governance skills.
Experience using Confluence, GitBook, Markdown, MkDocs, or similar documentation platforms.
