Title: Release Manager/Engineer

Location: Sydney

Permanent Role




Job Description:

End-to-end release management across SIT, UAT, PPT, and PROD

Release scope control, code freeze, and deployment gating

Branching, version control and CI/CD coordination using GitLab/Jenkins

Change governance, including CHG / CAB coordination and release approvals

Release artefact management, status reporting, Go/No-Go support and hypercare coordination

Cross-team coordination across delivery, testing, DevOps, platform, operations and security teams

Salesforce release environments and deployment tooling, ideally with exposure to Salesforce Core & Commerce, sandbox-based release processes, and tools such as SFDX / GitLab / Terraform / JIRA / Confluence

Deployment automation skills are desired, including hands-on experience with CI/CD pipeline orchestration, automated deployments, release gating, rollback support, and environment promotion controls
