Role Overview

You will join the DevOps team and help build and run the cloud infrastructure that the engineering teams ship on. The work centres on containerised workloads, infrastructure defined as code, and configuration management, mainly on GCP with some AWS exposure.

Responsibilities


Build and maintain cloud infrastructure on GCP, and on AWS where required
Deploy, run and support workloads on Kubernetes
Write and maintain infrastructure as code using Terraform
Automate server and environment configuration using Ansible
Work with engineering teams to keep environments consistent and reliable



Required Skills And Experience


2+ years of hands-on DevOps experience
Commercial experience with GCP (preferred) or AWS
Working experience running and supporting Kubernetes
Terraform used on real projects
Ansible for configuration management and automation
